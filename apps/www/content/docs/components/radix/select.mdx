## Usage

```tsx
<Select>
  <SelectTrigger aria-label="Fruit" className="w-[180px]">
    <SelectValue placeholder="Select a fruit" />
  </SelectTrigger>
  <SelectContent>
    <SelectGroup>
      <SelectLabel>Fruits</SelectLabel>
      <SelectItem value="apple">Apple</SelectItem>
      <SelectItem value="banana">Banana</SelectItem>
    </SelectGroup>
    <SelectSeparator />
    <SelectItem value="lemon">Lemon</SelectItem>
  </SelectContent>
</Select>
```

## Motion

The content grows out of the trigger: it fades in from a 0.96 scale over 0.2s and closes faster, in 0.15s. With `position="item-aligned"` it only fades, since Radix lines the selected item up with the trigger. Moving the highlight with the arrow keys is instant, and under reduced motion the content fades without scaling.
