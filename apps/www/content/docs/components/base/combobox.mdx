## Usage

```tsx
const frameworks = ['Next.js', 'SvelteKit', 'Nuxt.js', 'Remix', 'Astro'];

<Combobox items={frameworks}>
  <ComboboxInput placeholder="Select a framework" />
  <ComboboxContent>
    <ComboboxEmpty>No results.</ComboboxEmpty>
    <ComboboxList>
      {(framework) => (
        <ComboboxItem key={framework} value={framework}>
          {framework}
        </ComboboxItem>
      )}
    </ComboboxList>
  </ComboboxContent>
</Combobox>;
```

### Multiple

Wrap the chips in `AnimatePresence` so a removed chip plays its exit:

```tsx
const anchor = useComboboxAnchor();

<Combobox items={frameworks} multiple>
  <ComboboxChips ref={anchor}>
    <ComboboxValue>
      {(values) => (
        <>
          <AnimatePresence mode="popLayout" initial={false}>
            {values.map((value) => (
              <ComboboxChip key={value}>{value}</ComboboxChip>
            ))}
          </AnimatePresence>
          <ComboboxChipsInput />
        </>
      )}
    </ComboboxValue>
  </ComboboxChips>
  <ComboboxContent anchor={anchor}>
    <ComboboxEmpty>No results.</ComboboxEmpty>
    <ComboboxList>
      {(framework) => (
        <ComboboxItem key={framework} value={framework}>
          {framework}
        </ComboboxItem>
      )}
    </ComboboxList>
  </ComboboxContent>
</Combobox>;
```

## Motion

The popup grows out of the input: it fades in from a 0.95 scale over 0.6s and closes faster, in 0.4s. Typing filters the list instantly, with no per-item or height animation, and moving the highlight with the arrow keys is instant too. The check appears with the list; in multiple mode, toggling an item fades and scales it. Chips pop in and fade out when removed with the button; Backspace removes them instantly. Under reduced motion everything fades without scaling.
