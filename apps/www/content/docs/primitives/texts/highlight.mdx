## API Reference

### HighlightText

<TypeTable
  type={{
    text: {
      description: 'The text to display.',
      type: 'string',
      required: true,
    },
    delay: {
      description: 'The delay before the highlight starts, in milliseconds.',
      type: 'number',
      required: false,
      default: '0',
    },
    transition: {
      description: 'The transition to use.',
      type: 'Transition',
      required: false,
      default: '{ duration: 2, ease: ease.out }',
    },
    inView: {
      description:
        'Whether to wait for the text to be in view before highlighting.',
      type: 'boolean',
      required: false,
      default: 'false',
    },
    inViewMargin: {
      description: 'The margin to use when the text is in view.',
      type: 'string',
      required: false,
      default: '0px',
    },
    inViewOnce: {
      description:
        'Whether the highlight only plays once. When false, it replays each time the text comes back into view.',
      type: 'boolean',
      required: false,
      default: 'true',
    },
    '...props': {
      description: 'The props of the highlight text.',
      type: 'HTMLMotionProps<"span">',
      required: false,
    },
  }}

## Accessibility

Under reduced motion the highlight is shown at once, without the sweep.
