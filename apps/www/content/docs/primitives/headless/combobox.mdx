## Usage

```tsx
const [selected, setSelected] = React.useState<string | null>(null);
const [query, setQuery] = React.useState('');
const filtered = fruits.filter((fruit) =>
  fruit.toLowerCase().includes(query.toLowerCase()),
);

<Combobox value={selected} onChange={setSelected} onClose={() => setQuery('')}>
  <ComboboxInput
    displayValue={(fruit: string | null) => fruit ?? ''}
    onChange={(event) => setQuery(event.target.value)}
  />
  <ComboboxButton>Open</ComboboxButton>
  <ComboboxOptions anchor="bottom start">
    {filtered.map((fruit) => (
      <ComboboxOption key={fruit} value={fruit}>
        {fruit}
      </ComboboxOption>
    ))}
  </ComboboxOptions>
</Combobox>;
```

## Motion

`ComboboxOptions` fades in from a 0.95 scale with `transition.dropdown` and exits faster with `transition.exit`. It is rendered `static` inside `AnimatePresence`, so it stays mounted while it exits; during the exit it keeps the last rendered options, so resetting the query in `onClose` doesn't flash the unfiltered list. Headless UI sets `data-anchor` (`bottom_start`, `top_end`…) on anchored options: map it to a `transform-origin` (`data-[anchor=bottom_start]:origin-top-left`…) so the list grows from the input. Filtering is keyboard-driven: options appear and disappear instantly, and the highlight follows the arrow keys instantly (style `data-focus`). Under reduced motion it fades without scaling.
