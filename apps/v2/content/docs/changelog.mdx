## 2.2.0

  </ChangelogItemVersion>

<ChangelogItemTitle>Vue</ChangelogItemTitle>

<ChangelogItemDescription>

- Animate UI for Vue: `@animate-ui/vue` animates reka-ui's primitives with Motion for Vue, moving like the React ones.
  - Accordion, Collapsible, Switch, Checkbox, Toggle, Progress, Radio Group, Toggle Group, Dialog, Alert Dialog, Sheet, Popover, Tooltip, Hover Card, Dropdown Menu, Context Menu, Menubar and Tabs.
- The CLI animates shadcn-vue projects too: `animate` swaps the reka-ui imports and removes the CSS animations.
- The docs have a React / Vue switch in the sidebar, every guide page in Vue, and a Vue home page.

</ChangelogItemDescription>

<ChangelogItemTitle>Fixes</ChangelogItemTitle>

<ChangelogItemDescription>

- Toggle Group surfaces, menu highlights and the text a toast swaps out sit exactly on their items in a box of fractional width, instead of up to half a pixel off.

</ChangelogItemDescription>

</ChangelogItem>

## 2.1.0

  </ChangelogItemVersion>

<ChangelogItemTitle>Components</ChangelogItemTitle>

<ChangelogItemDescription>

- New **Page Transition** component: animates the change from one page to the next with view transitions, for Next.js, React Router and TanStack Router.
  - Ten effects (`fade`, `slide`, `push`, `zoom`, `iris`, `wipe`, `bands`, `stack`, `flow`, `chop`), plus `random`.
  - Direction from the `nav-back` and `nav-forward` transition types, and a transition type named after an effect plays it for one navigation.
  - `PageTransitionShared` morphs an element from one page to the other.

</ChangelogItemDescription>

<ChangelogItemDescription>

<ChangelogItem major date="2026-10-18">
  <ChangelogItemVersion>

## 2.0.0

  </ChangelogItemVersion>

<ChangelogItemDescription>

Animate UI is now an npm package. Instead of copying animated versions of shadcn/ui components, you keep your own components and swap the primitives they're built on.

</ChangelogItemDescription>

<ChangelogItemTitle>Packages</ChangelogItemTitle>

<ChangelogItemDescription>

- **`@animate-ui/react`**: animated primitives for Radix UI, Base UI and React Aria, each with exactly its library's API, plus `transition` / `exitTransition` animation props.
- **`@animate-ui/cli`**: `animate-ui animate <component>` swaps the primitive imports of installed shadcn/ui components and removes the CSS animations Motion replaces, whatever your base and style. `animate-ui migrate` moves a v1 project to v2: every import it can (v1-only parts stay on their v1 file, reported as manual steps), then asks before deleting the v1 files nothing imports anymore.
- **React Aria** support, and a drop-in replacement for Vaul built on the Radix Dialog. Headless UI is no longer supported.
- **`AnimateUIProvider`**: one `tempo` to make every animation faster or slower, and `checkAnimation` to draw checks (the default) or pop them, single selections' checks gliding from item to item, and `reducedMotion` to choose how reduced motion applies.
- **Motion 14**: `motion` 14 is a peer dependency.

</ChangelogItemDescription>

<ChangelogItemTitle>Components</ChangelogItemTitle>

<ChangelogItemDescription>

- **New components**: Combobox, Context Menu, Drawer, Menubar, Navigation Menu, Pagination, Questionnaire, Select, Slider and Toast, for every library that has them, plus Input OTP, Scroll Fade, Sliding Text and Swapping Text. Sidebar now comes for Base UI and React Aria too.
- **Motion rules everywhere**: springs and short ease-out tweens, exits quicker than entrances, transforms and opacity instead of layout, interruptible animations, nothing on keyboard navigation, reduced motion respected.
- **Registry**: backgrounds, icons and the styled buttons (Liquid, Flip, GitHub Stars, Theme Toggler) are files added to your project with the shadcn CLI, to style as you like; Code Block has a ready-made block too.

</ChangelogItemDescription>

<ChangelogItemTitle>Icons</ChangelogItemTitle>

<ChangelogItemDescription>

- The animated Lucide icons, plus 133 new ones, installed with shadcn; their core now comes from `@animate-ui/react/icons`, with a `speed` prop.
- **Hugeicons**: a second library of animated icons, next to Lucide.

</ChangelogItemDescription>

<ChangelogItemTitle>Backgrounds</ChangelogItemTitle>

<ChangelogItemDescription>

- Topography and Glyph join the backgrounds. The animated ones pause off screen and in hidden tabs, show a still frame under reduced motion, and leave their content on top and clickable.

</ChangelogItemDescription>

<ChangelogItemTitle>AI</ChangelogItemTitle>

<ChangelogItemDescription>

- The Animate UI skill (`npx skills add imskyleen/animate-ui`) teaches Claude Code, Cursor or Codex to animate any component the Animate UI way, and `animate-ui audit` lists the animations of a project and what each one costs for the skill to review.
- Every registry file can also be added through the shadcn MCP server.

</ChangelogItemDescription>

<ChangelogItemDescription>

- New documentation, with one page per primitive and a tab per library.

</ChangelogItemDescription>
