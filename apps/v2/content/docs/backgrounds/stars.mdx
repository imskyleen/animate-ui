## Usage

```tsx
import { StarsBackground } from '@/components/animate-ui/backgrounds/stars';

export function Hero() {
  return (
    <section className="relative h-[480px] overflow-hidden">
      <StarsBackground className="absolute inset-0" />
    </section>
  );
}
```

## Animation

- Three layers of stars (1, 2 and 3px) scroll upwards in a loop at different speeds, for depth: the smallest crosses 2000px in `speed` seconds, the others take two and three times longer. They move with hardware-accelerated `transform`s.
- The sky shifts away from the mouse on a spring (`factor`, `transition`), for parallax. It follows a mouse only: a tap doesn't shift it.
- The loops pause off screen and while the tab is hidden.
- Under reduced motion, the stars hold still and there is no parallax.
