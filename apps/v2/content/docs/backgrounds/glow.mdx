## Usage

```tsx
import { GlowBackground } from '@/components/animate-ui/backgrounds/glow';

export function Hero() {
  return (
    <section className="relative h-[560px] overflow-hidden bg-background">
      <GlowBackground className="absolute inset-0">
        <h1 className="relative">Your title</h1>
      </GlowBackground>
    </section>
  );
}
```

## Animation

- Three wide glows, one per color, sit near the edges and drift slowly on their own loops (26s, 32s and 38s, divided by `speed`), so they never line up the same way twice.
- A faint glow trails the cursor on a slow spring (`transition`): it fades in over 0.8s when the cursor enters and fades out when it leaves.
- A fine static grain sits on top, so the gradients never band (`grain`).
- The glows move with hardware-accelerated `transform`s.
- The loops pause off screen and while the tab is hidden.
- Under reduced motion, the glows hold still and the cursor glow stays hidden.
