---
title: Icons
description: Animated icons for the icon libraries you already use. Each icon is a file in your project, added with the shadcn CLI, and animated by one small core from @animate-ui/react.
---

Start with [Get Started](/docs/icons/get-started), then pick your icon library. Its icons keep their names and their look, and gain animations you trigger on hover, tap, view or from a parent.
