## Installation

Add icons one by one, here Bell. Each icon is a file in your project; the core that animates them comes from `@animate-ui/react/icons`, which the CLI installs with the first icon.

<RegistryInstallation name="icons-lucide-bell" />

## Usage

```tsx
import { Bell } from '@/components/animate-ui/icons/bell';

<Bell animateOnHover />;
```

Triggers, animations, timing and every prop are the same for all icon libraries: see [Get Started](/docs/icons/get-started).
