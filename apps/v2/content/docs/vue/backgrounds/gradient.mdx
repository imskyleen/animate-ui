## Usage

```vue
<script setup lang="ts">
import GradientBackground from '@/components/animate-ui/backgrounds/gradient/GradientBackground.vue';
</script>

<template>
  <section class="relative h-[480px] overflow-hidden">
    <GradientBackground class="absolute inset-0" />
  </section>
</template>
```

## Animation

- A large gradient slides back and forth behind the container (`background-position`), one round trip every 15s.
- It pauses off screen and while the tab is hidden.
- Under reduced motion, it holds its first frame.
