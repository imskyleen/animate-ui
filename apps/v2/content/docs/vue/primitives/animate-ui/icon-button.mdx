## Usage

```vue
<script setup lang="ts">
import { IconButton, IconButtonParticles } from '@animate-ui/vue/primitives/buttons/icon';
</script>

<template>
  <IconButton aria-label="Star">
    <StarIcon />
    <IconButtonParticles class="text-neutral-500" />
  </IconButton>
</template>
```

## Animation

- Each click bursts particles from the top edge of the button (built on [Particles](/docs/vue/primitives/animate-ui/particles)): 6 dots fly 30px out around it (spread evenly at the full 360°), growing then shrinking back to nothing as they fade in and out, over 0.8s with an `easeOut`, one after another 50ms apart. A click during a burst starts it over.
- Pressing scales the button to `tap-scale` (0.97), on Motion's spring for scale (`stiffness: 550, damping: 30`). It doesn't scale on hover, unless you set `hover-scale`.
- `<AnimateUIProvider :tempo>` paces the press spring.
- Under reduced motion, the particles don't burst and the button doesn't scale.

Returns `bursts()`, the number of clicks so far: each one starts a new burst.
