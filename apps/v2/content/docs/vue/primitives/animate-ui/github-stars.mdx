## Usage

```vue
<script setup lang="ts">
import {
  GithubStars,
  GithubStarsIcon,
  GithubStarsLogo,
  GithubStarsNumber,
  GithubStarsParticles,
} from '@animate-ui/vue/primitives/github-stars';
</script>

<template>
  <GithubStars username="imskyleen" repo="animate-ui" class="flex items-center gap-2">
    <GithubStarsLogo class="size-6" />
    <GithubStarsNumber />
    <GithubStarsParticles>
      <GithubStarsIcon :icon="StarIcon" class="size-4" color="gold" />
    </GithubStarsParticles>
  </GithubStars>
</template>
```

The count is fetched from the GitHub API (`api.github.com/repos/<username>/<repo>`), unauthenticated. To avoid the request (rate limits, server-side data), pass the count with `value`.

## Animation

- Once the count is loaded, the number counts up from 0 with rolling digits ([Sliding Number](/docs/vue/primitives/animate-ui/sliding-number)).
- The star fills from the bottom as the number climbs, and bursts into particles when the count is reached.
- Nothing is rendered until the count is loaded (with `as-child`, the child is there but hidden); the container is marked `aria-busy` meanwhile.
- With `in-view`, the request waits for the element to be on screen.
- Under reduced motion, the digits change without rolling and the burst is skipped.
