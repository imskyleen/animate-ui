## Usage

```vue
<script setup lang="ts">
import { computed, ref } from 'vue';
import {
  PinnedList,
  PinnedListItem,
  PinnedListItems,
  PinnedListLabel,
  PinnedListPinned,
  PinnedListTrigger,
  PinnedListUnpinned,
} from '@animate-ui/vue/primitives/pinned-list';

const items = ref(ITEMS);
const toggle = (id: string) =>
  (items.value = items.value.map((i) => (i.id === id ? { ...i, pinned: !i.pinned } : i)));

const pinned = computed(() => items.value.filter((i) => i.pinned));
const unpinned = computed(() => items.value.filter((i) => !i.pinned));
</script>

<template>
  <PinnedList @pinned-change="toggle">
    <PinnedListPinned>
      <PinnedListLabel :hide="pinned.length === 0">Pinned</PinnedListLabel>
      <PinnedListItems>
        <PinnedListItem v-for="item in pinned" :id="item.id" :key="item.id" custom-trigger>
          {{ item.name }}
          <PinnedListTrigger :aria-label="`Unpin ${item.name}`">…</PinnedListTrigger>
        </PinnedListItem>
      </PinnedListItems>
    </PinnedListPinned>
    <PinnedListUnpinned>
      <PinnedListLabel :hide="unpinned.length === 0">All</PinnedListLabel>
      <PinnedListItems>
        <PinnedListItem v-for="item in unpinned" :id="item.id" :key="item.id" custom-trigger>
          {{ item.name }}
          <PinnedListTrigger :aria-label="`Pin ${item.name}`">…</PinnedListTrigger>
        </PinnedListItem>
      </PinnedListItems>
    </PinnedListUnpinned>
  </PinnedList>
</template>
```

You own the pinned state: `@pinned-change` tells you which item to move. Without `custom-trigger`, clicking the whole item toggles it.

## Animation

- The item glides to its new place on a spring (stiffness 320, damping 25, mass 0.8: a shared layout animation with a slight overshoot), above the other items while it moves. The others make room.
- Labels fade in and out when a group becomes empty or filled (220ms, ease-out), and slide with the items making room, on the items' spring.
- Triggers, and items without `custom-trigger`, shrink on press (scale 0.97) on a quick spring (the item's own spring for items). Nothing scales on hover.
- `<AnimateUIProvider :tempo>` paces the default transitions.
- Under reduced motion, items jump to their new place and don't scale.

### usePinnedList, usePinnedListItem

`usePinnedList` returns the `movingId` ref (the item moving between the lists) and `pin(id)`. `usePinnedListItem` returns an `id()` getter.
