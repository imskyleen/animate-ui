## Usage

```vue
<script setup lang="ts">
import { Image, ImageZoom } from '@animate-ui/vue/primitives/effects/image-zoom';
</script>

<template>
  <ImageZoom width="320px" height="320px" aria-label="Product photo, zoomable">
    <Image src="/product.webp" alt="The product" />
  </ImageZoom>
</template>
```

`Image` renders an `img` by default; pass `as` to use your framework's image component (`:as="NuxtImg"`).

## Animation

- Hovering zooms in to `zoom-scale` on a spring, from the point under the pointer; moving the pointer pans the zoom.
- Clicking (or tapping on touch screens) toggles the zoom. The cursor shows whether a click zooms in or out.
- Under reduced motion, the zoom jumps instead of scaling.
