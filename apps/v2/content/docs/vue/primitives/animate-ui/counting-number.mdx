## Usage

```vue
<script setup lang="ts">
import { CountingNumber } from '@animate-ui/vue/primitives/texts/counting-number';
</script>

<template>
  <CountingNumber :number="2025" in-view />
</template>
```

A new `number` springs on from where the count is instead of restarting it.

## Animation

- Counts from `from-number` to `number` on a spring (`stiffness: 90, damping: 50`): most of the range goes by in the first second, then the last units tick in slowly (2025 lands after about 4.5s).
- The ticking value is written to the DOM directly, without a Vue render per frame.
- `transition` takes other spring options, or any Motion transition with a `type` or an `ease`.
- `<AnimateUIProvider :tempo>` paces the default spring.
- Under reduced motion, the number shows its target right away.
- Screen readers read the target value once, never the ticking values.
