## Usage

```vue
<script setup lang="ts">
import { Spring, SpringElement, SpringProvider } from '@animate-ui/vue/primitives/spring';
</script>

<template>
  <SpringProvider>
    <Spring class="text-muted-foreground" />
    <SpringElement>
      <img src="/avatar.png" alt="Avatar" draggable="false" />
    </SpringElement>
  </SpringProvider>
</template>
```

<Callout type="info">
  Add `draggable="false"` to images inside `SpringElement`, so the browser's
  native drag image doesn't take over the drag.
</Callout>

## Animation

- Dragging stretches a coil between the element's place and the element. The coil tightens as it stretches.
- On release, the element springs back with a bounce, the coil following it.
- `Spring` is a full-viewport SVG that never catches the pointer.
- Under reduced motion, the element is back in place at once on release.

### useSpring

Returns the spring state: the `x`/`y` and `springX`/`springY` motion values, the `isDragging` ref, a `path()` getter for the coil and the `child` ref.
