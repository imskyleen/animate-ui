## Usage

```vue
<script setup lang="ts">
import {
  BottomNavigation,
  BottomNavigationAccessory,
  BottomNavigationHighlight,
  BottomNavigationHighlightItem,
  BottomNavigationItem,
  BottomNavigationLabel,
} from '@animate-ui/vue/primitives/bottom-navigation';

const ITEMS = [
  { value: 'home', href: '/', label: 'Home', icon: HomeIcon },
  { value: 'search', href: '/search', label: 'Search', icon: SearchIcon },
];
</script>

<template>
  <BottomNavigation
    default-value="home"
    scroll-behavior="minimize"
    aria-label="Main"
    class="fixed inset-x-0 bottom-4 mx-auto flex w-fit items-center gap-2"
  >
    <BottomNavigationHighlight class="absolute inset-0 rounded-full bg-muted">
      <ul class="flex rounded-full border bg-background p-1.5">
        <li v-for="item in ITEMS" :key="item.value">
          <BottomNavigationHighlightItem :value="item.value">
            <BottomNavigationItem
              :value="item.value"
              :href="item.href"
              class="flex items-center px-4 py-2"
            >
              <component :is="item.icon" />
              <BottomNavigationLabel class="pl-2">{{
                item.label
              }}</BottomNavigationLabel>
            </BottomNavigationItem>
          </BottomNavigationHighlightItem>
        </li>
      </ul>
    </BottomNavigationHighlight>
    <BottomNavigationAccessory class="rounded-full border bg-background p-1.5">
      <button class="size-11 rounded-full hover:bg-muted">+</button>
    </BottomNavigationAccessory>
  </BottomNavigation>
</template>
```

Items are links: give them an `href`, or `as-child` with your router's link (`RouterLink`, `NuxtLink`) or a `button`. The selected item gets `aria-current="page"` and `data-state="active"`. With a router, bind the current route with `v-model` so the highlight follows navigation. `BottomNavigationHighlight` and `BottomNavigationHighlightItem` are optional; without them, style the active item with `data-state="active"`.

`scroll-behavior` sets what the bar does while the page scrolls down: `"minimize"` folds it to the selected item, like iOS' tab bar, `"hide"` slides it out, and `"none"` (the default) leaves it. It comes back as soon as the page scrolls up or reaches the top, an item takes focus, or the bar is tapped. It listens to the window, or to `scroll-container` (a template ref's element) when the page scrolls inside an element. To fold, items shrink to nothing, padding included: space them with padding rather than a `gap`, which would stay.

`BottomNavigationLabel` and `BottomNavigationAccessory` are optional:

- A label shows only on the selected item, so the bar stays icons and one name. Its text stays in the accessibility tree, so it names the item even while closed.
- The accessory (a button, a player, a search field) stays beside the bar, folded or not: it follows the bar as it folds. Pressing or focusing it leaves the bar folded.

A closed label takes no room: put its spacing inside it (`pl-2`), not on the item.

## Animation

- The highlight slides to the selected item on a spring (stiffness 300, damping 30): one surface is handed from the previous item to the new one, at full opacity ([Highlight](/docs/primitives/animate-ui/highlight)).
- Items scale to 0.97 while pressed, on the buttons' spring.
- Labels open on the highlight's spring, so the highlight widens with the selected item: the new label grows from nothing out of a 4px blur as the previous one narrows and blurs away.
- Both scroll behaviors start once the page has scrolled down by 6px and run on a critically damped spring (stiffness 300, damping 35).
  - `"minimize"`: the other items narrow to nothing as they fade out into a 4px blur, the bar closing around the selected one with its highlight; they come back the same way.
  - `"hide"`: the bar slides out past the bottom edge, and back on the way up.
- `<AnimateUIProvider :tempo>` paces every spring.
- Under reduced motion, the highlight moves at once, items don't scale, labels change width at once (fading), the bar folds at once, and the hidden bar fades out instead of sliding (and can’t be clicked while hidden).
