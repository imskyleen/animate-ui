## Installation

<Installation />

The code is highlighted with [Shiki](https://shiki.style), a peer dependency of this primitive, loaded on demand:

```npm
npm install shiki
```

## Usage

```vue
<script setup lang="ts">
import { CodeBlock } from '@animate-ui/vue/primitives/code-block';
</script>

<template>
  <CodeBlock
    code="console.log('Hello, world!');"
    lang="javascript"
    writing
    :duration="2000"
  />
</template>
```

The block renders Shiki's `<pre>` inside a div. Style it through that div (`[&_pre]:…`, `[&_.line]:…`); `data-writing` and `data-done` let you show a cursor while it types.

## Animation

- With `writing`, the code appears one character at a time, evenly over `duration` (after `delay`), and the block and `scroll-container` (its parent element by default) scroll smoothly to follow the last line.
- With `in-view`, writing starts when the block scrolls into view.
- Under reduced motion, the whole code is shown at once (`done` is still emitted).

### CodeBlock

It emits `done` once the whole code is shown, and `write` (`{ index, length, done }`) on each written character, and once done.
