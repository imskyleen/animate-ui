The other parts stay as they are.

shadcn-vue's Code Block isn't built on a primitive it could swap: `animate-ui animate code-block` rewrites it in place instead. In `CodeBlockContent.vue` the outer `Primitive` becomes the code-block primitive's `Content`, and `CodeBlockCopyButton.vue` is built on the [Copy Button](/docs/vue/primitives/animate-ui/copy-button). A file you changed is left as it is, and the CLI points here: the Manual tab lists the edits.

## Usage

```vue
<script setup lang="ts">
import { useCodeWriting } from '@animate-ui/vue/primitives/code-block';
import {
  CodeBlock,
  CodeBlockActions,
  CodeBlockContent,
  CodeBlockCopyButton,
  CodeBlockHeader,
  CodeBlockLine,
  CodeBlockTitle,
  CodeBlockToken,
  useHighlightedCode,
} from '@/components/ui/code-block';

const props = defineProps<{ code: string }>();

const written = useCodeWriting(
  () => props.code,
  () => ({
    duration: 4000,
    inView: true,
  }),
);
const lines = useHighlightedCode(written.code, 'ts');
</script>

<template>
  <CodeBlock :ref="written.ref">
    <CodeBlockHeader>
      <CodeBlockTitle>route.ts</CodeBlockTitle>
      <CodeBlockActions>
        <CodeBlockCopyButton :value="code" />
      </CodeBlockActions>
    </CodeBlockHeader>
    <CodeBlockContent :writing="written.writing.value" line-numbers>
      <CodeBlockLine v-for="(line, index) in lines" :key="index">
        <CodeBlockToken v-for="(token, i) in line" :key="i" :token="token" />
      </CodeBlockLine>
    </CodeBlockContent>
  </CodeBlock>
</template>
```

Everything else is shadcn-vue's: the composition, plain text content, line numbers, wrapping, diff and highlighted lines, the small size and the destructive variant. Without `useCodeWriting`, the block shows its code at once.

`useCodeWriting` types the code out and returns what is written so far: highlight that, and give `writing` to `CodeBlockContent` for the cursor and the scroll. Its `ref` goes on the element (or component) whose entering the viewport starts the writing (with `inView`). `useHighlightedCode` (shadcn-vue's) returns the tokens of each line, rendered with `CodeBlockToken`. The copy button copies the whole `value`, even while the code is being written.

## Animation

- With `useCodeWriting`, the code appears one character at a time, evenly over `duration` (after `delay`). With `cadence: 'natural'`, it types like someone typing instead: quicker inside a word, pausing after punctuation and at the end of a line, the next line's indentation coming at once. Each new line is highlighted as it comes: `useHighlightedCode` tokenizes only the lines that are new.
- While it writes, `CodeBlockContent` shows a cursor (`|`) at the end of the last line (`:cursor="false"` hides it) and scrolls smoothly to follow the last line.
- The last characters written fade in behind the cursor, on `CodeBlockLine`s (plain text content gets the cursor only): transparent right behind it, opaque again 4 characters back. When the writing pauses (450ms without a new character) or moves to a new line, the fade slides off the end in 250ms (ease-out `cubic-bezier(0.23, 1, 0.32, 1)`), and the cursor pulses until it goes on.
- With `inView`, writing starts when the block scrolls into view.
- The copy button's icon shrinks into a blur as the check grows out of it when the code is copied, and swaps back after 2 seconds ([Copy Button](/docs/primitives/animate-ui/copy-button)); the button scales to 0.97 while pressed.
- Wrapping on or off (`:wrap`), the lines glide to their new place and the block to its new height, in 300ms with the same ease-out.
- Under reduced motion, the whole code is shown at once (`onDone` is still called), so there is no cursor or fade; wrapping changes at once; the copy icons crossfade through their blur without scaling, and the button doesn't scale.

### useCodeWriting

`useCodeWriting(code, options)` takes the code (a value, ref or getter) and a getter of options, and returns `{ ref, element, code, writing, done, isInView }`: `code` is what is written so far (a ref), `writing` is true until the whole code is shown.

## Primitive

`@animate-ui/vue/primitives/code-block` also exports the `CodeBlock` primitive: one element that highlights a whole `code` with Shiki's `codeToHtml` (a peer dependency, loaded on demand) and types it out.

```vue
<CodeBlock code="console.log('Hello, world!');" lang="javascript" writing />
```
