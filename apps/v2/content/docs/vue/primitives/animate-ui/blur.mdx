## Usage

```vue
<script setup lang="ts">
import { Blur, Blurs } from '@animate-ui/vue/primitives/effects/blur';
import Card from './Card.vue';
</script>

<template>
  <Blur>
    <h1>Animated primitives for Vue</h1>
  </Blur>
  <!-- Staggered: each child starts 100ms after the previous one. -->
  <Blurs :hold-delay="100">
    <Card />
    <Card />
    <Card />
  </Blurs>
</template>
```

With `as-child`, the animation is applied to your element instead of a wrapping `div`.

## Animation

- The element sharpens from `initial-blur` to `blur` on a spring (stiffness 200, damping 20): about 250ms from 10px to sharp.
- Under reduced motion, it still comes into focus: a blur doesn't move anything.
- `in-view` waits for the element to scroll into view, once by default.
- `<AnimateUIProvider :tempo>` paces the default spring.
