## Installation

<Installation />

The tooltips are Animate UI's [Tooltip](/docs/vue/primitives/animate-ui/tooltip), positioned with [Floating UI](https://floating-ui.com), a peer dependency of this primitive:

```npm
npm install @floating-ui/react
```

## Usage

```vue
<script setup lang="ts">
import { AvatarGroup } from '@animate-ui/vue/primitives/avatar-group';

defineProps<{ people: { name: string; src: string }[] }>();
</script>

<template>
  <AvatarGroup class="h-12 -space-x-3" invert-overlap>
    <img
      v-for="person in people"
      :key="person.name"
      :src="person.src"
      :alt="person.name"
      class="size-12 rounded-full border-3 border-background"
    />
  </AvatarGroup>
</template>
```

Each child is an avatar. Put an `AvatarGroupTooltip` inside an avatar to give it a tooltip:

```vue
<div class="size-12 rounded-full border-3 border-background bg-muted">
  SK
  <AvatarGroupTooltip class="rounded-md bg-foreground px-3 py-1.5 text-xs text-background">
    <AvatarGroupTooltipArrow class="size-2.5 fill-foreground" />
    <p>Skyleen</p>
  </AvatarGroupTooltip>
</div>
```

## Animation

- The hovered (or pressed) avatar rises by `translate` on a bouncy spring (stiffness 300, damping 17): it overshoots by about 17% before it settles, and dips below its place the same way when it comes back down.
- The tooltips share one popup ([Tooltip](/docs/vue/primitives/animate-ui/tooltip)): it opens at once (`open-delay` is 0) and glides from avatar to avatar on its spring (stiffness 400, damping 29), a little past the next avatar before it settles.
- `<AnimateUIProvider :tempo>` paces the default springs.
- Under reduced motion, the avatar rises at once and the tooltip only fades.
