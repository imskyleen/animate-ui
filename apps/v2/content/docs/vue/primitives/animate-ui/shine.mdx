## Usage

```vue
<script setup lang="ts">
import { Shine } from '@animate-ui/vue/primitives/effects/shine';
</script>

<template>
  <Shine as-child loop :loop-delay="500">
    <button>Get started</button>
  </Shine>
</template>
```

`enable-on-hover` and `enable-on-tap` play the shine on interaction instead of right away.

## Animation

- A skewed gradient of `color` (the text color by default) sweeps from left to right over `duration` (1.2s, `cubic-bezier(0.4, 0, 0.2, 1)`), clipped to the element. It never catches the pointer.
- With `loop`, it sweeps again after `loop-delay`. With `enable-on-hover` and `loop`, it keeps sweeping while hovered.
- It moves with a hardware-accelerated `transform`.
- Under reduced motion, there is no shine: it's decorative.
