## Usage

```vue
<script setup lang="ts">
import {
  RotatingText,
  RotatingTextContainer,
} from '@animate-ui/vue/primitives/texts/rotating';
</script>

<template>
  <RotatingTextContainer :text="['Fast', 'Accessible', 'Animated']">
    <RotatingText />
  </RotatingTextContainer>
</template>
```

## Animation

- After `delay` (right away by default), the current word slides out by `y` while fading, then the next one slides in from the other side: 0.3s each on an ease-out, one after the other. The next swaps follow every `duration`. With no delay, the first word leaves as soon as it mounts, so the second one is the first to show.
- The cycle pauses off screen and in a hidden tab.
- `<AnimateUIProvider :tempo>` paces the default transition.
- Under reduced motion, the words keep taking turns as a crossfade, without travel.
- With `align`, the container keeps the width of its longest text, so a word swap never moves the text around it, and each word sits at the start, center or end of that width.
- Screen readers read every word once, never the cycling one.
