## Usage

```vue
<script setup lang="ts">
import { HighlightText } from '@animate-ui/vue/primitives/texts/highlight';
</script>

<template>
  <HighlightText
    text="Highlight Text"
    class="bg-linear-to-r from-blue-100 to-purple-100"
    in-view
  />
</template>
```

## Animation

- The background grows from the left edge over 2s on an ease-in-out: slow at first, fastest midway, easing into place.
- With `:in-view-once="false"`, it resets off screen and sweeps again on the next entrance.
- `<AnimateUIProvider :tempo>` paces the default duration.
- Under reduced motion, the text is highlighted at once.
