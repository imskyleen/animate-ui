## Usage

```vue
<script setup lang="ts">
import { Particles, ParticlesEffect } from '@animate-ui/vue/primitives/effects/particles';

defineProps<{ liked: boolean }>();
</script>

<template>
  <Particles :animate="liked">
    <button>Like</button>
    <ParticlesEffect class="size-1 rounded-full bg-red-500" />
  </Particles>
</template>
```

The burst plays when `animate` becomes `true`. Remount `Particles` (with a `key`) to replay it.

## Animation

- `count` particles shoot out from a point on one side of the element, spread over `spread` degrees, then shrink and fade out (800ms, ease-out). Each starts `hold-delay` seconds after the previous one.
- Particles are absolutely positioned: the layout never moves.
- With `in-view`, the burst waits for the element to be on screen.
- Under reduced motion, the burst is skipped: it's decorative.
