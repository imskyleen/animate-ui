## Usage

```vue
<script setup lang="ts">
import { Zoom, Zooms } from '@animate-ui/vue/primitives/effects/zoom';
import Card from './Card.vue';
</script>

<template>
  <Zoom>
    <h1>Animated primitives for Vue</h1>
  </Zoom>
  <!-- Staggered: each child starts 100ms after the previous one. -->
  <Zooms :hold-delay="100">
    <Card />
    <Card />
    <Card />
  </Zooms>
</template>
```

With `as-child`, the animation is applied to your element instead of a wrapping `div`.

## Animation

- The element scales from `initial-scale` (0.5 by default) to `scale` on a spring (stiffness 200, damping 20), overshooting by about 2% before it settles.
- Under reduced motion, it doesn't scale: it fades in instead.
- `in-view` waits for the element to scroll into view, once by default.
- `<AnimateUIProvider :tempo>` paces the default spring.
