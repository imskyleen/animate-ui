## Usage

```vue
<script setup lang="ts">
import { Fade, Fades } from '@animate-ui/vue/primitives/effects/fade';
import Card from './Card.vue';
</script>

<template>
  <Fade>
    <h1>Animated primitives for Vue</h1>
  </Fade>
  <!-- Staggered: each child starts 100ms after the previous one. -->
  <Fades :hold-delay="100">
    <Card />
    <Card />
    <Card />
  </Fades>
</template>
```

With `as-child`, the animation is applied to your element instead of a wrapping `div`.

## Animation

- The element fades from `initial-opacity` to `opacity` on a spring (stiffness 200, damping 20): about 250ms.
- Only opacity animates, so it stays the same under reduced motion.
- `in-view` waits for the element to scroll into view, once by default.
- `<AnimateUIProvider :tempo>` paces the default spring.
