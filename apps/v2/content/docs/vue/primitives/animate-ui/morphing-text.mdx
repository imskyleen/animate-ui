## Usage

```vue
<script setup lang="ts">
import { MorphingText } from '@animate-ui/vue/primitives/texts/morphing';
</script>

<template>
  <MorphingText :text="['Fast', 'Accessible', 'Animated']" loop />
</template>
```

<Callout type="info">
  Letters are animated one by one, so a line can break inside a word. Prefer
  texts short enough not to wrap.
</Callout>

## Animation

- Each text holds for `hold-delay`, then morphs into the next. The letters both texts share, in the same order, slide to their new place on `spring.selection` (stiffness 300, damping 30): they never cross each other. The others fade out into a blur (6px) in 150ms, and the new ones rise in from it (0.12em, 300ms on the ease-out curve), 80ms later and 12ms apart.
- Each letter takes exactly its width in the whole text, so the font's kerning holds: at rest, the text reads as if it were set in one piece.
- Emoji and accented letters stay whole.
- The cycle pauses off screen and in a hidden tab.
- `<AnimateUIProvider :tempo>` paces the default spring.
- Under reduced motion, the texts keep cycling as a plain crossfade.
- Screen readers read the current text whole, not letter by letter. It is not a live region.
