## Usage

```vue
<script setup lang="ts">
import {
  ScrollingNumber,
  ScrollingNumberContainer,
  ScrollingNumberHighlight,
  ScrollingNumberItems,
} from '@animate-ui/vue/primitives/texts/scrolling-number';
</script>

<template>
  <ScrollingNumberContainer :number="1000" :step="100" :items-size="40">
    <ScrollingNumber>
      <ScrollingNumberItems />
    </ScrollingNumber>
    <ScrollingNumberHighlight />
  </ScrollingNumberContainer>
</template>
```

## Animation

- After `delay`, the strip spins through every step up to `number` on a spring (`stiffness: 90, damping: 30`): fast through the range, then it settles without overshoot.
- A new `number` springs on from where the strip is.
- The strip is written by a motion value, without a Vue render per frame. `@number-change` reports the value under the highlight as it passes.
- `<AnimateUIProvider :tempo>` paces the default spring.
- Under reduced motion, the wheel lands on the number right away.
- The strip is hidden from screen readers, which read the number once from the container.
