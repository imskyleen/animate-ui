## Usage

```vue
<script setup lang="ts">
import {
  HoverCardContent,
  HoverCardPortal,
  HoverCardRoot,
  HoverCardTrigger,
} from '@animate-ui/vue/primitives/reka-ui';
</script>

<template>
  <HoverCardRoot>
    <HoverCardTrigger href="https://animate-ui.com"
      >@animate_ui</HoverCardTrigger
    >
    <HoverCardPortal>
      <HoverCardContent :side-offset="4"
        >Animated drop-in primitives for Reka UI.</HoverCardContent
      >
    </HoverCardPortal>
  </HoverCardRoot>
</template>
```

## Animation

The motion of Animate UI's React Hover Card:

- **Content** grows from 0.8 and fades in, from the trigger (`--reka-hover-card-content-transform-origin`), on a spring (stiffness 400, damping 29) that overshoots a little before it settles.
- Once reka-ui's `close-delay` is over, it closes the same way: it shrinks back to 0.8 on the same spring while it fades out, then unmounts.
- reka-ui only opens it for mouse-like pointers: a tap on a touch screen follows the link, nothing sticks.
- With `force-mount` (on the Content or the Portal), the closed content stays in the DOM: it plays its exit, then is hidden and `inert`.
- Reopening while it closes picks up from where it is, on the same spring.
- Open from the start (`default-open`), it plays the same entrance on page load.
- With `follow-cursor` on the Root, the content leans towards the pointer while it moves over the trigger, by half its offset from the trigger's center, on a spring (stiffness 200, damping 17): on both axes, or only `'x'` or `'y'`. Under reduced motion it follows without the spring.
- Under reduced motion, it only fades (no scale).

## API Reference

Every part takes exactly the props of [reka-ui's Hover Card](https://reka-ui.com/docs/components/hover-card#api-reference). Animate UI adds the animation props below.

### HoverCardRoot

[reka-ui props](https://reka-ui.com/docs/components/hover-card#root), plus:

<TypeTable
  type={{
    'follow-cursor': {
      description:
        'Make the content follow the pointer over the trigger, on both axes or only one.',
      type: "boolean | 'x' | 'y'",
      default: 'false',
    },
    'follow-cursor-spring-options': {
      description: 'The spring the content follows the pointer on.',
      type: 'SpringOptions',
      default: '{ stiffness: 200, damping: 17 }',
    },
  }}
/>

### HoverCardTrigger, HoverCardPortal, HoverCardArrow

[reka-ui props](https://reka-ui.com/docs/components/hover-card#trigger) only. They are not animated.

### HoverCardContent

[reka-ui props](https://reka-ui.com/docs/components/hover-card#content), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the opening, and of the closing unless `exit-transition` is set.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 400, damping: 29 }",
    },
    'exit-transition': {
      description: 'Transition of the closing.',
      type: 'Transition',
      default: 'transition',
    },
  }}
/>
