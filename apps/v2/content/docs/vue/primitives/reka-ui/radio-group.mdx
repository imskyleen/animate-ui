## Usage

```vue
<script setup lang="ts">
import {
  RadioGroupIndicator,
  RadioGroupItem,
  RadioGroupRoot,
} from '@animate-ui/vue/primitives/reka-ui';
</script>

<template>
  <RadioGroupRoot default-value="comfortable" aria-label="Density">
    <RadioGroupItem id="r1" value="default">
      <RadioGroupIndicator>
        <span class="size-2 rounded-full bg-current" />
      </RadioGroupIndicator>
    </RadioGroupItem>
    <label for="r1">Default</label>
  </RadioGroupRoot>
</template>
```

## Animation

The motion of Animate UI's React radio group:

- **Indicator**: the dot pops in when its item is selected. Its scale and its opacity spring from 0 to 1 (stiffness 200, damping 16: it overshoots a little before settling), and back to 0 the same way when another item is selected, then the indicator unmounts, as in reka-ui. The indicator element itself never moves: its content (the dot) animates, so shadcn-vue's centered dot stays centered.
- **Item** scales to 0.97 while pressed (no hover scale), on Motion's default spring for scale (stiffness 550, damping 30).
- In the demo, an item's fill is a layer of its own (`before:` in its classes) that grows from 70% while it fades in, in 300ms, and shrinks back as it fades out, like the [Checkbox](/docs/vue/primitives/reka-ui/checkbox)'s: the dot pops in over it. The layer covers the border (`before:-inset-px`) and the border keeps its color. It's CSS, so copy the classes for the same effect; under reduced motion the layer only fades.
- An item already selected when the group appears (the page loading, a dialog opening) shows its dot at rest: only a change of selection animates a dot.
- Selecting with the arrow keys animates like a click.
- Selecting again mid-animation turns back from where the dot is.
- Under reduced motion, the dot only fades and nothing scales.
- With `force-mount`, an unselected item's indicator stays in the DOM with its dot hidden.

## API Reference

Every part takes exactly the props of [reka-ui's Radio Group](https://reka-ui.com/docs/components/radio-group#api-reference). Animate UI adds the animation props below. With `as-child`, a part renders your element with reka-ui's behaviour, without the animation.

### RadioGroupRoot

[reka-ui props](https://reka-ui.com/docs/components/radio-group#root) only: nothing animates on the group itself.

### RadioGroupItem

[reka-ui props](https://reka-ui.com/docs/components/radio-group#item), plus:

<TypeTable
  type={{
    transition: {
      description: 'Transition of the press scale.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 550, damping: 30, restSpeed: 10 }",
    },
  }}
/>

### RadioGroupIndicator

[reka-ui props](https://reka-ui.com/docs/components/radio-group#indicator), plus:

<TypeTable
  type={{
    transition: {
      description: 'Transition of the dot appearing.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 200, damping: 16 }",
    },
    exitTransition: {
      description: 'Transition of the dot leaving.',
      type: 'Transition',
      default: 'the same spring as transition',
    },
  }}
/>

`AnimateUIProvider`'s `tempo` scales these transitions with everything else.
