Animate UI for Vue animates your shadcn-vue components: they keep their structure, their styles and reka-ui's API, and only the import changes.

```ts
import { AccordionContent } from 'reka-ui' // [!code --]
import { AccordionContent } from '@animate-ui/vue/primitives/reka-ui' // [!code ++]
```

## Installation

```npm
npm install @animate-ui/vue motion-v
```

`@animate-ui/vue/primitives/reka-ui` exports everything reka-ui does, helpers and props types included: swap a file's whole `reka-ui` import, and the parts Animate UI animates take over. It's built on [Motion for Vue](https://motion.dev/docs/vue), with the same springs, curves and timings as Animate UI for React.
