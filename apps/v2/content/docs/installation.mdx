## Install the packages

```npm
npm install @animate-ui/react motion
```

`@animate-ui/react` uses the primitive library your components already depend on (`radix-ui`, `@base-ui/react` or `react-aria-components`).

## Animate your components

Run the CLI in your project. It finds your shadcn/ui components through `components.json`, swaps their primitive imports for Animate UI's and removes the CSS animation classes Motion replaces.

```bash
pnpm dlx @animate-ui/cli@latest animate all
```

Animate one component at a time by naming it, and preview the changes with `--dry-run`:

```bash
pnpm dlx @animate-ui/cli@latest animate accordion --dry-run
```

## Change the pace (optional)

Every animation follows the same timing. Wrap your app in `AnimateUIProvider` to make it all faster or slower:

```tsx
import { AnimateUIProvider } from '@animate-ui/react/provider';

export default function Layout({ children }: { children: React.ReactNode }) {
  return <AnimateUIProvider tempo={1.2}>{children}</AnimateUIProvider>;
}
```

`tempo` multiplies every duration: `0.8` feels crisper, `1.2` more relaxed. Without the provider, the defaults apply.
