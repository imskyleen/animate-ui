## Usage

```tsx
import { Zoom, Zooms } from '@animate-ui/react/primitives/effects/zoom';

export function Hero() {
  return (
    <>
      <Zoom>
        <h1>Animated primitives for React</h1>
      </Zoom>

      {/* Staggered: each child starts 100ms after the previous one. */}
      <Zooms holdDelay={100}>
        <Card />
        <Card />
        <Card />
      </Zooms>
    </>
  );
}
```

With `asChild`, the animation is applied to your element instead of a wrapping `div`.

## Animation

- The element scales from `initialScale` (0.5 by default) to `scale` on a spring (stiffness 200, damping 20), overshooting by about 2% before it settles.
- Under reduced motion, it doesn't scale: it fades in instead.
- `inView` waits for the element to scroll into view, once by default.
- `<AnimateUIProvider tempo>` paces the default spring.
