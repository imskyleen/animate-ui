## Usage

```tsx
import { SlidingNumber } from '@animate-ui/react/primitives/texts/sliding-number';

export function Price({ value }: { value: number }) {
  return <SlidingNumber number={value} thousandSeparator="," />;
}
```

## Animation

- Each digit rolls to its new value on a quick spring without overshoot (0.25s), in the direction the number moves: up when it grows. 9 to 0 rolls one step forward, not back through every digit.
- With `fromNumber`, the number counts to `number` over 3s on a strong ease-out, every digit rolling on the way.
- Digits are positioned in percentages of their own height: no measuring, right on the first frame and when the font size changes. Counting doesn't re-render React per frame.
- `<AnimateUIProvider tempo>` paces the default spring and count.
- Under reduced motion, the digits change without rolling.
- Screen readers read the number once, not every rolled digit.
