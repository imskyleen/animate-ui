## Usage

```tsx
import { Slide, Slides } from '@animate-ui/react/primitives/effects/slide';

export function Hero() {
  return (
    <>
      <Slide direction="up">
        <h1>Animated primitives for React</h1>
      </Slide>

      {/* Staggered: each child starts 100ms after the previous one. */}
      <Slides holdDelay={100} direction="up">
        <Card />
        <Card />
        <Card />
      </Slides>
    </>
  );
}
```

With `asChild`, the animation is applied to your element instead of a wrapping `div`.

## Animation

- The element travels `offset` pixels (100 by default) into place on a spring (stiffness 200, damping 20), overshooting by about 4% before it settles. It moves with `x` / `y`, a hardware-accelerated transform.
- `direction` is the direction it moves in: `up` starts below its place.
- Under reduced motion, it doesn't travel: it fades in instead.
- `inView` waits for the element to scroll into view, once by default.
- `<AnimateUIProvider tempo>` paces the default spring.
