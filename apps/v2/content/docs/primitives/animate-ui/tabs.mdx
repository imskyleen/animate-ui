## Usage

```tsx
import {
  Tabs,
  TabsContent,
  TabsContents,
  TabsHighlight,
  TabsHighlightItem,
  TabsList,
  TabsTrigger,
} from '@animate-ui/react/primitives/tabs';

export function Settings() {
  return (
    <Tabs defaultValue="account">
      <TabsHighlight className="absolute inset-0 rounded-md bg-background">
        <TabsList className="flex rounded-lg bg-muted p-1">
          <TabsHighlightItem value="account" className="flex-1">
            <TabsTrigger value="account">Account</TabsTrigger>
          </TabsHighlightItem>
          <TabsHighlightItem value="password" className="flex-1">
            <TabsTrigger value="password">Password</TabsTrigger>
          </TabsHighlightItem>
        </TabsList>
      </TabsHighlight>
      <TabsContents>
        <TabsContent value="account">
          Make changes to your account here.
        </TabsContent>
        <TabsContent value="password">Change your password here.</TabsContent>
      </TabsContents>
    </Tabs>
  );
}
```

Unlike the library tabs, these are Animate UI's own: no Radix UI, Base UI or React Aria underneath. `TabsHighlight` and `TabsHighlightItem` are optional; without them, style the active trigger with `data-state="active"`. Without `defaultValue`, the first trigger is selected.

## Animation

- The highlight slides to the selected trigger on a spring (stiffness 200, damping 25): the new one fades in as it slides from the previous one, which fades out 200ms later ([Highlight](/docs/primitives/animate-ui/highlight)).
- Panels sit side by side and slide to the selected one on a spring (stiffness 300, damping 30); the container's height follows the active panel on the same spring. Inactive panels blur (4px, spring with stiffness 200, damping 25) and are `inert`.
- Keyboard: arrow keys move to the next or previous enabled trigger (wrapping) and select it, Home and End jump to the ends; only the selected trigger is in the Tab order. Keyboard selection animates exactly like a click.
- `<AnimateUIProvider tempo>` paces every spring.
- Under reduced motion, the highlight, panels and height change at once.
