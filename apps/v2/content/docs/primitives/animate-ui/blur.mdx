## Usage

```tsx
import { Blur, Blurs } from '@animate-ui/react/primitives/effects/blur';

export function Hero() {
  return (
    <>
      <Blur>
        <h1>Animated primitives for React</h1>
      </Blur>

      {/* Staggered: each child starts 100ms after the previous one. */}
      <Blurs holdDelay={100}>
        <Card />
        <Card />
        <Card />
      </Blurs>
    </>
  );
}
```

With `asChild`, the animation is applied to your element instead of a wrapping `div`.

## Animation

- The element sharpens from `initialBlur` to `blur` over 600ms with a strong ease-out.
- Under reduced motion, it fades in instead.
- `inView` waits for the element to scroll into view, once by default.
- `<AnimateUIProvider tempo>` paces the default transition.
