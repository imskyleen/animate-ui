## Usage

```tsx
import {
  ScrollingNumber,
  ScrollingNumberContainer,
  ScrollingNumberHighlight,
  ScrollingNumberItems,
} from '@animate-ui/react/primitives/texts/scrolling-number';

export function Score() {
  return (
    <ScrollingNumberContainer number={1000} step={100} itemsSize={40}>
      <ScrollingNumber>
        <ScrollingNumberItems />
      </ScrollingNumber>
      <ScrollingNumberHighlight />
    </ScrollingNumberContainer>
  );
}
```

## Animation

- The strip spins through every step up to `number` over 2s on a strong ease-out: fast through the range, slow as it lands.
- A new `number` retargets the spin from where it is.
- The strip is written by a motion value, without a React render per frame. `onNumberChange` reports the value under the highlight as it passes.
- `<AnimateUIProvider tempo>` paces the default duration.
- Under reduced motion, the wheel lands on the number right away.
- The strip is hidden from screen readers, which read the number once from the container.
