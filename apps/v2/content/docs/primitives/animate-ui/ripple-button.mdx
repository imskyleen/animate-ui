## Usage

```tsx
import {
  RippleButton,
  RippleButtonRipples,
} from '@animate-ui/react/primitives/buttons/ripple';

export function Send() {
  return (
    <RippleButton className="[--ripple-button-ripple-color:white]">
      Send
      <RippleButtonRipples />
    </RippleButton>
  );
}
```

## Animation

- Each click sends a ripple from the pointer: it grows to `scale` while fading out over 0.6s, then is removed. Rapid clicks each get their own ripple.
- Pressing scales the button to `tapScale` (0.97), on Motion's spring for scale (`stiffness: 550, damping: 30`). It doesn't scale on hover, unless you set `hoverScale`.
- `<AnimateUIProvider tempo>` paces the default spring and ripple.
- Under reduced motion, the ripple fades in place without growing, and the button doesn't scale.
