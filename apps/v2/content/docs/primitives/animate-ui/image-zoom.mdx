## Usage

```tsx
import { Image, ImageZoom } from '@animate-ui/react/primitives/effects/image-zoom';

export function ProductPhoto() {
  return (
    <ImageZoom width={320} height={320} aria-label="Product photo, zoomable">
      <Image src="/product.webp" alt="The product" />
    </ImageZoom>
  );
}
```

`Image` renders an `img` by default; pass `as` to use your framework's image component (`as={NextImage}`).

## Animation

- Hovering zooms in to `zoomScale` on a spring, from the point under the pointer; moving the pointer pans the zoom.
- Clicking (or tapping on touch screens) toggles the zoom. The cursor shows whether a click zooms in or out.
- Under reduced motion, the zoom jumps instead of scaling.
