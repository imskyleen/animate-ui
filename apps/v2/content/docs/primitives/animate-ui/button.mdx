## Usage

```tsx
import { Button } from '@animate-ui/react/primitives/buttons/button';

export function Save() {
  return <Button className="rounded-md px-4 py-2">Save</Button>;
}
```

With `asChild`, the animation lands on your own element:

```tsx
<Button asChild>
  <a href="/docs">Docs</a>
</Button>
```

## Animation

- Hovering scales the button to `hoverScale`, pressing to `tapScale`, on Motion's spring for scale (`stiffness: 550, damping: 30`): quick, with a slight overshoot.
- `transition` replaces that spring.
- `<AnimateUIProvider tempo>` paces the default spring.
- Under reduced motion, the button doesn't scale.
