## Usage

```tsx
import { Button } from '@animate-ui/react/primitives/buttons/button';

export function Save() {
  return <Button className="rounded-md px-4 py-2">Save</Button>;
}
```

With `asChild`, the animation lands on your own element:

```tsx
<Button asChild>
  <a href="/docs">Docs</a>
</Button>
```

## Animation

- Hovering scales the button to `hoverScale`, pressing to `tapScale`, both in 150ms on a strong ease-out.
- `<AnimateUIProvider tempo>` paces the press feedback.
- Under reduced motion, the button doesn't scale.
