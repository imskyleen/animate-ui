## Usage

```tsx
import { SlidingText } from '@animate-ui/react/primitives/texts/sliding';

export function NavLink() {
  return (
    <a href="/docs">
      <SlidingText text="Docs" />
    </a>
  );
}
```

## Animation

- The text sits in a box that clips it. On `hover`, it slides out by its own height plus a small gap (0.6em) while a copy of it slides in from the other side, in 0.25s on an ease-in-out.
- `direction="down"` sends the text down and brings the copy from above; `direction="up"` does the opposite.
- With `trigger="hover"`, leaving slides it back the other way. Left halfway, it turns back from where it is.
- With `trigger="click"`, each click slides it once more in the same direction. A click during a slide carries it on without a jump.
- The box keeps the text's size and baseline, so it fits inside a line, a link or a button. A text on several lines slides as a whole.
- Inside a link or a button (or an element with `role="button"` or `role="link"`), the whole control slides it: hovering or clicking its padding counts, not just the text.
- `<AnimateUIProvider tempo>` paces the default transition.
- Under reduced motion, the text doesn't move.
- Screen readers read the text once: the copy is hidden from them.
