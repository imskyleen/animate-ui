## Usage

```tsx
import { Magnetic } from '@animate-ui/react/primitives/effects/magnetic';

export function CallToAction() {
  return (
    <Magnetic strength={0.4} range={160}>
      <button>Come closer</button>
    </Magnetic>
  );
}
```

## Animation

- Within `range` pixels of its center, the element moves toward the pointer: the closer, the stronger the pull (`strength`). It springs back when the pointer leaves the range.
- The pull follows the pointer on a spring, so it's interruptible and never jumps. It moves with a hardware-accelerated `transform`.
- The pointer is only tracked while the element is on screen. With `onlyOnHover`, only while it's hovered.
- Off on touch screens (`disableOnTouch`), where there is no pointer to follow.
- `<AnimateUIProvider tempo>` paces the default spring.
- Under reduced motion, the element stays in place.
