## Usage

```tsx
import {
  Cursor,
  CursorContainer,
  CursorFollow,
  CursorProvider,
} from '@animate-ui/react/primitives/cursor';

export function Canvas() {
  return (
    <div className="relative h-72">
      <CursorProvider>
        <CursorContainer>
          <Cursor>
            <ArrowIcon />
          </Cursor>
          <CursorFollow side="bottom" align="end">
            <span>Designer</span>
          </CursorFollow>
        </CursorContainer>
      </CursorProvider>
    </div>
  );
}
```

By default, the cursor lives in the parent of `CursorContainer`. With `global`, it replaces the pointer on the whole page.

## Animation

- Entering the area hides the native pointer and fades the cursor in (600ms); leaving fades it out (400ms) and restores the pointer.
- `Cursor` sticks to the pointer. `CursorFollow` trails it on a spring, so it feels attached without being rigid, and appears at the pointer instead of flying in.
- The position is driven by motion values with a hardware-accelerated `transform`: moving the pointer never re-renders React.
- Touch pointers are ignored: a custom cursor only makes sense for pointers that hover.
- `<AnimateUIProvider tempo>` paces the fades and the follow spring.
- Under reduced motion, `CursorFollow` sticks to the pointer too.

### useCursor

Returns the cursor state: `cursorX` and `cursorY` motion values, `active`, `global`, and `cursorPos` (a snapshot of the position when read).
