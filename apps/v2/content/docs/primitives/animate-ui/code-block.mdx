## Installation

<Installation />

The code is highlighted with [Shiki](https://shiki.style), a peer dependency of this primitive, loaded on demand:

```bash
npm install shiki
```

## Usage

```tsx
import { CodeBlock } from '@animate-ui/react/primitives/code-block';

export function Snippet() {
  return (
    <CodeBlock
      code="console.log('Hello, world!');"
      lang="javascript"
      writing
      duration={2000}
    />
  );
}
```

The block renders Shiki's `<pre>` inside a div. Style it through that div (`[&_pre]:…`, `[&_.line]:…`); `data-writing` and `data-done` let you show a cursor while it types.

## Animation

- With `writing`, the code appears one character at a time, evenly over `duration` (after `delay`), and the block, or `scrollContainerRef`, scrolls smoothly to follow the last line.
- With `inView`, writing starts when the block scrolls into view.
- Under reduced motion, the whole code is shown at once (`onDone` is still called).
