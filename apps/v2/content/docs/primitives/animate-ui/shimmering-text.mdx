## Usage

```tsx
import { ShimmeringText } from '@animate-ui/react/primitives/texts/shimmering';

export function Loading() {
  return <ShimmeringText text="Thinking…" />;
}
```

## Animation

- Each letter pulses from `color` to `shimmeringColor` and back, one after the other, in a loop. `wave` also lifts each letter as the glint passes.
- Emoji and accented letters stay whole.
- The shimmer pauses off screen and in a hidden tab.
- Under reduced motion, the text holds still in its `color`.
- Screen readers read the text once, not letter by letter.
