## Usage

```tsx
import { Particles, ParticlesEffect } from '@animate-ui/react/primitives/effects/particles';

export function LikeButton({ liked }: { liked: boolean }) {
  return (
    <Particles animate={liked}>
      <button>Like</button>
      <ParticlesEffect className="size-1 rounded-full bg-red-500" />
    </Particles>
  );
}
```

The burst plays when `animate` becomes `true`. Remount `Particles` (with a `key`) to replay it.

## Animation

- `count` particles shoot out from a point on one side of the element, spread over `spread` degrees, then shrink and fade out (800ms, ease-out). Each starts `holdDelay` seconds after the previous one.
- Particles are absolutely positioned: the layout never moves.
- With `inView`, the burst waits for the element to be on screen.
- Under reduced motion, the burst is skipped: it's decorative.
