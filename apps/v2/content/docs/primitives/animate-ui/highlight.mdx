## Usage

```tsx
import { Highlight } from '@animate-ui/react/primitives/effects/highlight';

export function Segmented() {
  return (
    <Highlight defaultValue="overview" className="rounded-full bg-accent">
      <button data-value="overview">Overview</button>
      <button data-value="activity">Activity</button>
      <button data-value="settings">Settings</button>
    </Highlight>
  );
}
```

Each child is wrapped in a `HighlightItem`. Its value comes from `value`, `id`, `data-value` or the child's `id`. Items receive `data-active="true"` when highlighted, for styling.

### Controlled items

With `controlledItems`, place `HighlightItem`s anywhere inside `Highlight` instead of as direct children.

```tsx
<Highlight controlledItems hover className="rounded-md bg-accent">
  <nav>
    <HighlightItem value="docs">
      <a href="/docs">Docs</a>
    </HighlightItem>
    <HighlightItem value="blog">
      <a href="/blog">Blog</a>
    </HighlightItem>
  </nav>
</Highlight>
```

### Modes

- `children` (default): the highlight is rendered inside the active item and moves with a shared layout animation. Prefer it in most cases.
- `parent`: the highlight is rendered once in a container, and its position and size spring to the active item. Use it when the items clip or stack in a way that hides the `children` highlight.

```tsx
<Highlight mode="parent" containerClassName="flex" className="bg-accent">
  <div data-value="a">A</div>
  <div data-value="b">B</div>
</Highlight>
```

## Animation

- In `children` mode, the highlight slides to the new item on a spring (stiffness 500, damping 40) with a shared layout animation: the new one fades in as it slides from the previous one, which follows it and fades out after `exitDelay` (200ms). It fades in when nothing was highlighted.
- In `parent` mode, a single highlight springs its top, left, width and height to the active item, fades in when it appears, and fades out `exitDelay` after the last item is left.
- Leaving with `hover` fades it out after `exitDelay`, so moving between items doesn't flicker.
- `hover` only applies to pointers that can hover (mouse, trackpad): touch taps never leave a highlight stuck.
- In `parent` mode, `forceUpdateBounds` measures the active item on every frame, so the highlight follows it whatever moves it (scrolling, resizing, an animated container).
- `<AnimateUIProvider tempo>` paces the transition and `exitDelay`.
- Under reduced motion, the highlight jumps to the new item and only fades.
