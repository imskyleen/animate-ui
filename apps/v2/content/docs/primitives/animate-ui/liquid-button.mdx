## Usage

Set the two colours with CSS variables:

```tsx
import { LiquidButton } from '@animate-ui/react/primitives/buttons/liquid';

export function Start() {
  return (
    <LiquidButton className="[--liquid-button-background-color:var(--muted)] [--liquid-button-color:var(--primary)] hover:text-primary-foreground">
      Get started
    </LiquidButton>
  );
}
```

## Animation

- On hover, a `fillHeight` line of `--liquid-button-color` slides in along the bottom, then rises to fill the button, each step taking `delay` (a CSS transition). Leaving, the fill variables ease back over 0.3s, then the text colour and the liquid drain in reverse.
- Hovering scales the button to `hoverScale` in a 0.3s ease-out; pressing scales it to `tapScale`, and releasing or leaving springs it back (Motion's spring for scale, `stiffness: 550, damping: 30`).
- `transition` replaces the press, release and leave transitions.
- `<AnimateUIProvider tempo>` paces the Motion transitions (not the CSS `delay`).
- Under reduced motion, the button fills without scaling.

### LiquidButton

<TypeTable
  type={{
    delay: {
      description: 'Duration of each step of the fill (a CSS time).',

    fillHeight: {
      description:
        'Height of the line that slides in before the fill rises (a CSS length).',
