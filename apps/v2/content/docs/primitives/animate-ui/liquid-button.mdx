## Usage

Set the two colours with CSS variables:

```tsx
import { LiquidButton } from '@animate-ui/react/primitives/buttons/liquid';

export function Start() {
  return (
    <LiquidButton className="[--liquid-button-background-color:var(--muted)] [--liquid-button-color:var(--primary)] hover:text-primary-foreground">
      Get started
    </LiquidButton>
  );
}
```

## Animation

- On hover, a `fillHeight` line of `--liquid-button-color` slides in along the bottom, then rises to fill the button, each step taking `delay` (a CSS transition). Leaving drains it in reverse.
- Hovering scales the button to `hoverScale`, pressing to `tapScale`, in 150ms.
- `<AnimateUIProvider tempo>` paces the press feedback.
- Under reduced motion, the button fills without scaling.
