## Usage

Bring your own theme state, as with [Theme Toggler](/docs/primitives/animate-ui/theme-toggler). With [next-themes](https://github.com/pacocoursey/next-themes):

```tsx
import { useTheme } from 'next-themes';
import {
  ThemeTogglerButton,
  ThemeTogglerButtonIcon,
  type Resolved,
  type ThemeSelection,
} from '@animate-ui/react/primitives/buttons/theme-toggler';

export function ThemeButton() {
  const { theme, resolvedTheme, setTheme } = useTheme();

  return (
    <ThemeTogglerButton
      theme={theme as ThemeSelection}
      resolvedTheme={resolvedTheme as Resolved}
      setTheme={setTheme}
      modes={['light', 'dark']}
      aria-label="Toggle theme"
    >
      <ThemeTogglerButtonIcon light={<SunIcon />} dark={<MoonIcon />} />
    </ThemeTogglerButton>
  );
}
```

Each click switches to the next theme of `modes`. When `modes` leave out `system`, the button shows the theme actually displayed, and a system theme counts as the one it resolves to. Read the state in your own parts with `useThemeTogglerButton()`.

## Animation

- A click wipes the new theme across the page in `direction`, over 700ms with an `ease-in-out` ([Theme Toggler](/docs/primitives/animate-ui/theme-toggler)'s View Transition).
- The icon swaps as the wipe starts: the old one shrinks to half its size into a light blur (`blur(2px)`) as it fades out, while the new one grows out of it, over 0.15s with an ease-out (`cubic-bezier(0.23, 1, 0.32, 1)`). Icons only swap once the button is used: on mount, and when the theme becomes known after hydrating, the icon shows at rest.
- Pressing scales the button to `tapScale` (0.97), on Motion's spring for scale (`stiffness: 550, damping: 30`). It doesn't scale on hover, unless you set `hoverScale`.
- `<AnimateUIProvider tempo>` paces the wipe, the swap and the press spring.
- Under reduced motion, the theme changes at once without the wipe, the icons crossfade without scaling or blurring, and the button doesn't scale.
