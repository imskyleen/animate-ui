## Usage

```tsx
import { CountingNumber } from '@animate-ui/react/primitives/texts/counting-number';

export function Stat() {
  return <CountingNumber number={2025} inView />;
}
```

A new `number` retargets the running count instead of restarting it.

## Animation

- Counts from `fromNumber` to `number` over 3s on a strong ease-out: it races through the bulk of the range and slows on the last digits, so the final value is readable as it lands.
- The ticking value is written to the DOM directly, without a React render per frame.
- Spring options in `transition` (`stiffness`, `damping`, `bounce`, `visualDuration`…) animate the count as a spring.
- `<AnimateUIProvider tempo>` paces the default duration.
- Under reduced motion, the number shows its target right away.
- Screen readers read the target value once, never the ticking values.
