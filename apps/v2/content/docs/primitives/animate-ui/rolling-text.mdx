## Usage

```tsx
import { RollingText } from '@animate-ui/react/primitives/texts/rolling';

export function Title() {
  return <RollingText text="Rolling Text" inView />;
}
```

## Animation

- Each letter turns over in 3D (`rotateX`): its front copy rolls away from its upper quarter while the back copy rolls in from its baseline 0.3s later, 0.5s each on an ease-out.
- Letters start 0.1s apart (the `delay` of `transition`). Words never break in the middle; emoji and accented letters stay whole.
- Once rolled, the text stays rolled: leaving the viewport doesn't reverse it.
- `<AnimateUIProvider tempo>` paces the default transition and the 0.3s offset.
- Under reduced motion, the letters sit in their final state at once.
- Screen readers read the text once, not letter by letter.
