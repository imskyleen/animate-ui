## Usage

```tsx
import {
  FlipButton,
  FlipButtonBack,
  FlipButtonFront,
} from '@animate-ui/react/primitives/buttons/flip';

export function Subscribe() {
  return (
    <FlipButton from="top">
      <FlipButtonFront>Subscribe</FlipButtonFront>
      <FlipButtonBack>It's free</FlipButtonBack>
    </FlipButton>
  );
}
```

## Animation

- On hover, the front face rotates away and the back face rotates in from `from`, on a spring (0.6s, a hint of bounce). Leaving flips it back.
- The faces are stacked in the same grid cell: the button takes the size of the larger one.
- Pressing scales the button to `tapScale` in 150ms.
- `<AnimateUIProvider tempo>` paces the flip and the press.
- Under reduced motion, the faces crossfade without rotating or sliding, and the button doesn't scale.
