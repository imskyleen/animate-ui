## Usage

```tsx
import { Effect, Effects } from '@animate-ui/react/primitives/effects/effect';

export function Hero() {
  return (
    <>
      <Effect fade blur slide zoom>
        <h1>Animated primitives for React</h1>
      </Effect>

      {/* Staggered: each child starts 100ms after the previous one. */}
      <Effects holdDelay={100} fade blur slide zoom>
        <Card />
        <Card />
        <Card />
      </Effects>
    </>
  );
}
```

With `asChild`, the animation is applied to your element instead of a wrapping `div`.

## Animation

- Pick any combination of `fade`, `blur`, `slide` and `zoom`. `true` uses each effect's defaults; an object customizes it.
- Everything animates together on one spring (stiffness 200, damping 20). Slide (`x` / `y`) and zoom (`scale`) are hardware-accelerated transforms.
- Under reduced motion, there is no travel or scale: the fade and the blur still play.
- `inView` waits for the element to scroll into view, once by default.
- `<AnimateUIProvider tempo>` paces the default spring.
