## Usage

```tsx
import { SplittingText } from '@animate-ui/react/primitives/texts/splitting';

export function Title() {
  return <SplittingText text="Splitting Text" type="words" inView />;
}
```

Pass an array of lines with `type="lines"`:

```tsx
<SplittingText
  type="lines"
  text={['Introducing Splitting Text', 'Made with Motion.']}
/>
```

## Animation

- Each piece fades and slides in from the right over 0.7s on a strong ease-out, 0.05s apart for characters, 0.2s for words, 0.3s for lines.
- `initial`, `animate` and `transition` customise every piece. The defaults use a `transform` string: override `initial` and `animate` together.
- Words never break in the middle; emoji and accented letters stay whole.
- `<AnimateUIProvider tempo>` paces the default duration.
- Under reduced motion (or with `disableAnimation`), every piece is in place at once.
- Screen readers read the text once, not piece by piece.
