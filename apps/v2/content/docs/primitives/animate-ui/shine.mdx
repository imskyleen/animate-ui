## Usage

```tsx
import { Shine } from '@animate-ui/react/primitives/effects/shine';

export function GetStarted() {
  return (
    <Shine asChild loop loopDelay={1500} color="white" opacity={0.4}>
      <button>Get started</button>
    </Shine>
  );
}
```

`enableOnHover` and `enableOnTap` play the shine on interaction instead of right away.

## Animation

- A skewed gradient sweeps from left to right over `duration` (1.2s), clipped to the element. It never catches the pointer.
- With `loop`, it sweeps again after `loopDelay`. With `enableOnHover` and `loop`, it keeps sweeping while hovered.
- It moves with a hardware-accelerated `transform`.
- Under reduced motion, there is no shine: it's decorative.
