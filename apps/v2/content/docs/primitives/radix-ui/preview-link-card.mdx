## Installation

<Installation />

It's built on Radix UI's Hover Card, a peer dependency of this primitive:

```bash
npm install radix-ui
```

## Usage

```tsx
import {
  PreviewLinkCard,
  PreviewLinkCardContent,
  PreviewLinkCardImage,
  PreviewLinkCardPortal,
  PreviewLinkCardTrigger,
} from '@animate-ui/react/primitives/radix-ui/preview-link-card';

export function DocsLink() {
  return (
    <PreviewLinkCard href="https://animate-ui.com/docs">
      <PreviewLinkCardTrigger>Animate UI Docs</PreviewLinkCardTrigger>
      <PreviewLinkCardPortal>
        <PreviewLinkCardContent>
          <PreviewLinkCardImage alt="Animate UI Docs" />
        </PreviewLinkCardContent>
      </PreviewLinkCardPortal>
    </PreviewLinkCard>
  );
}
```

The screenshot comes from [Microlink](https://microlink.io)'s API, as in Animate UI v1: it captures `href` on a mobile viewport three times the image's size. Pass `src` to show an image of your own instead. Either way, it's preloaded (a `<link rel="preload">` in the head) as soon as the card mounts, so it's there when the card opens.

## Animation

It is Animate UI's [Hover Card](/docs/primitives/radix-ui/hover-card), so the card moves exactly like it:

- **Content** grows from 0.8 and fades in, from the trigger (`--radix-hover-card-content-transform-origin`), on a spring (stiffness 400, damping 29) that overshoots a little before it settles.
- It opens after Radix's `openDelay` (700ms by default) and, once its `closeDelay` is over (300ms), closes the same way: it shrinks back to 0.8 on the same spring while it fades out, then unmounts.
- Reopening while it closes picks up from where it is, on the same spring.
- Radix only opens it for mouse-like pointers: a tap on a touch screen follows the link, nothing sticks.
- With `followCursor` on the Root, the card leans towards the pointer while it moves over the trigger, on a spring (stiffness 200, damping 17), as in v1.
- Under reduced motion, it only fades (no scale).

## API Reference

The parts take the props of Animate UI's [Hover Card](/docs/primitives/radix-ui/hover-card#api-reference), so those of [Radix UI's Hover Card](https://www.radix-ui.com/primitives/docs/components/hover-card#api-reference), plus the ones below.

### PreviewLinkCard

Hover Card's [Root](/docs/primitives/radix-ui/hover-card#root) (`openDelay`, `closeDelay`, `open`, `followCursor`…), plus:

### PreviewLinkCardTrigger

Hover Card's [Trigger](https://www.radix-ui.com/primitives/docs/components/hover-card#trigger): a link, to the Root's `href` unless it has its own.

### PreviewLinkCardPortal, PreviewLinkCardArrow

Hover Card's [Portal](https://www.radix-ui.com/primitives/docs/components/hover-card#portal) and [Arrow](https://www.radix-ui.com/primitives/docs/components/hover-card#arrow).

### PreviewLinkCardContent

Hover Card's [Content](/docs/primitives/radix-ui/hover-card#content) (`transition`, `exitTransition`, `side`, `align`…), rendered as a link to the Root's `href`: it is the card, and its `className` styles it. With `asChild`, your element is rendered instead.

### usePreviewLinkCard

Returns the card's `href`, its image's `src`, `width` and `height`: for an image of your own.
