## Usage

Import the primitive from Animate UI instead of Radix UI. Everything else stays the same.

```tsx
import { Select } from '@animate-ui/react/primitives/radix-ui';

export function FontPicker() {
  return (
    <Select.Root defaultValue="geist">
      <Select.Trigger aria-label="Font">
        <Select.Value placeholder="Choose a font" />
        <Select.Icon />
      </Select.Trigger>
      <Select.Portal>
        <Select.Content position="popper" sideOffset={4}>
          <Select.Viewport>
            <Select.Item value="inter">
              <Select.ItemText>Inter</Select.ItemText>
            </Select.Item>
            <Select.Item value="geist">
              <Select.ItemText>Geist</Select.ItemText>
              <Select.ItemIndicator>✓</Select.ItemIndicator>
            </Select.Item>
          </Select.Viewport>
        </Select.Content>
      </Select.Portal>
    </Select.Root>
  );
}
```

Coming from the `@radix-ui/react-select` package? Use the subpath: `import * as SelectPrimitive from '@animate-ui/react/primitives/radix-ui/select'`.

## Animation

Radix's Select has no Animate UI v1 counterpart: it moves like v1's Dropdown Menu.

- **Content** with `position="popper"` fades and scales in from 0.9, from the trigger (`--radix-select-content-transform-origin`), in 200ms (`{ duration: 0.2, ease: [0.23, 1, 0.32, 1] }`, a strong ease-out), and closes the same way before it unmounts.
- With `position="item-aligned"` (Radix's default), the list is laid over the trigger with the selected item lined up on the value, so it only fades: there is no side to grow from, and a scale would skew Radix's measurement.
- **The highlight**: one surface glides behind the highlighted item on a spring (stiffness 350, damping 35), following the pointer and the arrow keys alike, like v1's menu highlight. The new copy fades in as it moves; the previous one goes along and fades out 200ms later. When the pointer leaves the list, it stays on the last item. It wears the item's own highlighted background (`focus:bg-accent`, `data-highlighted:bg-accent`…), read from your styles: the item's background is cleared while it's highlighted; its text colors stay.
- **ItemIndicator**: choosing another item moves the check there while the list closes, like v1's radio indicator.
- Reopening while the list is closing picks up from where it is. A closing list is `inert`, so it can't be clicked through.
- After the exit, the closed list goes back to Radix, which keeps the items mounted off-screen: the trigger keeps its label, typeahead on the closed trigger and native form submission still work.
- With `forceMount` (on `Content` or `Portal`), the closed list stays mounted, transparent and `inert`. Like in Radix, a mounted list keeps the select modal.
- Open from the start (`defaultOpen`), the list plays its entrance on page load.
- Under reduced motion, nothing scales or glides: the list and the highlight only fade.

## API Reference

Every part takes exactly the props of [Radix UI's Select](https://www.radix-ui.com/primitives/docs/components/select#api-reference). Animate UI adds the animation props below.

### Root, Trigger, Value, Icon, Portal, Viewport, ItemText, Group, Label, Separator, ScrollUpButton, ScrollDownButton, Arrow

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/select#root) only. They are not animated.

### Item

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/select#item) only. It takes part in the highlight; it needs nothing more.

### Content

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/select#content), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the opening, and of the closing unless `exitTransition` is set.',

      default: '{ duration: 0.2, ease: [0.23, 1, 0.32, 1] }',

    exitTransition: {
      description: 'Transition of the closing.',
      type: 'Transition',

    },
  }}
/>

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/select#itemindicator), plus:
