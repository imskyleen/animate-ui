## Usage

Import the primitive from Animate UI instead of Radix UI. Everything else stays the same.

```tsx
import { Checkbox } from '@animate-ui/react/primitives/radix-ui';

export function Terms() {
  return (
    <label className="flex items-center gap-2">
      <Checkbox.Root defaultChecked>
        <Checkbox.Indicator>
          <CheckIcon />
        </Checkbox.Indicator>
      </Checkbox.Root>
      Accept terms and conditions
    </label>
  );
}
```

Coming from the `@radix-ui/react-checkbox` package? Use the subpath: `import * as CheckboxPrimitive from '@animate-ui/react/primitives/radix-ui/checkbox'`.

### Check animation

The check draws itself by default. With `animation="pop"` on the Indicator, it pops in from half its size instead, and shrinks back out:

```tsx
<Checkbox.Root defaultChecked>
  <Checkbox.Indicator animation="pop">
    <CheckIcon />
  </Checkbox.Indicator>
</Checkbox.Root>
```

The same demo with `checkAnimation="pop"` (its Controls switch it back to `draw`):

To pop every check of your app at once (checkboxes, menus, selects, comboboxes), set `checkAnimation="pop"` on an [`AnimateUIProvider`](/docs/installation#choose-how-checks-animate-optional) instead.

## Animation

The motion of Animate UI v1's checkbox:

- **Indicator**: the check draws itself. Its stroke (`pathLength`) and its opacity go from 0 to 1 together in 0.3s, after a 0.2s delay, on Motion's default ease-out (v1's delay and curve, drawn a little slower than v1's 0.2s). Unchecking erases it in 0.3s, without the delay, then the indicator unmounts, as in Radix. The indicator element itself never moves: its content animates, so your layout and classes stay as they are. Content that isn't an SVG shape fades the same way.
- With `animation="pop"` (or `checkAnimation="pop"` on an `AnimateUIProvider`), the check pops instead: after the same 0.2s, it springs in from half its size out of a 2px blur (stiffness 500, damping 24, a little past its size), and shrinks back into its blur in 0.15s when the box is unchecked. Its stroke stays whole. The demo's Controls switch between the two.
- **Root** doesn't move: unlike v1's, it doesn't scale when pressed or hovered. The check (and, in the demo, the box's fill) answers the click.
- In the demo, the box's fill is a layer of its own (`before:` in its classes) that grows from 70% while it fades in, in 300ms, and shrinks back as it fades out: the check draws over a box that is nearly full. The layer covers the box's border (`before:-inset-px`) and the border keeps its color, so no outline rings the growing fill. It's CSS, so copy the classes for the same effect; under reduced motion the layer only fades.
- A box that is checked when it mounts draws its check too, as v1's did. The indicator stays hidden until then, so a server-rendered page doesn't flash the check first.
- Checking with Space animates the same way: the state changes at once, the animation never delays it.
- Toggling again mid-animation turns back from where the check is.
- `indeterminate` shows the indicator like `checked`. An icon swapped for the indeterminate state draws without the delay, as v1's indeterminate line did.
- Under reduced motion, the check only fades, drawn or popped (its stroke stays whole, nothing scales).
- With `forceMount`, the unchecked indicator stays in the DOM with its check hidden.
- The box's own colours are the component's CSS: shadcn/ui's `transition-colors` fades them.

## API Reference

Every part takes exactly the props of [Radix UI's Checkbox](https://www.radix-ui.com/primitives/docs/components/checkbox#api-reference). Animate UI adds the animation props below. With `asChild`, a part renders your element with Radix's behaviour, without the animation.

### Root

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/checkbox#root) only. It isn't animated.

### Indicator

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/checkbox#indicator), plus:

  }}
/>

`AnimateUIProvider`'s `tempo` scales these transitions with everything else.
