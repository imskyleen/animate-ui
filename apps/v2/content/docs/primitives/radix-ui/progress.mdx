## Usage

Import the primitive from Animate UI instead of Radix UI. Everything else stays the same.

```tsx
import { Progress } from '@animate-ui/react/primitives/radix-ui';

export function Upload({ value }: { value: number }) {
  return (
    <Progress.Root value={value} className="h-2 overflow-hidden rounded-full">
      <Progress.Indicator
        className="size-full bg-primary"
        style={{ transform: `translateX(-${100 - value}%)` }}
      />
    </Progress.Root>
  );
}
```

Coming from the `@radix-ui/react-progress` package? Use the subpath: `import * as ProgressPrimitive from '@animate-ui/react/primitives/radix-ui/progress'`.

## Animation

The motion of Animate UI v1's progress:

- **Indicator** springs to each new value (stiffness 300, damping 35: most of the way in ~230ms and settled by ~550ms, like [Motion UI's progress bar](https://motion.dev/ui/components/progress-bar), with no jump at the end; no overshoot, which would uncover the start of the track). Radix leaves the indicator's position to you: shadcn/ui moves it with `style={{ transform: translateX(-…%) }}`, the `x` v1 animated. Animate UI animates that translation instead of jumping to it, as an `x` that keeps its momentum when a new value arrives mid-way.
- It starts at its value on mount, with no animation.
- shadcn/ui's `transition-all` on the indicator would run on top of Motion: the CLI removes it.
- Under reduced motion, the indicator jumps to each value.

## API Reference

Every part takes exactly the props of [Radix UI's Progress](https://www.radix-ui.com/primitives/docs/components/progress#api-reference). Animate UI adds the animation props below.

### Root

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/progress#root) only.

### Indicator

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/progress#indicator), plus:

<TypeTable

`AnimateUIProvider`'s `tempo` scales these transitions with everything else.
