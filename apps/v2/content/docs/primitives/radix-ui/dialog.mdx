## Usage

Import the primitive from Animate UI instead of Radix UI. Everything else stays the same.

```tsx
import { Dialog } from '@animate-ui/react/primitives/radix-ui';

export function EditProfile() {
  return (
    <Dialog.Root>
      <Dialog.Trigger>Edit profile</Dialog.Trigger>
      <Dialog.Portal>
        <Dialog.Overlay />
        <Dialog.Content>
          <Dialog.Title>Edit profile</Dialog.Title>
          <Dialog.Description>
            Make changes to your profile here.
          </Dialog.Description>
          <Dialog.Close>Save</Dialog.Close>
        </Dialog.Content>
      </Dialog.Portal>
    </Dialog.Root>
  );
}
```

Coming from the `@radix-ui/react-dialog` package? Use the subpath: `import * as DialogPrimitive from '@animate-ui/react/primitives/radix-ui/dialog'`.

## Sheet

shadcn/ui's Sheet is the same primitive: its content carries `data-side`, and the Dialog then slides it in from that edge, fading in, like Animate UI v1's Sheet, instead of tipping it in. Add it with `shadcn add sheet`, then animate it with `animate-ui animate sheet`.

## Animation

Animate UI v1's dialog motion, with a smoother overlay and a quicker exit.

- **Overlay** fades in from nothing to what its classes set: its background color deepens while its backdrop filter grows, so the page behind blurs progressively from 0 (fading its opacity would cross-fade the sharp page with an already blurred one). In 400ms on CSS's `ease` (`cubic-bezier(0.25, 0.1, 0.25, 1)`), which starts and lands gently, so the page never changes all at once, on the first frame or on the last; it clears the same way in 250ms once the content is dismissed. Its blur grows as it's seen: the eye sees most of a blur in its first pixel, so its radius rises slowly at first, and what's seen of the blur keeps pace with the tint.
- **Content** tips forward into place, around its center: it starts from `perspective(500px) rotateX(-20deg) scale(0.8)`, transparent and blurred (4px), and comes upright and sharp on a spring (stiffness 150, damping 25), fading in ahead of it (400ms on a soft ease-out), and ahead of the overlay: it's there first, then it settles. Dismissed, it goes back the way it came, at once, quicker and speeding away (0.2s, a steady push from half its average speed to one and a half), out of sight just before the overlay has cleared, then unmounts.
- `from` picks the edge the content tips from, as in v1: `top` by default (`rotateX(-20deg)`), `bottom` (`rotateX(20deg)`), `left` (`rotateY(20deg)`) or `right` (`rotateY(-20deg)`) (a sheet, with `data-side`, slides from its side instead).
- With `data-side="top" | "right" | "bottom" | "left"` (shadcn/ui's Sheet), the content slides in from that edge by its own size and fades in, in 0.4s on a soft ease-out (`cubic-bezier(0.215, 0.61, 0.355, 1)`): it answers at once and slows down all the way in. Unlike a drawer it doesn't go past its rest: held against the screen's edge, it would open a gap there. Dismissed, it leaves like a dialog, at once, quicker than it came and speeding off its edge (0.2s, a steady push), fading out.
- Each part leaves its own way unless you set its `exitTransition`: the overlay clears in 250ms, a dialog or a sheet speeds away in 0.2s.
- Radix keeps the Overlay and the Content mounted while they exit. Clicks go through to the page as soon as the dialog closes, and focus returns to the trigger once the exit is over.
- Reopening while it closes picks up from where it is.
- Opening from the keyboard animates the same way; focus moves into the dialog at once.
- With `forceMount` (on the Portal, Overlay or Content), the closed dialog stays in the DOM: it plays its exit, then is hidden and `inert`.
- A Content rendered without a Portal animates on its own, and `asChild` makes your element the animated one.
- Under reduced motion, the content fades and un-blurs without tilting, scaling or sliding.
- `AnimateUIProvider tempo` scales every duration and spring.

## API Reference

Every part takes exactly the props of [Radix UI's Dialog](https://www.radix-ui.com/primitives/docs/components/dialog#api-reference). Animate UI adds the animation props below.

### Root, Trigger, Portal, Title, Description, Close

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/dialog#root) only. They are not animated.

### Overlay

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/dialog#overlay), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the fade in (background color and backdrop filter).',
      type: 'Transition',
      default: '{ duration: 0.4, ease: [0.25, 0.1, 0.25, 1] }',
    },
    exitTransition: {
      description: 'Transition of the fade out.',
      type: 'Transition',
      default: '{ duration: 0.25, ease: [0.25, 0.1, 0.25, 1] }',
    },
  }}
/>

### Content

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/dialog#content), plus:

<TypeTable
  type={{
    from: {
      description:
        'The edge the content tips from as it comes in, as in v1. Ignored by a sheet (data-side).',
      type: "'top' | 'bottom' | 'left' | 'right'",
      default: "'top'",
    },
    transition: {
      description:
        'Transition of the opening. One you pass drives its fade too.',
      type: 'Transition',
      default:
        "{ type: 'spring', stiffness: 150, damping: 25, opacity: { duration: 0.4, ease: [0.215, 0.61, 0.355, 1] } }; with data-side: { duration: 0.4, ease: [0.215, 0.61, 0.355, 1] }",
    },
    exitTransition: {
      description: 'Transition of the closing.',
      type: 'Transition',
      default: '{ duration: 0.2, ease: [0.33, 0.17, 0.67, 0.5] }',
    },
  }}
/>
