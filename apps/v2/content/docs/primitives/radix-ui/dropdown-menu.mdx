## Usage

Import the primitive from Animate UI instead of Radix UI. Everything else stays the same.

```tsx
import { DropdownMenu } from '@animate-ui/react/primitives/radix-ui/dropdown-menu';

export function AccountMenu() {
  return (
    <DropdownMenu.Root>
      <DropdownMenu.Trigger>Account</DropdownMenu.Trigger>
      <DropdownMenu.Portal>
        <DropdownMenu.Content sideOffset={4}>
          <DropdownMenu.Item>Profile</DropdownMenu.Item>
          <DropdownMenu.Item>Billing</DropdownMenu.Item>
          <DropdownMenu.Separator />
          <DropdownMenu.Item>Log out</DropdownMenu.Item>
        </DropdownMenu.Content>
      </DropdownMenu.Portal>
    </DropdownMenu.Root>
  );
}
```

The `import * as DropdownMenuPrimitive from '@radix-ui/react-dropdown-menu'` style works too.

## Animation

- **Content** fades in and scales up from 0.95 over 600ms with a strong ease-out, growing from the trigger (`--radix-dropdown-menu-content-transform-origin`, set inline so it works without styles). It closes in 400ms, then unmounts.
- **SubContent** grows from the side of its trigger (same origin variable, which Radix sets for submenus), in 400ms both ways: submenus open often.
- Moving the highlight with the arrow keys is never animated: items keep their own CSS highlight, which changes on the same frame.
- When the menu closes with focus inside, focus goes back to the trigger at once instead of after the exit, and the leaving menu ignores the pointer and can't dismiss anything.
- **ItemIndicator** (the check and the radio dot) fades in over 600ms when an item gets checked and out in 400ms. Items already checked when the menu opens show at once.
- With `forceMount` (on the Content or the Portal), the closed content stays in the DOM: it plays its exit, then is hidden (`visibility: hidden`).
- Under reduced motion, everything only fades.

## API Reference

Every part takes exactly the props of [Radix UI's Dropdown Menu](https://www.radix-ui.com/primitives/docs/components/dropdown-menu#api-reference). Animate UI adds the animation props below.

### Root, Trigger, Portal, Group, Label, Item, CheckboxItem, RadioGroup, RadioItem, Separator, Arrow, Sub, SubTrigger

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/dropdown-menu#api-reference) only. They are not animated.

### Content

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/dropdown-menu#content), plus:

<TypeTable
  type={{
    transition: {
      description: 'Transition of the opening.',
      type: 'Transition',
      default: 'transition.dropdown (600ms, ease-out)',
    },
    exitTransition: {
      description: 'Transition of the closing.',
      type: 'Transition',
      default: 'transition.exit (400ms, ease-out)',
    },
  }}
/>

### SubContent

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/dropdown-menu#subcontent), plus:

      description: 'Transition of the closing.',
