## Usage

Import the primitive from Animate UI instead of Radix UI. Everything else stays the same.

```tsx
import { DropdownMenu } from '@animate-ui/react/primitives/radix-ui';

export function AccountMenu() {
  return (
    <DropdownMenu.Root>
      <DropdownMenu.Trigger>Account</DropdownMenu.Trigger>
      <DropdownMenu.Portal>
        <DropdownMenu.Content sideOffset={4}>
          <DropdownMenu.Item>Profile</DropdownMenu.Item>
          <DropdownMenu.Item>Billing</DropdownMenu.Item>
          <DropdownMenu.Separator />
          <DropdownMenu.Item>Log out</DropdownMenu.Item>
        </DropdownMenu.Content>
      </DropdownMenu.Portal>
    </DropdownMenu.Root>
  );
}
```

Coming from the `@radix-ui/react-dropdown-menu` package? Use the subpath: `import * as DropdownMenuPrimitive from '@animate-ui/react/primitives/radix-ui/dropdown-menu'`.

## Animation

The motion of Animate UI v1's Dropdown Menu, value for value:

- **Content** fades and scales in from 0.9, from the trigger (`--radix-dropdown-menu-content-transform-origin`, set inline so it works without styles), in 200ms (`{ duration: 0.2, ease: [0.23, 1, 0.32, 1] }`, a strong ease-out), and closes the same way before it unmounts.
- **SubContent** grows from the side of its trigger the same way.
- **The highlight**: one surface glides behind the highlighted item on a spring (stiffness 350, damping 35), following the pointer and the arrow keys alike, and into submenus. The new copy fades in as it moves; the previous one goes along and fades out 200ms later. When the pointer leaves the menu, it stays on the last item. It wears the item's own highlighted background (`focus:bg-accent`, `data-highlighted:bg-accent`…), read from your styles: the item's background is cleared while it's highlighted, or while its submenu is open; its text colors stay.
- **ItemIndicator**: a checkbox item's check pops in from half its size with a fade whenever it appears (checking the item, or opening the menu) and goes at once when unchecked. A radio item's indicator glides to the newly checked item (when choosing it closes the menu, it glides while the menu fades out, as in v1).
- When the menu closes with focus inside, focus goes back to the trigger at once instead of after the exit, and the leaving menu ignores the pointer and can't dismiss anything.
- With `forceMount` (on the Content or the Portal), the closed content stays in the DOM: it plays its exit, then is hidden (`visibility: hidden`).
- Open from the start (`defaultOpen`), the menu plays its entrance on page load, like v1.
- Under reduced motion, nothing scales or glides: the menu and the highlight only fade.

## API Reference

Every part takes exactly the props of [Radix UI's Dropdown Menu](https://www.radix-ui.com/primitives/docs/components/dropdown-menu#api-reference). Animate UI adds the animation props below.

### Root, Trigger, Portal, Group, Label, RadioGroup, Separator, Arrow, Sub

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/dropdown-menu#api-reference) only. They are not animated.

### Item, CheckboxItem, RadioItem, SubTrigger

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/dropdown-menu#item) only. They take part in the highlight; it needs nothing more.

### Content, SubContent

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/dropdown-menu#content), plus:

<TypeTable
  type={{
