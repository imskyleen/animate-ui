## Usage

Import the primitive from Animate UI instead of Radix UI. Everything else stays the same.

```tsx
import { DropdownMenu } from '@animate-ui/react/primitives/radix-ui';

export function AccountMenu() {
  return (
    <DropdownMenu.Root>
      <DropdownMenu.Trigger>Account</DropdownMenu.Trigger>
      <DropdownMenu.Portal>
        <DropdownMenu.Content sideOffset={4}>
          <DropdownMenu.Item>Profile</DropdownMenu.Item>
          <DropdownMenu.Item>Billing</DropdownMenu.Item>
          <DropdownMenu.Separator />
          <DropdownMenu.Item>Log out</DropdownMenu.Item>
        </DropdownMenu.Content>
      </DropdownMenu.Portal>
    </DropdownMenu.Root>
  );
}
```

Coming from the `@radix-ui/react-dropdown-menu` package? Use the subpath: `import * as DropdownMenuPrimitive from '@animate-ui/react/primitives/radix-ui/dropdown-menu'`.

## Animation

The motion of Animate UI v1's Dropdown Menu:

- **Content** fades and scales in from 0.9, from the trigger (`--radix-dropdown-menu-content-transform-origin`, set inline so it works without styles), in 250ms (`{ duration: 0.25, ease: [0.215, 0.61, 0.355, 1] }`, a soft ease-out), and closes the same way before it unmounts.
- **SubContent** grows from the side of its trigger the same way.
- **The highlight**: one surface glides behind the highlighted item on a spring (stiffness 500, damping 40), following the pointer and the arrow keys alike, and into submenus. Moving to another item, it carries on from where it is, at its speed: however fast the pointer or the arrow keys go, there's one highlight on screen. It only fades in (200ms) when it appears from nothing. It glides on the compositor (a Web Animation of `transform`), so a busy main thread, a submenu opening for instance, doesn't stall it. Into a submenu or back out of it, each menu clips its own part, as in v1: the previous surface glides along with the new one, the same box on screen, so the two make one highlight crossing from one menu into the other; the entering part fades in as it glides. When the pointer leaves the menu, it stays on the last item. It wears the item's own highlighted background (`focus:bg-accent`, `data-highlighted:bg-accent`…), read from your styles: the item's background is cleared while it's highlighted (or still has the focus, or its submenu is open), and a `focus:` background is read again once the item has the focus; its text colors stay.
- **ItemIndicator**: a checkbox item's check pops in from half its size out of a light blur (2px), with a little overshoot, whenever it appears (checking the item, or opening the menu), and shrinks back into its blur in 150ms when the item is unchecked (it stays mounted for that). A radio item's check glides to the newly checked item on the highlight's spring, like a select's.
- Choosing an item closes the menu (Radix's default): when its check moves (a radio item's glides from the one shown, a checkbox item's pops in or out), the menu holds still for 150ms first, so the change is seen, then fades out. Escape and outside clicks don't wait.
- When the menu closes with focus inside, focus goes back to the trigger at once instead of after the exit, and the leaving menu ignores the pointer and can't dismiss anything.
- With `forceMount` (on the Content or the Portal), the closed content stays in the DOM: it plays its exit, then is hidden (`visibility: hidden`).
- Open from the start (`defaultOpen`), the menu plays its entrance on page load, like v1.
- Under reduced motion, nothing scales or glides: the menu and the checks only fade, and the menu doesn't hold; the highlight jumps from item to item and only fades in when it appears.

## API Reference

Every part takes exactly the props of [Radix UI's Dropdown Menu](https://www.radix-ui.com/primitives/docs/components/dropdown-menu#api-reference). Animate UI adds the animation props below.

### Root, Trigger, Portal, Group, Label, RadioGroup, Separator, Arrow, Sub

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/dropdown-menu#api-reference) only. They are not animated.

### Item, CheckboxItem, RadioItem, SubTrigger

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/dropdown-menu#item) only. They take part in the highlight; it needs nothing more.

### Content, SubContent

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/dropdown-menu#content), plus:

<TypeTable
  type={{

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/dropdown-menu#itemindicator), plus:
