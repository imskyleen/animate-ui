## Usage

Import the primitive from Animate UI instead of Radix UI. Everything else stays the same.

```tsx
import { Switch } from '@animate-ui/react/primitives/radix-ui/switch';

export function AirplaneMode() {
  return (
    <label className="flex items-center gap-2">
      <Switch.Root>
        <Switch.Thumb />
      </Switch.Root>
      Airplane mode
    </label>
  );
}
```

The `import * as SwitchPrimitive from '@radix-ui/react-switch'` style works too.

## Animation

- **Thumb** glides to its new side. The thumb's `translate` classes still decide where it rests (`data-checked:translate-x-…`): on a change, Animate UI puts it back where it was with a `transform` and springs it to its new place (`spring.snappy`, 0.6s, bounce 0.15). Only `transform` animates, never its width or position, so the track's own transitions are untouched.
- **Root** scales to 0.96 while pressed (150ms).
- Toggling again mid-glide turns back from where the thumb is, without a jump.
- Toggling with Space glides the same way: the state changes at once, the animation never delays it.
- Under reduced motion, the thumb jumps to its side (no press feedback either).
- shadcn/ui's `transition-transform` on the thumb tweened its `translate`; the CLI removes it (Animate UI also skips it while measuring, so a leftover class doesn't break the glide).

## API Reference

Every part takes exactly the props of [Radix UI's Switch](https://www.radix-ui.com/primitives/docs/components/switch#api-reference). Animate UI adds the animation props below. With `asChild`, a part renders your element with Radix's behaviour, without the animation.

### Root

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/switch#root), plus:

<TypeTable
  type={{
    transition: {
      description: 'Transition of the press feedback.',
      type: 'Transition',
      default: 'transition.press (150ms, ease-out)',
    },
  }}
/>

### Thumb

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/switch#thumb), plus:

<TypeTable
  type={{
    transition: {
      description: 'Transition of the thumb gliding to its new side.',
      type: 'Transition',
      default: 'spring.snappy (0.6s, bounce 0.15)',
    },
  }}
/>
