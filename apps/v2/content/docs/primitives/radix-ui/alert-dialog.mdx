## Usage

Import the primitive from Animate UI instead of Radix UI. Everything else stays the same.

```tsx
import { AlertDialog } from '@animate-ui/react/primitives/radix-ui';

export function DeleteProject() {
  return (
    <AlertDialog.Root>
      <AlertDialog.Trigger>Delete project</AlertDialog.Trigger>
      <AlertDialog.Portal>
        <AlertDialog.Overlay />
        <AlertDialog.Content>
          <AlertDialog.Title>Delete this project?</AlertDialog.Title>
          <AlertDialog.Description>
            This action cannot be undone.
          </AlertDialog.Description>
          <AlertDialog.Cancel>Cancel</AlertDialog.Cancel>
          <AlertDialog.Action>Delete</AlertDialog.Action>
        </AlertDialog.Content>
      </AlertDialog.Portal>
    </AlertDialog.Root>
  );
}
```

Coming from the `@radix-ui/react-alert-dialog` package? Use the subpath: `import * as AlertDialogPrimitive from '@animate-ui/react/primitives/radix-ui/alert-dialog'`.

## Animation

Animate UI v1's alert dialog motion, with a smoother overlay and a quicker exit.

- **Overlay** fades in from nothing to what its classes set: its background color deepens while its backdrop filter grows, so the page behind blurs progressively from 0 (fading its opacity would cross-fade the sharp page with an already blurred one). Over 400ms on a soft ease-out, along with the content's fade, and it leaves the same way.
- **Content** tips forward into place, around its center: it starts from `perspective(500px) rotateX(-20deg) scale(0.8)`, transparent and blurred (4px), and comes upright and sharp on a spring (stiffness 150, damping 25), fading in ahead of it with the overlay (400ms on a soft ease-out): it's there first, then it settles. Dismissed, it goes back the way it came, but quicker and speeding away (0.25s on an ease-in), out of sight just before the overlay has cleared, then unmounts.
- `from` picks the edge the content tips from, as in v1: `top` by default (`rotateX(-20deg)`), `bottom` (`rotateX(20deg)`), `left` (`rotateY(20deg)`) or `right` (`rotateY(-20deg)`).
- On the overlay, `exitTransition` defaults to `transition`: change `transition` and both directions follow, as in v1. The dialog's own exit is the quicker one above unless you set `exitTransition`.
- Radix keeps the Overlay and the Content mounted while they exit; Cancel is focused as soon as it opens, and focus returns to the trigger once the exit is over.
- Reopening while it closes picks up from where it is.
- With `forceMount`, the closed alert dialog stays in the DOM: it plays its exit, then is hidden and `inert`.
- Under reduced motion, the content fades and un-blurs without tilting or scaling.
- `AnimateUIProvider tempo` scales every duration and spring.

## API Reference

Every part takes exactly the props of [Radix UI's Alert Dialog](https://www.radix-ui.com/primitives/docs/components/alert-dialog#api-reference). Animate UI adds the animation props below.

### Root, Trigger, Portal, Title, Description, Action, Cancel

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/alert-dialog#root) only. They are not animated.

### Overlay

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/alert-dialog#overlay), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the fade in (background color and backdrop filter).',
      type: 'Transition',
      default: '{ duration: 0.4, ease: [0.215, 0.61, 0.355, 1] }',
    },
    exitTransition: {
      description: 'Transition of the fade out.',
      type: 'Transition',
      default: 'transition',
    },
  }}
/>

### Content

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/alert-dialog#content), plus:

<TypeTable
  type={{
    from: {
      description: 'The edge the content tips from as it comes in, as in v1.',
      type: "'top' | 'bottom' | 'left' | 'right'",
      default: "'top'",
    },
    transition: {
      description:
        'Transition of the opening. One you pass drives its fade too.',

      default:
        "{ type: 'spring', stiffness: 150, damping: 25, opacity: { duration: 0.4, ease: [0.215, 0.61, 0.355, 1] } }",

      description: 'Transition of the closing.',
      type: 'Transition',
      default: '{ duration: 0.25, ease: [0.42, 0, 1, 1] }',
    },
  }}
/>
