## Usage

Import the primitive from Animate UI instead of Radix UI. Everything else stays the same.

```tsx
import { NavigationMenu } from '@animate-ui/react/primitives/radix-ui';

export function SiteNav() {
  return (
    <NavigationMenu.Root>
      <NavigationMenu.List>
        <NavigationMenu.Item>
          <NavigationMenu.Trigger>Learn</NavigationMenu.Trigger>
          <NavigationMenu.Content>
            <NavigationMenu.Link href="/docs">
              Documentation
            </NavigationMenu.Link>
          </NavigationMenu.Content>
        </NavigationMenu.Item>
        <NavigationMenu.Item>
          <NavigationMenu.Link href="/blog">Blog</NavigationMenu.Link>
        </NavigationMenu.Item>
        <NavigationMenu.Indicator />
      </NavigationMenu.List>
      <NavigationMenu.Viewport className="h-(--radix-navigation-menu-viewport-height) w-(--radix-navigation-menu-viewport-width)" />
    </NavigationMenu.Root>
  );
}
```

Coming from the `@radix-ui/react-navigation-menu` package? Use the subpath: `import * as NavigationMenuPrimitive from '@animate-ui/react/primitives/radix-ui/navigation-menu'`.

## Animation

Radix's Navigation Menu has no Animate UI v1 counterpart: it moves like v1's Dropdown Menu.

- **Viewport** fades and scales in from 0.9, dropping from its top edge, in 250ms (`{ duration: 0.25, ease: [0.215, 0.61, 0.355, 1] }`, a soft ease-out), like v1's menu content, and closes the same way before it unmounts.
- Moving from one item to another, the Viewport's size follows the new content in 250ms too instead of jumping: Animate UI animates `--radix-navigation-menu-viewport-width` and `--radix-navigation-menu-viewport-height`, so classes reading them resize smoothly.
- **Content** displayed in the Viewport fades in from a 4px blur, in 250ms, when moving between items; the previous content leaves at once. Without a Viewport, each Content fades and scales under its item like the Viewport does.
- **Indicator** follows the active trigger like v1's menu highlight, on the highlight's spring (stiffness 500, damping 40, quicker than v1's), fading in on it and out 200ms after the menu closes.
- Keyboard navigation between links and triggers moves focus only: nothing animates.
- With `forceMount`, closed parts stay in the DOM: they play their exit, then are hidden (`visibility: hidden`).
- An item open from the start (`defaultValue`) shows with the Viewport's entrance on page load.
- Under reduced motion, everything only fades and sizes change at once.

## API Reference

Every part takes exactly the props of [Radix UI's Navigation Menu](https://www.radix-ui.com/primitives/docs/components/navigation-menu#api-reference). Animate UI adds the animation props below.

### Root, Sub, List, Item, Trigger, Link

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/navigation-menu#api-reference) only. They are not animated.

### Viewport

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/navigation-menu#viewport), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the opening and of the resizing between items, and of the closing unless `exitTransition` is set.',
      type: 'Transition',
      default: '{ duration: 0.25, ease: [0.215, 0.61, 0.355, 1] }',
    },
    exitTransition: {
      description: 'Transition of the closing.',
      type: 'Transition',
      default: 'transition',
    },
  }}
/>

### Content

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/navigation-menu#content), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the entrance (and, without a Viewport, of the closing unless `exitTransition` is set).',
      type: 'Transition',
      default: '{ duration: 0.25, ease: [0.215, 0.61, 0.355, 1] }',
    },
    exitTransition: {
      description: 'Transition of the closing, without a Viewport.',
      type: 'Transition',
      default: 'transition',
    },
  }}
/>

### Indicator

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/navigation-menu#indicator), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the move between triggers and of the fade-in.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 500, damping: 40 }",
    },
    exitTransition: {
      description: 'Transition of the fade-out.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 500, damping: 40, delay: 0.2 }",
    },
  }}
/>
