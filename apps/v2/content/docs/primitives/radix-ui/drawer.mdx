## Installation

<Installation name="drawer" />

shadcn/ui's Radix Drawer is built on [Vaul](https://vaul.emilkowal.ski), which is no longer maintained. Animate UI's Drawer has exactly Vaul's API (the `Drawer` object and its parts, the same props, the same `data-vaul-*` attributes), built on Radix UI's Dialog and Motion. `animate-ui animate drawer` swaps the `vaul` import for it, so you can also remove the `vaul` dependency from your project.

## Usage

Import the primitive from Animate UI instead of Vaul. Everything else stays the same.

```tsx
import { Drawer } from '@animate-ui/react/primitives/radix-ui/drawer';

export function MoveGoal() {
  return (
    <Drawer.Root>
      <Drawer.Trigger>Move goal</Drawer.Trigger>
      <Drawer.Portal>
        <Drawer.Overlay />
        <Drawer.Content>
          <Drawer.Handle />
          <Drawer.Title>Move goal</Drawer.Title>
          <Drawer.Description>Set your daily activity goal.</Drawer.Description>
          <Drawer.Close>Save</Drawer.Close>
        </Drawer.Content>
      </Drawer.Portal>
    </Drawer.Root>
  );
}
```

The `import * as Vaul from 'vaul'` style works too, as do the named exports (`Root`, `NestedRoot`, `Content`, `Overlay`, `Portal`, `Handle`) and the types (`DialogProps`, `ContentProps`, `HandleProps`, `WithFadeFromProps`, `WithoutFadeFromProps`). `direction`, `snapPoints` with `activeSnapPoint`, `setActiveSnapPoint` and `fadeFromIndex`, `dismissible`, `handleOnly`, `modal`, `closeThreshold`, `shouldScaleBackground` (on the element with `data-vaul-drawer-wrapper`), `NestedRoot`, `container`, `onDrag`, `onRelease`, `onClose` and `onAnimationEnd` behave as in Vaul, and `data-vaul-no-drag` keeps an element from starting a drag.

## Animation

Animate UI v1 had no drawer: the motion is Vaul's.

- **Content** slides in from its edge (`direction`, its own size plus any gap to the edge), opaque, a sheet sliding in rather than a fade, on Vaul's curve: 0.5s of `cubic-bezier(0.32, 0.72, 0, 1)`, which answers at once and glides to rest. It slides back out the same way. With snap points, it slides to the active one.
- **Overlay** comes in like the dialogs': its tint deepens while its backdrop blur grows from 0, on the drawer's curve, so the page behind blurs progressively (fading its opacity would cross-fade the sharp page with an already blurred one), and it clears the same way. Once a drag has moved the drawer, it also follows the drawer's position, like Vaul's; with snap points, it always does, coming in between the snap point before `fadeFromIndex` and that one. Over a background image (a gradient), it fades its opacity instead.
- **Dragging** follows the pointer on the same frame: the pointer sets the position directly, with no transition, no fade and no React render. Pulled past the open position, it rubber-bands. On release, it closes past `closeThreshold` (25% of its size) or on a flick, and otherwise glides back on the same curve. With snap points, it goes to the closest one, a flick moves one point (a fast one skips to the first or last), and a flick down from the first closes it.
- **Scrollable content** keeps scrolling: a drag doesn't start when the content under the pointer can scroll that way, nor shortly after it scrolled (`scrollLockTimeout`).
- A drag dismissal continues from where the pointer let go; opening again while it closes picks up from where it is. The click that ends a drag doesn't activate the button under it.
- **Nested drawers**: the parent steps back (16px towards its open edge, slightly smaller) on the same curve while a nested drawer is open, and follows the nested drawer's drag.
- **`shouldScaleBackground`** scales the `[data-vaul-drawer-wrapper]` element with the drawer's position, and paints the body black (`setBackgroundColorOnScale`, not with `noBodyStyles`).
- With `forceMount`, the closed drawer stays in the DOM: it plays its exit, then is hidden and `inert`.
- Under reduced motion, the drawer fades in place and settles without moving; a drag still follows the pointer.
- `AnimateUIProvider tempo` scales every duration and spring.

Not reproduced from Vaul: its iOS Safari workarounds (`position: fixed` on the body, so `preventScrollRestoration` and `disablePreventScroll` are accepted but have no effect; Radix's Dialog locks the scroll of a modal drawer). `repositionInputs` and `fixed` keep a bottom drawer above the on-screen keyboard, more simply than Vaul. A Handle tap on a drawer without snap points does nothing.

## API Reference

Every part takes exactly the props of [Vaul's Drawer](https://vaul.emilkowal.ski/api) (its Content, Overlay, Trigger, Close, Title and Description take [Radix UI's Dialog props](https://www.radix-ui.com/primitives/docs/components/dialog#api-reference)). Animate UI adds the animation props below.

### Root, NestedRoot, Trigger, Portal, Handle, Title, Description, Close

[Vaul props](https://vaul.emilkowal.ski/api) only.

### Content

[Vaul props](https://vaul.emilkowal.ski/api), plus:

<TypeTable
  type={{

    exitTransition: {
