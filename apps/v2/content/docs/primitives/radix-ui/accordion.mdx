## Usage

Import the primitive from Animate UI instead of Radix UI. Everything else stays the same.

```tsx
import { Accordion } from '@animate-ui/react/primitives/radix-ui';

export function FAQ() {
  return (
    <Accordion.Root type="single" collapsible>
      <Accordion.Item value="item-1">
        <Accordion.Header>
          <Accordion.Trigger>Is it accessible?</Accordion.Trigger>
        </Accordion.Header>
        <Accordion.Content>
          Yes. It adheres to the WAI-ARIA design pattern.
        </Accordion.Content>
      </Accordion.Item>
    </Accordion.Root>
  );
}
```

Coming from the `@radix-ui/react-accordion` package? Use the subpath: `import * as AccordionPrimitive from '@animate-ui/react/primitives/radix-ui/accordion'`.

## Animation

- **Content** grows its height and fades in over 600ms with a strong ease-out, and collapses in 400ms before it unmounts.
- Opening another item while one is closing retargets smoothly.
- With `forceMount`, closed content stays in the DOM, collapsed and `inert`.
- Under reduced motion, the height changes at once.

## API Reference

Every part takes exactly the props of [Radix UI's Accordion](https://www.radix-ui.com/primitives/docs/components/accordion#api-reference). Animate UI adds the animation props below.

### Root, Item, Header, Trigger

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/accordion#root) only. They are not animated.

### Content

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/accordion#content), plus:
