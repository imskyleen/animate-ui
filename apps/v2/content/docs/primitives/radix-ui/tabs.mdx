## Usage

Import the primitive from Animate UI instead of Radix UI. Everything else stays the same.

```tsx
import { Tabs } from '@animate-ui/react/primitives/radix-ui';

export function Settings() {
  return (
    <Tabs.Root defaultValue="account">
      <Tabs.List aria-label="Settings">
        <Tabs.Trigger value="account">Account</Tabs.Trigger>
        <Tabs.Trigger value="password">Password</Tabs.Trigger>
      </Tabs.List>
      <Tabs.Content value="account">Make changes to your account.</Tabs.Content>
      <Tabs.Content value="password">Change your password.</Tabs.Content>
    </Tabs.Root>
  );
}
```

Coming from the `@radix-ui/react-tabs` package? Use the subpath: `import * as TabsPrimitive from '@animate-ui/react/primitives/radix-ui/tabs'`.

## Animation

- **The active tab's surface slides** to the new tab on a spring (stiffness 200, damping 25), like Animate UI v1's highlight: the new surface fades in as it slides from the previous one, which follows it and fades out 200ms later. The List draws it as an indicator that copies the active tab's own classes and data attributes, so it looks exactly like your active tab (background, border, shadow, and the `line` variant's underline) in every style and theme, while the active tab's own surface is hidden. Its focus ring stays on the tab.
- **The tabs' colors change over 500ms** (Tailwind's `ease-in-out`), as in v1, whatever transition your tabs set.
- Clicking quickly through tabs retargets the slide smoothly.
- **The incoming panel fades in from a 4px blur** over 500ms ease-in-out, while its height springs from the previous panel's to its own (stiffness 200, damping 30), like v1's tab contents. The panels share an element (the tabs root, usually), which remembers the selected panel's height. The outgoing panel leaves at once, so the two never overlap.
- The selected panel fades in on mount (page load) too, as in v1.
- Keyboard changes animate like clicks, as in v1: arrow keys, Home and End slide the surface and fade the panel in; focus moves at once.
- With `forceMount`, inactive panels stay in the DOM, `hidden`, and fade in when they become active.
- `<AnimateUIProvider tempo>` paces every transition.
- Under reduced motion, the surface jumps and the height changes at once; the fades still play.

## API Reference

Every part takes exactly the props of [Radix UI's Tabs](https://www.radix-ui.com/primitives/docs/components/tabs#api-reference). Animate UI adds the animation props below.

### Root, Trigger

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/tabs#root) only.

### List

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/tabs#list), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the surface sliding to the new tab (pointer changes); the previous surface fades out 200ms after it starts.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 200, damping: 25 }",
    },
  }}
/>

### Content

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/tabs#content), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the incoming panel: its fade from a blur, and its height (in `height`, or the whole transition when it has none).',
      type: 'Transition',
      default:
        "{ duration: 0.5, ease: 'easeInOut', height: { type: 'spring', stiffness: 200, damping: 30 } }",
    },
  }}
/>
