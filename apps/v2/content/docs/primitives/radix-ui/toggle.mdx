## Usage

Import the primitive from Animate UI instead of Radix UI. Everything else stays the same.

```tsx
import { Toggle } from '@animate-ui/react/primitives/radix-ui';

export function BoldToggle() {
  return (
    <Toggle.Root aria-label="Toggle bold">
      <BoldIcon />
    </Toggle.Root>
  );
}
```

Coming from the `@radix-ui/react-toggle` package? Use the subpath: `import * as TogglePrimitive from '@animate-ui/react/primitives/radix-ui/toggle'`.

## Animation

- Pressing it scales it to 0.96 (150ms, strong ease-out), and back on release. That's the only motion: the on/off colours stay your CSS.
- The state changes on the click (or Space / Enter) itself: the animation never delays it.
- Under reduced motion, there is no press scale.
