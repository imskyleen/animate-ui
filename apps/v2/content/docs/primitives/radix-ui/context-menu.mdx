## Usage

Import the primitive from Animate UI instead of Radix UI. Everything else stays the same.

```tsx
import { ContextMenu } from '@animate-ui/react/primitives/radix-ui';

export function CanvasMenu() {
  return (
    <ContextMenu.Root>
      <ContextMenu.Trigger>Right click here</ContextMenu.Trigger>
      <ContextMenu.Portal>
        <ContextMenu.Content>
          <ContextMenu.Item>Undo</ContextMenu.Item>
          <ContextMenu.Item>Duplicate</ContextMenu.Item>
          <ContextMenu.Separator />
          <ContextMenu.Item>Delete</ContextMenu.Item>
        </ContextMenu.Content>
      </ContextMenu.Portal>
    </ContextMenu.Root>
  );
}
```

Coming from the `@radix-ui/react-context-menu` package? Use the subpath: `import * as ContextMenuPrimitive from '@animate-ui/react/primitives/radix-ui/context-menu'`.

## Animation

Radix's Context Menu has no Animate UI v1 counterpart: it moves like v1's Dropdown Menu.

- **Content** fades and scales in from 0.9, from the pointer (`--radix-context-menu-content-transform-origin`, set inline so it works without styles), in 250ms (`{ duration: 0.25, ease: [0.215, 0.61, 0.355, 1] }`, a soft ease-out), and closes the same way before it unmounts.
- **SubContent** grows from the side of its trigger the same way.
- **The highlight**: one surface glides behind the highlighted item on a spring (stiffness 500, damping 40), following the pointer and the arrow keys alike, and into submenus. Moving to another item, it carries on from where it is, at its speed: however fast the pointer or the arrow keys go, there's one highlight on screen. It only fades in (200ms) when it appears from nothing. It glides on the compositor (a Web Animation of `transform`), so a busy main thread, a submenu opening for instance, doesn't stall it. When the pointer leaves the menu, it stays on the last item. It wears the item's own highlighted background (`focus:bg-accent`, `data-highlighted:bg-accent`…), read from your styles: the item's background is cleared while it's highlighted, or while its submenu is open; its text colors stay.
- **ItemIndicator**: a checkbox item's check pops in from half its size with a fade whenever it appears (checking the item, or opening the menu) and goes at once when unchecked. A radio item's indicator glides to the newly checked item (when choosing it closes the menu, it glides while the menu fades out, as in v1).
- When the menu closes with focus inside, focus goes back to where it was before the menu opened at once instead of after the exit, and the leaving menu ignores the pointer and can't dismiss anything.
- With `forceMount` (on the Content or the Portal), the closed content stays in the DOM: it plays its exit, then is hidden (`visibility: hidden`).
- Under reduced motion, nothing scales or glides: the menu only fades; the highlight jumps from item to item and only fades in when it appears.

## API Reference

Every part takes exactly the props of [Radix UI's Context Menu](https://www.radix-ui.com/primitives/docs/components/context-menu#api-reference). Animate UI adds the animation props below.

### Root, Trigger, Portal, Group, Label, RadioGroup, Separator, Arrow, Sub

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/context-menu#api-reference) only. They are not animated.

### Item, CheckboxItem, RadioItem, SubTrigger

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/context-menu#item) only. They take part in the highlight; it needs nothing more.

### Content, SubContent

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/context-menu#content), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the opening, and of the closing unless `exitTransition` is set.',
      type: 'Transition',
      default: '{ duration: 0.25, ease: [0.215, 0.61, 0.355, 1] }',
    },
    exitTransition: {
      description: 'Transition of the closing.',
      type: 'Transition',
      default: 'transition',
    },
  }}
/>

### ItemIndicator

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/context-menu#itemindicator), plus:

<TypeTable
  type={{

      default:
        "Motion's defaults, as in v1: a spring (stiffness 550, damping 30) and a 300ms fade; radio items: a 450ms move",
    },
  }}
/>
