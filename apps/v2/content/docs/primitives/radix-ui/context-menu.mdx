## Usage

Import the primitive from Animate UI instead of Radix UI. Everything else stays the same.

```tsx
import { ContextMenu } from '@animate-ui/react/primitives/radix-ui';

export function CanvasMenu() {
  return (
    <ContextMenu.Root>
      <ContextMenu.Trigger>Right click here</ContextMenu.Trigger>
      <ContextMenu.Portal>
        <ContextMenu.Content>
          <ContextMenu.Item>Undo</ContextMenu.Item>
          <ContextMenu.Item>Duplicate</ContextMenu.Item>
          <ContextMenu.Separator />
          <ContextMenu.Item>Delete</ContextMenu.Item>
        </ContextMenu.Content>
      </ContextMenu.Portal>
    </ContextMenu.Root>
  );
}
```

Coming from the `@radix-ui/react-context-menu` package? Use the subpath: `import * as ContextMenuPrimitive from '@animate-ui/react/primitives/radix-ui/context-menu'`.

### Check animation

Checkbox and radio items show their check in an `ItemIndicator`: it draws itself when the item is checked, and erases itself when it's unchecked (a radio item's while the new one draws). With `animation="pop"`, it pops in from half its size and shrinks back out instead, and a radio item's check glides to the newly checked item:

```tsx
import * as React from 'react';
import { ContextMenu } from '@animate-ui/react/primitives/radix-ui';

export function CanvasMenu() {
  const [showGrid, setShowGrid] = React.useState(true);
  const [zoom, setZoom] = React.useState('fit');

  return (
    <ContextMenu.Root>
      <ContextMenu.Trigger>Right click here</ContextMenu.Trigger>
      <ContextMenu.Portal>
        <ContextMenu.Content>
          <ContextMenu.CheckboxItem
            checked={showGrid}
            onCheckedChange={setShowGrid}
          >
            <ContextMenu.ItemIndicator animation="pop">
              <CheckIcon />
            </ContextMenu.ItemIndicator>
            Show grid
          </ContextMenu.CheckboxItem>
          <ContextMenu.Separator />
          <ContextMenu.RadioGroup value={zoom} onValueChange={setZoom}>
            <ContextMenu.RadioItem value="fit">
              <ContextMenu.ItemIndicator animation="pop">
                <CheckIcon />
              </ContextMenu.ItemIndicator>
              Zoom to fit
            </ContextMenu.RadioItem>
            <ContextMenu.RadioItem value="100">
              <ContextMenu.ItemIndicator animation="pop">
                <CheckIcon />
              </ContextMenu.ItemIndicator>
              Zoom to 100%
            </ContextMenu.RadioItem>
          </ContextMenu.RadioGroup>
        </ContextMenu.Content>
      </ContextMenu.Portal>
    </ContextMenu.Root>
  );
}
```

## Animation

Radix's Context Menu has no Animate UI v1 counterpart: it moves like v1's Dropdown Menu.

- **Content** fades and scales in from 0.9, from the pointer (`--radix-context-menu-content-transform-origin`, set inline so it works without styles), in 250ms (`{ duration: 0.25, ease: [0.215, 0.61, 0.355, 1] }`, a soft ease-out), and closes the same way before it unmounts.
- **SubContent** grows from the side of its trigger the same way.
- **The highlight**: one surface glides behind the highlighted item on a spring (stiffness 500, damping 40), following the pointer and the arrow keys alike, and into submenus. Moving to another item, it carries on from where it is, at its speed: however fast the pointer or the arrow keys go, there's one highlight on screen. It only fades in (200ms) when it appears from nothing. It glides on the compositor (a Web Animation of `transform`), so a busy main thread, a submenu opening for instance, doesn't stall it. Into a submenu or back out of it, each menu clips its own part, as in v1: the previous surface glides along with the new one, the same box on screen, so the two make one highlight crossing from one menu into the other; the entering part fades in as it glides. When the pointer leaves the menu, it stays on the last item. It wears the item's own highlighted background (`focus:bg-accent`, `data-highlighted:bg-accent`…), read from your styles: the item's background is cleared while it's highlighted (or still has the focus, or its submenu is open), and a `focus:` background is read again once the item has the focus; its text colors stay.
- **ItemIndicator**: an item's check draws itself like a Checkbox's check (its stroke and opacity in 0.3s on Motion's easeOut, at once: there's no box to fill first) whenever it appears (checking the item, or opening the menu), and erases itself in 0.3s when the item is unchecked (it stays mounted for that). Checking another radio item erases the old check while the new one draws itself.
- With `animation="pop"` on the ItemIndicator (or `checkAnimation="pop"` on an `AnimateUIProvider`), checks pop instead: in from half their size out of a 2px blur (a spring, stiffness 500, damping 24), and back into their blur in 0.15s. A radio item's check doesn't pop from one item to another: it glides from the item it leaves to the newly checked one, on the highlight's spring (stiffness 500, damping 40), like a select's. The demo's Controls switch between the two.
- Choosing an item closes the menu (Radix's default): when its check changes (a checkbox item's, or another radio item's than the checked one), the menu holds still for 150ms first, so the change is seen, then fades out. Escape and outside clicks don't wait.
- When the menu closes with focus inside, focus goes back to where it was before the menu opened at once instead of after the exit, and the leaving menu ignores the pointer and can't dismiss anything.
- With `forceMount` (on the Content or the Portal), the closed content stays in the DOM: it plays its exit, then is hidden (`visibility: hidden`). It still opens on a click: closed, it's a dismissable layer already, and Radix would take the pointer down that opens it for one outside it, closing it at once.
- Under reduced motion, nothing scales or glides: the menu and the checks only fade, and the menu doesn't hold; the highlight jumps from item to item and only fades in when it appears.

## API Reference

Every part takes exactly the props of [Radix UI's Context Menu](https://www.radix-ui.com/primitives/docs/components/context-menu#api-reference). Animate UI adds the animation props below.

### Root, Trigger, Portal, Group, Label, RadioGroup, Separator, Arrow, Sub

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/context-menu#api-reference) only. They are not animated.

### Item, CheckboxItem, RadioItem, SubTrigger

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/context-menu#item) only. They take part in the highlight; it needs nothing more.

### Content, SubContent

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/context-menu#content), plus:
