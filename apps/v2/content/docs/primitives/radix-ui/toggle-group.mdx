## Usage

Import the primitive from Animate UI instead of Radix UI. Everything else stays the same.

```tsx
import { ToggleGroup } from '@animate-ui/react/primitives/radix-ui';

export function Alignment() {
  return (
    <ToggleGroup.Root
      type="single"
      defaultValue="left"
      aria-label="Text alignment"
    >
      <ToggleGroup.Item value="left" aria-label="Align left">
        <AlignLeftIcon />
      </ToggleGroup.Item>
      <ToggleGroup.Item value="center" aria-label="Align center">
        <AlignCenterIcon />
      </ToggleGroup.Item>
      <ToggleGroup.Item value="right" aria-label="Align right">
        <AlignRightIcon />
      </ToggleGroup.Item>
    </ToggleGroup.Root>
  );
}
```

Coming from the `@radix-ui/react-toggle-group` package? Use the subpath: `import * as ToggleGroupPrimitive from '@animate-ui/react/primitives/radix-ui/toggle-group'`.

## Animation

The motion of Animate UI v1's toggle group:

- **Item** (each item) scales to 0.95 while pressed, on Motion's default spring for scale (stiffness 550, damping 30); the selection changes on the press itself.
- **Root** with `type="single"`: the selected item's surface slides to the newly selected item, on a spring (stiffness 200, damping 25), the new surface fading in as the previous one fades out while following it (v1's highlight, a shared layout animation). The first selection fades the surface in on its item; clearing the selection fades it out.
- To make shadcn/ui's surface slide without touching the component, the group draws it with its own `::before` and `::after`, behind its items, copying the selected item's background and corner radii; a small stylesheet clears the selected item's own background while it isn't hovered (hovered, its own background shows on top, as v1's item hover did over the highlight). The items' borders and `first:` / `last:` styles are untouched.
- With multiple selection there is no sliding surface: each item keeps its own colours (shadcn/ui's CSS, faded by its `transition-all`; v1 faded a highlight per item in 0.3s).
- The arrow keys only move the focus between items: nothing animates.
- Under reduced motion, there is no press scale and the surface jumps to its item (its fades still play).

## API Reference

Every part takes exactly the props of [Radix UI's Toggle Group](https://www.radix-ui.com/primitives/docs/components/toggle-group#api-reference). Animate UI adds the animation props below. With `asChild`, an item renders your element with Radix's behaviour, without the press scale.

### Root

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/toggle-group#root), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the surface sliding between items (`type="single"`).',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 200, damping: 25 }",
    },
  }}
/>

### Item

[Radix UI props](https://www.radix-ui.com/primitives/docs/components/toggle-group#item), plus:

<TypeTable
  type={{
    transition: {
      description: 'Transition of the press scale.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 550, damping: 30 }",
    },
  }}
/>

`AnimateUIProvider`'s `tempo` scales these transitions with everything else.
