Radix UI has no Combobox. shadcn/ui's Radix UI Combobox is built on Base UI's Combobox, and so is this one: it's the [Base UI Combobox](/docs/primitives/base-ui/combobox), in a Radix UI project. It needs `@base-ui/react` next to `radix-ui`, as shadcn/ui's does.

## Installation

<Installation name="combobox" />

shadcn/ui's Radix UI Combobox imports `@base-ui/react`: `animate-ui animate combobox` swaps that import, as it does for the Base UI one.

## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same.

```tsx
import { Combobox } from '@animate-ui/react/primitives/base-ui/combobox';

const frameworks = ['Next.js', 'React Router', 'Astro', 'SvelteKit'];

export function FrameworkPicker() {
  return (
    <Combobox.Root items={frameworks}>
      <Combobox.Input
        aria-label="Framework"
        placeholder="Search a framework…"
      />
      <Combobox.Portal>
        <Combobox.Positioner sideOffset={6}>
          <Combobox.Popup>
            <Combobox.Empty>No framework found.</Combobox.Empty>
            <Combobox.List>
              {(item: string) => (
                <Combobox.Item key={item} value={item}>
                  {item}
                </Combobox.Item>
              )}
            </Combobox.List>
          </Combobox.Popup>
        </Combobox.Positioner>
      </Combobox.Portal>
    </Combobox.Root>
  );
}
```

`import { Combobox } from '@base-ui/react'` (shadcn/ui's import) becomes `import { Combobox } from '@animate-ui/react/primitives/base-ui'`.

## Animation

The Base UI Combobox's, described on [its page](/docs/primitives/base-ui/combobox#animation):

- **Popup** fades and scales in from 0.9, from the input, in 200ms on a strong ease-out, and closes the same way.
- **The highlight** glides behind the highlighted item on a spring, following the pointer and the arrow keys alike.
- **Chip**: an added chip pops in from half its size with a fade.
- **ItemIndicator**: with a single value, the check moves to the chosen item; with `multiple`, it pops in.
- Under reduced motion, nothing scales or glides: everything only fades.

## API Reference

The [Base UI Combobox's](/docs/primitives/base-ui/combobox#api-reference): every part takes exactly the props of [Base UI's Combobox](https://base-ui.com/react/components/combobox#api-reference), and Animate UI adds `transition` (and `exitTransition`) to the Popup, `transition` to the Chip and the ItemIndicator.
