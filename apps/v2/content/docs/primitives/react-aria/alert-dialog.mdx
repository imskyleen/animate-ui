## Usage

React Aria builds an alert dialog from a `Dialog` with `role="alertdialog"` inside a `Modal`. Import from Animate UI instead of `react-aria-components`: it re-exports all of React Aria, with animated `Modal` and `ModalOverlay`.

```tsx
import {
  Button,
  Dialog,
  DialogTrigger,
  Heading,
  Modal,
  ModalOverlay,
} from '@animate-ui/react/primitives/react-aria';

export function DeleteProject() {
  return (
    <DialogTrigger>
      <Button>Delete project</Button>
      <ModalOverlay>
        <Modal>
          <Dialog role="alertdialog">
            <Heading slot="title">Delete this project?</Heading>
            <p>This action cannot be undone.</p>
            <Button slot="close">Cancel</Button>
            <Button slot="close">Delete</Button>
          </Dialog>
        </Modal>
      </ModalOverlay>
    </DialogTrigger>
  );
}
```

## Animation

React Aria has no Animate UI v1 counterpart: the motion is v1's Alert Dialog (Radix UI and Base UI shipped the same one), with a quicker exit.

- **ModalOverlay** fades in over 400ms on a soft ease-out, a little ahead of the modal, and out the same way. React Aria renders the Modal inside it, so it fades its own background color and backdrop filter (from transparent to the values its classes set) rather than its opacity, which would fade the modal with it.
- **Modal** tips forward into place, around its center: it starts from `perspective(500px) rotateX(-20deg) scale(0.8)`, transparent and blurred (4px), and comes upright, opaque and sharp on a spring (stiffness 150, damping 25). Dismissed, it goes back the way it came, but quicker and speeding away (0.25s on an ease-in), out of sight just before the overlay has cleared, then unmounts.
- `from` picks the edge the modal tips from, as in v1: `top` by default (`rotateX(-20deg)`), `bottom` (`rotateX(20deg)`), `left` (`rotateY(20deg)`) or `right` (`rotateY(-20deg)`).
- On the overlay, `exitTransition` defaults to `transition`: change `transition` and both directions follow, as in v1. The dialog's own exit is the quicker one above unless you set `exitTransition`.
- Animate UI passes `isExiting` while the exit plays, so React Aria keeps the modal mounted, `data-exiting` stays accurate, and focus returns to the trigger.
- Without `isDismissable`, an outside click doesn't close it; Escape does, unless `isKeyboardDismissDisabled`.
- Reopening while it closes picks up from where it is.
- Under reduced motion, the modal fades and un-blurs without tilting or scaling.
- `AnimateUIProvider tempo` scales every duration and spring.

## API Reference

`Modal` and `ModalOverlay` take exactly the props of [React Aria's Modal](https://react-spectrum.adobe.com/react-aria/Modal.html#props), plus:

<TypeTable
  type={{
    from: {
      description: 'Modal: the edge it tips from as it comes in, as in v1.',
      type: "'top' | 'bottom' | 'left' | 'right'",
      default: "'top'",
    },
    transition: {
      description: 'Transition of the opening (the fade in, for ModalOverlay).',
      type: 'Transition',
      default:
        "Modal: { type: 'spring', stiffness: 150, damping: 25 }; ModalOverlay: { duration: 0.4, ease: [0.215, 0.61, 0.355, 1] }",
    },
    exitTransition: {
      description:
        'Transition of the closing (the fade out, for ModalOverlay).',
      type: 'Transition',
      default:
        'Modal: { duration: 0.25, ease: [0.42, 0, 1, 1] }; ModalOverlay: transition',
    },
  }}
/>

`DialogTrigger`, `Dialog`, `Heading` and the other components take [React Aria props](https://react-spectrum.adobe.com/react-aria/Dialog.html#props) only. They are not animated.
