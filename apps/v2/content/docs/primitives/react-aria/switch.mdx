## Usage

Import from Animate UI instead of `react-aria-components`: it re-exports all of React Aria, with the animated controls below. Everything else stays the same.

```tsx
import { Switch } from '@animate-ui/react/primitives/react-aria';

export function AirplaneMode() {
  return (
    <Switch>
      {({ isSelected }) => (
        <>
          <span className="track">
            <span
              data-slot="switch-thumb"
              data-selected={isSelected || undefined}
            />
          </span>
          Airplane mode
        </>
      )}
    </Switch>
  );
}
```

React Aria lets you render the thumb yourself. Animate UI glides the element marked `data-slot="switch-thumb"`, which is what shadcn/ui renders: add the attribute to your own thumb.

## Animation

The motion of Animate UI v1's Radix UI and Headless UI switches (v1 had no React Aria switch):

- **Thumb**, pressed: stretches toward the middle of the track, its other edge in place. Its width grows by 3/16 (a 16px thumb becomes 19px, v1's `pressedWidth`) on a spring (stiffness 300, damping 25). It's the thumb's real width, so its round ends stay round. Pressed means React Aria's `isPressed`: the pointer, or Space and Enter on the keyboard.
- **Thumb**, on a change: springs to its new side while its width springs back, on the same spring (v1's `layout` animation). The thumb's `translate` classes still decide where it rests (`data-selected:translate-x-…`): Animate UI puts it back where it was with a `transform` and springs it to its new place.
- **Switch** doesn't move. Its colours are the component's CSS, and v1's track changed colour at once: shadcn/ui's `transition-all` on the track would fade it, so the CLI removes it.
- Toggling again mid-glide turns back from where the thumb is, without a jump.
- Under reduced motion, the thumb jumps to its side, without the stretch.
- shadcn/ui's `transition-transform` on the thumb would tween its `translate`; the CLI removes it too (Animate UI also skips it while measuring, so a leftover class doesn't break the glide).
- `className`, `style` and `render` props keep working.

## API Reference

`Switch` takes exactly the props of [React Aria's Switch](https://react-spectrum.adobe.com/react-aria/Switch.html#props), plus the props below.
