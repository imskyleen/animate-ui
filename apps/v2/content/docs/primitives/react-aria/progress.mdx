## Usage

Import from Animate UI instead of `react-aria-components`: it re-exports all of React Aria, with an animated `ProgressBar`. Everything else stays the same.

```tsx
import { Label, ProgressBar } from '@animate-ui/react/primitives/react-aria';

export function Upload({ value }: { value: number }) {
  return (
    <ProgressBar value={value}>
      {({ percentage, valueText }) => (
        <>
          <Label>Uploading</Label>
          <span>{valueText}</span>
          <div className="h-2 overflow-hidden rounded-full bg-muted">
            <div className="h-full bg-primary" style={{ width: `${percentage}%` }} />
          </div>
        </>
      )}
    </ProgressBar>
  );
}
```

## Animation

- React Aria only hands its children a `percentage`: the bar is your own markup, sized with an inline percentage `width` (as shadcn/ui and React Aria's docs do). The **ProgressBar** finds that element, keeps it full width and reveals the value with an animated `transform` instead (no layout on every frame); the track clips it, as shadcn/ui's `overflow-x-hidden` track does. Right-to-left is handled.
- It moves with `spring.snappy` without bounce (600ms): progress often updates in bursts, and a spring keeps its velocity when a new value retargets it. No overshoot, which would uncover the start of the track.
- It starts at its value on mount, with no animation.
- shadcn/ui's `transition-all` on the indicator would run on top of Motion: the CLI removes it.
- Under reduced motion, the bar jumps to each value.

## API Reference

Every component takes exactly the props of [React Aria's ProgressBar](https://react-spectrum.adobe.com/react-aria/ProgressBar.html#props). Animate UI adds the animation props below.

### ProgressBar

[React Aria props](https://react-spectrum.adobe.com/react-aria/ProgressBar.html#props), plus:

<TypeTable
  type={{

The bar is any element inside the ProgressBar with an inline percentage `width` and no child elements.
