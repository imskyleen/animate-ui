## Usage

Import from Animate UI instead of `react-aria-components`: it re-exports all of React Aria, with animated `Modal` and `ModalOverlay`. Everything else stays the same.

```tsx
import {
  Button,
  Dialog,
  DialogTrigger,
  Heading,
  Modal,
  ModalOverlay,
} from '@animate-ui/react/primitives/react-aria';

export function EditProfile() {
  return (
    <DialogTrigger>
      <Button>Edit profile</Button>
      <ModalOverlay isDismissable>
        <Modal>
          <Dialog>
            <Heading slot="title">Edit profile</Heading>
            <Button slot="close">Save</Button>
          </Dialog>
        </Modal>
      </ModalOverlay>
    </DialogTrigger>
  );
}
```

A `Modal` on its own (without a `ModalOverlay`) animates too. `DialogTrigger`, `Dialog` and `Heading` are not animated.

## Sheet

shadcn/ui's Sheet is the same primitive: its `Modal` carries `data-side`, and it then slides in from that edge, fading in, like Animate UI v1's Sheet, instead of tipping in. Add it with `shadcn add sheet`, then animate it with `animate-ui animate sheet`.

## Animation

React Aria has no Animate UI v1 counterpart: the motion is v1's Dialog (Radix UI, Base UI and Headless UI shipped the same one) and, for the Sheet, v1's Sheet.

- **ModalOverlay** fades in in 200ms, easeInOut, and out the same way. React Aria renders the Modal inside it, where v1's overlay and content were siblings: fading its opacity (or filter) would fade and blur the modal too and cut its exit short. So it fades its own background color and backdrop filter, from transparent to the values its classes set, and the modal moves exactly like v1's content.
- **Modal** tips forward into place, around its center: it starts from `perspective(500px) rotateX(-20deg) scale(0.8)`, transparent and blurred (4px), and comes upright, opaque and sharp on a spring (stiffness 150, damping 25). It closes the same way, on the same spring, still visible once the overlay is gone, then unmounts.
- With `data-side="top" | "right" | "bottom" | "left"` (shadcn/ui's Sheet), the modal slides in from that edge by its own size and fades in, on v1's sheet spring (stiffness 150, damping 22, a little livelier), and slides back out the same way.
- `exitTransition` defaults to `transition`: change `transition` and both directions follow, as in v1.
- React Aria only keeps a closing modal mounted if animations are running when it closes, before Motion starts any. Animate UI tracks the same open state React Aria reads (the `DialogTrigger`'s, or `isOpen`/`defaultOpen`) and passes `isExiting` while the exit plays, so `data-exiting` and the `isExiting` render prop stay accurate, focus stops being trapped and returns to the trigger.
- Reopening while it closes picks up from where it is.
- Opening from the keyboard animates the same way; focus moves into the dialog at once.
- `className` and `style` functions keep working, and your own `render` function is made animatable rather than replaced.
- Under reduced motion, the modal fades and un-blurs without tilting, scaling or sliding.
- `AnimateUIProvider tempo` scales every duration and spring.

## API Reference

`Modal` and `ModalOverlay` take exactly the props of [React Aria's Modal](https://react-spectrum.adobe.com/react-aria/Modal.html#props), plus:

### ModalOverlay

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the fade in (of its background color and backdrop filter).',
      type: 'Transition',
      default: "{ duration: 0.2, ease: 'easeInOut' }",
    },
    exitTransition: {
      description: 'Transition of the fade out.',
      type: 'Transition',
      default: 'transition',
    },
  }}
/>

### Modal

<TypeTable
  type={{
    transition: {
      description: 'Transition of the opening.',
      type: 'Transition',
      default:
        "{ type: 'spring', stiffness: 150, damping: 25 }; with data-side: { type: 'spring', stiffness: 150, damping: 22 }",
    },
    exitTransition: {
      description: 'Transition of the closing.',
      type: 'Transition',
      default: 'transition',
    },
  }}
/>

`DialogTrigger`, `Dialog`, `Heading` and the other components take [React Aria props](https://react-spectrum.adobe.com/react-aria/Dialog.html#props) only. They are not animated.
