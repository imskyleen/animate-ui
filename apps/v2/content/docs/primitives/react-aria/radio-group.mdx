## Usage

Import from Animate UI instead of `react-aria-components`: it re-exports all of React Aria, with the animated controls below. Everything else stays the same.

```tsx
import {
  Label,
  Radio,
  RadioGroup,
} from '@animate-ui/react/primitives/react-aria';

export function Density() {
  return (
    <RadioGroup defaultValue="comfortable">
      <Label>Density</Label>
      {['default', 'comfortable', 'compact'].map((value) => (
        <Radio key={value} value={value}>
          {({ isSelected }) => (
            <>
              <span data-slot="radio-group-indicator">
                {isSelected && (
                  <span className="size-2 rounded-full bg-current" />
                )}
              </span>
              {value}
            </>
          )}
        </Radio>
      ))}
    </RadioGroup>
  );
}
```

React Aria lets you render the indicator yourself. Animate UI animates the content of the element marked `data-slot="radio-group-indicator"`, which is what shadcn/ui renders: add the attribute to your own indicator.

## Animation

The motion of Animate UI v1's Radix UI radio group (v1 had no React Aria one):

- **Radio**: the dot you render inside `data-slot="radio-group-indicator"` pops in when it mounts. Its scale and its opacity spring from 0 to 1 (stiffness 200, damping 16: it overshoots a little before settling). When it unmounts, a copy of it springs back to 0 in its place, then goes away: your render function stays the single source of truth.
- **Radio** scales to 1.05 while hovered and to 0.95 while pressed (React Aria's `isHovered` and `isPressed`), on Motion's default spring for scale (stiffness 550, damping 30).
- Selecting with the arrow keys animates like a click.
- A radio already selected on load renders at rest: the dot is your markup, rendered by the server before any script runs.
- Under reduced motion, the dot only fades and nothing scales.
- `className` and `style` render props keep working.

## API Reference

`RadioGroup` and `Radio` take exactly the props of [React Aria's RadioGroup](https://react-spectrum.adobe.com/react-aria/RadioGroup.html#props). A `render` function of your own gets React Aria's behaviour, without the hover and press scale.

### RadioGroup

React Aria props only: nothing animates on the group itself.

### Radio

React Aria props, plus:

The hover and press scale uses Motion's default spring for scale (stiffness 550, damping 30). `AnimateUIProvider`'s `tempo` scales these transitions with everything else.
