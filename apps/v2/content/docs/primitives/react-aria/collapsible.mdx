## Usage

Import from Animate UI instead of `react-aria-components`: it re-exports all of React Aria, with an animated `DisclosurePanel`. Everything else stays the same.

```tsx
import {
  Button,
  Disclosure,
  DisclosurePanel,
} from '@animate-ui/react/primitives/react-aria';

export function Changelog() {
  return (
    <Disclosure>
      <Button slot="trigger">Show all changes</Button>
      <DisclosurePanel>
        Drop-in primitives for Radix UI, Base UI and React Aria.
      </DisclosurePanel>
    </Disclosure>
  );
}
```

## Animation

- **DisclosurePanel** grows its height and fades in over 600ms with a strong ease-out, and collapses in 400ms.
- Toggling it while it moves retargets from where it is.
- React Aria keeps a closed panel mounted with `hidden="until-found"`: the panel stays visible (and `inert`) while it collapses, then gets `hidden="until-found"` back, so find-in-page can still reveal it. A panel revealed by find-in-page opens at once, as in React Aria.
- `--disclosure-panel-height` and `--disclosure-panel-width` read `auto`: classes using them follow Motion's height.
- Under reduced motion, the height changes at once and the panel only fades.

## API Reference

Every component takes exactly the props of [React Aria's Disclosure](https://react-spectrum.adobe.com/react-aria/Disclosure.html#props). Animate UI adds the animation props below.

### Disclosure, Button

[React Aria props](https://react-spectrum.adobe.com/react-aria/Disclosure.html#props) only. They are not animated.

### DisclosurePanel

[React Aria props](https://react-spectrum.adobe.com/react-aria/Disclosure.html#disclosurepanel), plus:
