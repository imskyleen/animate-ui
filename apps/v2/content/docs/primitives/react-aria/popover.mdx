## Usage

Import from Animate UI instead of `react-aria-components`: it re-exports all of React Aria, with an animated `Popover`. Everything else stays the same.

```tsx
import {
  Button,
  Dialog,
  DialogTrigger,
  Heading,
  Popover,
} from '@animate-ui/react/primitives/react-aria';

export function SharePopover() {
  return (
    <DialogTrigger>
      <Button>Share</Button>
      <Popover placement="bottom" offset={4}>
        <Dialog>
          <Heading slot="title">Share this document</Heading>
          Anyone with the link can view it.
        </Dialog>
      </Popover>
    </DialogTrigger>
  );
}
```

`Popover` is the overlay under React Aria's `Select`, `ComboBox`, `MenuTrigger`, `SubmenuTrigger`, `DatePicker` and `PreviewTrigger` too: importing them from Animate UI animates every one of them.

## Animation

React Aria has no Animate UI v1 counterpart: the Popover moves like the closest v1 overlay.

- Under a `DialogTrigger`, a `PreviewTrigger` or a date picker, like the Radix UI and Base UI popovers: it grows from 0.8 and fades in, from the trigger (`--trigger-anchor-point`, or the side facing the trigger before React Aria measures it), on a spring (stiffness 300, damping 25) that overshoots a little; it shrinks back the same way when it closes, then unmounts.
- Under a `MenuTrigger`, a `SubmenuTrigger`, a `Select` or a `ComboBox`, like the menus: a 250ms fade and scale from 0.9 (soft ease-out), both ways. Submenus move like their menu.
- React Aria only keeps a closing popover mounted if animations are running when it closes, before Motion starts any. Animate UI tracks the same open state React Aria reads (the trigger's, or `isOpen`/`defaultOpen`) and passes `isExiting` while the exit plays, so `data-exiting` and the `isExiting` render prop stay accurate.
- Reopening while it closes picks up from where it is.
- `shouldSkipAnimation` (set by `PreviewTrigger` when swapping previews during its warmup) skips both the entrance and the exit, as React Aria intends.
- `className` and `style` functions keep working, and your own `render` function is made animatable rather than replaced.
- Open from the start (`defaultOpen` on the trigger or the Popover), it plays its entrance on page load, like v1.
- Under reduced motion, it only fades (no scale).

## API Reference

`Popover` takes exactly the props of [React Aria's Popover](https://react-spectrum.adobe.com/react-aria/Popover.html#props), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the opening, and of the closing unless `exitTransition` is set.',
      type: 'Transition',
      default:
        "{ type: 'spring', stiffness: 300, damping: 25 }; menus, selects and comboboxes: { duration: 0.25, ease: [0.215, 0.61, 0.355, 1] }",
    },
    exitTransition: {
      description: 'Transition of the closing.',
      type: 'Transition',
      default: 'transition',
    },
  }}
/>

`DialogTrigger`, `Dialog`, `OverlayArrow` and the other components take [React Aria props](https://react-spectrum.adobe.com/react-aria/Popover.html#props) only. They are not animated.
