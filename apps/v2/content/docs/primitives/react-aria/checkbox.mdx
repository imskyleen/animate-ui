## Usage

Import from Animate UI instead of `react-aria-components`: it re-exports all of React Aria, with the animated controls below. Everything else stays the same.

```tsx
import { Checkbox } from '@animate-ui/react/primitives/react-aria';

export function Terms() {
  return (
    <Checkbox defaultSelected>
      {({ isSelected }) => (
        <>
          <span data-slot="checkbox-indicator">
            {isSelected && <CheckIcon />}
          </span>
          Accept terms and conditions
        </>
      )}
    </Checkbox>
  );
}
```

React Aria lets you render the indicator yourself. Animate UI animates the content of the element marked `data-slot="checkbox-indicator"`, which is what shadcn/ui renders: add the attribute to your own indicator.

## Animation

The motion of Animate UI v1's Radix UI checkbox (v1 had no React Aria one):

- **Indicator**: the check you render inside `data-slot="checkbox-indicator"` draws itself when it mounts. Its stroke (`pathLength`) and its opacity go from 0 to 1 together in 0.2s, after a 0.2s delay, on Motion's default ease-out. When it unmounts, a copy of it erases in 0.2s in its place, then goes away: your render function stays the single source of truth, React Aria's state and render props are never delayed. Content that isn't an SVG shape fades the same way.
- **Checkbox** scales to 1.05 while hovered and to 0.95 while pressed (React Aria's `isHovered` and `isPressed`: the pointer, or Space on the keyboard), on Motion's default spring for scale (stiffness 550, damping 30).
- Checking with Space animates the same way: the state changes at once, the animation never delays it.
- A box that is already checked on load renders at rest: the check is your markup, rendered by the server before any script runs.
- Toggling again mid-animation turns back from where the check is.
- `isIndeterminate` shows the indicator like `isSelected`; an icon swapped for the indeterminate state draws without the delay, as v1's indeterminate line did. Inside a `CheckboxGroup`, each checkbox animates the same way.
- Under reduced motion, the check only fades (its stroke stays whole) and nothing scales.
- The box's own colours are the component's CSS: shadcn/ui's `transition-colors` fades them.
- `className` and `style` render props keep working.

## API Reference

`Checkbox` takes exactly the props of [React Aria's Checkbox](https://react-spectrum.adobe.com/react-aria/Checkbox.html#props), plus the props below. A `render` function of your own gets React Aria's behaviour, without the hover and press scale.

<TypeTable
  type={{
    transition: {
      description: 'Transition of the check drawing itself.',
      type: 'Transition',
      default: '{ duration: 0.2, delay: 0.2 }',
    },
    exitTransition: {
      description: 'Transition of the check erasing itself.',
      type: 'Transition',
      default: '{ duration: 0.2 }',
    },
  }}
/>

The hover and press scale uses Motion's default spring for scale (stiffness 550, damping 30). `AnimateUIProvider`'s `tempo` scales these transitions with everything else.
