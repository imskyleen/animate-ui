## Usage

Import from Animate UI instead of `react-aria-components`: it re-exports all of React Aria, with an animated `Popover`. Everything else stays the same.

```tsx
import {
  Button,
  ListBox,
  ListBoxItem,
  Popover,
  Select,
  SelectValue,
} from '@animate-ui/react/primitives/react-aria';

export function FontPicker() {
  return (
    <Select aria-label="Font" defaultValue="geist">
      <Button>
        <SelectValue />
      </Button>
      <Popover placement="bottom start" offset={4}>
        <ListBox>
          <ListBoxItem id="inter">Inter</ListBoxItem>
          <ListBoxItem id="geist">Geist</ListBoxItem>
          <ListBoxItem id="lora">Lora</ListBoxItem>
        </ListBox>
      </Popover>
    </Select>
  );
}
```

## Animation

React Aria's Select has no Animate UI v1 counterpart: its list opens in Animate UI's [Popover](/docs/primitives/react-aria/popover), which moves like v1's Dropdown Menu content under a select.

- **Popover**: the list fades and scales in from 0.9, from the trigger (`--trigger-anchor-point`), in 200ms, and closes the same way before it unmounts. Reopening while it closes picks up from where it is.
- **ListBox** and **ListBoxItem** are React Aria's, untouched: their highlight is your CSS, and shadcn/ui renders the selected check itself (`isSelected ? <Icon /> : null`), so it stays your markup.
- Opening from the keyboard animates the same way.
- Open from the start (`defaultOpen`), the list plays its entrance on page load.
- Under reduced motion, the list only fades.

## API Reference

`Select`, `SelectValue`, `ListBox`, `ListBoxItem`, `ListBoxSection`, `Header` and the other components take [React Aria props](https://react-spectrum.adobe.com/react-aria/Select.html#props) only. They are not animated.
