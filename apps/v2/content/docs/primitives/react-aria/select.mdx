## Usage

Import from Animate UI instead of `react-aria-components`: it re-exports all of React Aria, with an animated `Popover`, `ListBox`, `ListBoxItem` and `SelectionIndicator`. Everything else stays the same.

```tsx
import {
  Button,
  ListBox,
  ListBoxItem,
  Popover,
  Select,
  SelectionIndicator,
  SelectValue,
} from '@animate-ui/react/primitives/react-aria';

export function FontPicker() {
  return (
    <Select aria-label="Font" defaultValue="geist">
      <Button>
        <SelectValue />
      </Button>
      <Popover placement="bottom start" offset={4}>
        <ListBox>
          <ListBoxItem id="inter" textValue="Inter">
            Inter
            <SelectionIndicator>✓</SelectionIndicator>
          </ListBoxItem>
          <ListBoxItem id="geist" textValue="Geist">
            Geist
            <SelectionIndicator>✓</SelectionIndicator>
          </ListBoxItem>
          <ListBoxItem id="lora" textValue="Lora">
            Lora
            <SelectionIndicator>✓</SelectionIndicator>
          </ListBoxItem>
        </ListBox>
      </Popover>
    </Select>
  );
}
```

## Animation

React Aria's Select has no Animate UI v1 counterpart: its list opens in Animate UI's [Popover](/docs/primitives/react-aria/popover), which moves like v1's Dropdown Menu content under a select.

- **Popover**: the list fades and scales in from 0.9, from the trigger (`--trigger-anchor-point`), in 250ms, and closes the same way before it unmounts. Reopening while it closes picks up from where it is.
- **ListBoxItem**: one highlight glides behind the focused item (the one React Aria marks `data-focused`) on a spring (stiffness 500, damping 40), following the pointer and the arrow keys alike, like v1's menu highlight and the Radix UI and Base UI selects. React Aria focuses the selected item when the list opens, so the highlight starts on it. Moving to another item, it carries on from where it is, at its speed: however fast the pointer or the arrow keys go, there's one highlight on screen. It only fades in (200ms) when it appears from nothing. It glides on the compositor (a Web Animation of `transform`), so a busy main thread, a submenu opening for instance, doesn't stall it. When the pointer leaves the list, it stays on the last item. It wears the item's own focused background (`data-focused:bg-accent`…), read from your styles: the item's background is cleared while it's focused; its text colors stay. The highlight is rendered through the item's `render` prop: your own `render` still works. The ListBox is its own stacking context (`isolation: isolate`), so the highlight goes under the items' content, above the list's background.
- **SelectionIndicator** (the check inside an item): choosing another item holds the list still for 150ms while the check glides there, on the highlight's spring (stiffness 500, damping 40), then the list closes: the check is seen landing. A first choice (no check to glide from yet) and closing any other way (Escape, a click outside) don't wait. With `selectionMode="multiple"`, the list stays open: a selected item's check pops in from half its size out of a light blur, with a little overshoot, and shrinks back out when it's deselected. shadcn/ui renders the check as `isSelected ? <Icon /> : null`, which doesn't animate: render it in a `SelectionIndicator` instead, as the demo does. `SelectValue` renders the chosen item's content again in the trigger: the indicator renders nothing there (React Aria's own would throw outside the list). Outside Animate UI's ListBox and Menu (in a Tab, a ToggleButton…) or with your own `render`, it's React Aria's own.
- Opening from the keyboard animates the same way.
- Open from the start (`defaultOpen`), the list plays its entrance on page load.
- Under reduced motion, the list only fades; the highlight jumps from item to item instead of gliding (it still fades in when it appears); a single selection's check jumps, and a multiple selection's check only fades.

## API Reference

`Select`, `SelectValue`, `ListBoxSection`, `Header` and the other components take [React Aria props](https://react-spectrum.adobe.com/react-aria/Select.html#props) only. They are not animated.

### Popover

[React Aria props](https://react-spectrum.adobe.com/react-aria/Popover.html#props), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the opening, and of the closing unless `exitTransition` is set.',
      type: 'Transition',
      default: '{ duration: 0.25, ease: [0.215, 0.61, 0.355, 1] }',
    },
    exitTransition: {
      description: 'Transition of the closing.',
      type: 'Transition',
      default: 'transition',
    },
  }}
/>

### ListBox

[React Aria props](https://react-spectrum.adobe.com/react-aria/ListBox.html#props) only. It holds its items' highlight and lets a single selection's check glide.

### ListBoxItem

[React Aria props](https://react-spectrum.adobe.com/react-aria/ListBox.html#listboxitem) only. It takes part in the highlight; it needs nothing more.

### SelectionIndicator

[React Aria props](https://react-spectrum.adobe.com/react-aria/ListBox.html), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the check moving to the chosen item (single selection), or popping in and out (multiple).',
      type: 'Transition',
      default:
        "the highlight's spring (stiffness 500, damping 40); multiple: a spring with a little overshoot (stiffness 500, damping 24) with a 200ms fade and blur, 150ms out",
    },
  }}
/>
