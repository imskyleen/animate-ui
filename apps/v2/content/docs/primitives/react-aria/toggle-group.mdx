## Usage

Import from Animate UI instead of `react-aria-components`: it re-exports all of React Aria, with the animated controls below. Everything else stays the same. shadcn/ui's Toggle Group is React Aria's `ToggleButtonGroup`, with `ToggleButton` items.

```tsx
import {
  ToggleButton,
  ToggleButtonGroup,
} from '@animate-ui/react/primitives/react-aria';

export function Formatting() {
  return (
    <ToggleButtonGroup selectionMode="multiple" aria-label="Text formatting">
      <ToggleButton id="bold" aria-label="Bold">
        <BoldIcon />
      </ToggleButton>
      <ToggleButton id="italic" aria-label="Italic">
        <ItalicIcon />
      </ToggleButton>
      <ToggleButton id="underline" aria-label="Underline">
        <UnderlineIcon />
      </ToggleButton>
    </ToggleButtonGroup>
  );
}
```

## Animation

The motion of Animate UI v1's Radix UI toggle group (v1 had no React Aria one):

- **ToggleButton** (each item) scales to 0.97 while pressed, on Motion's default spring for scale (stiffness 550, damping 30); the selection changes on the press itself.
- **ToggleButtonGroup** with single selection (`selectionMode="single"`, React Aria's default): the selected item's surface slides to the newly selected item, on a spring (stiffness 300, damping 30), the new surface fading in as the previous one fades out while following it (v1's highlight, a shared layout animation). The first selection fades the surface in on its item; clearing the selection fades it out.
- To make shadcn/ui's surface slide without touching the component, the group draws it with its own `::before` and `::after`, behind its items, copying the selected item's background and corner radii; a small stylesheet clears the selected item's own background while it isn't hovered (hovered, its own background shows on top, as v1's item hover did over the highlight). The items' borders and `first:` / `last:` styles are untouched.
- With multiple selection there is no sliding surface: each item keeps its own colours (shadcn/ui's CSS, faded by its `transition-all`; v1 faded a highlight per item in 0.3s).
- The arrow keys only move the focus between items: nothing animates.
- Under reduced motion, there is no press scale and the surface jumps to its item (its fades still play).

## API Reference

`ToggleButtonGroup` takes exactly the props of [React Aria's ToggleButtonGroup](https://react-spectrum.adobe.com/react-aria/ToggleButtonGroup.html#props), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the surface sliding between items (single selection).',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 300, damping: 30 }",
    },
  }}
/>

Its items are [ToggleButtons](/docs/primitives/react-aria/toggle), which take React Aria's props, plus:

<TypeTable
  type={{
    transition: {
      description: 'Transition of the press scale.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 550, damping: 30 }",
    },
  }}
/>

`AnimateUIProvider`'s `tempo` scales these transitions with everything else.
