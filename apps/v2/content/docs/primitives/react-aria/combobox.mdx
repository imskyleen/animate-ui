## Usage

Import from Animate UI instead of `react-aria-components`: it re-exports all of React Aria, with an animated `Popover`, `ListBox`, `ListBoxItem`, `SelectionIndicator`, `TagList` and `Tag`. Everything else stays the same.

```tsx
import {
  ComboBox,
  Input,
  ListBox,
  ListBoxItem,
  Popover,
  SelectionIndicator,
} from '@animate-ui/react/primitives/react-aria';

const frameworks = [
  { id: 'next', name: 'Next.js' },
  { id: 'astro', name: 'Astro' },
  { id: 'sveltekit', name: 'SvelteKit' },
];

export function FrameworkPicker() {
  return (
    <ComboBox aria-label="Framework" defaultItems={frameworks}>
      <Input placeholder="Search a framework…" />
      <Popover placement="bottom start" offset={6}>
        <ListBox>
          {(item: (typeof frameworks)[number]) => (
            <ListBoxItem id={item.id} textValue={item.name}>
              {item.name}
              <SelectionIndicator>✓</SelectionIndicator>
            </ListBoxItem>
          )}
        </ListBox>
      </Popover>
    </ComboBox>
  );
}
```

### Check animation

The chosen item's check draws itself while the previous one erases itself. With `animation="pop"` on every item's SelectionIndicator, the check glides from the previous item to the chosen one instead (a first choice pops it in from half its size):

```tsx
<ListBoxItem id={item.id} textValue={item.name}>
  {item.name}
  <SelectionIndicator animation="pop">✓</SelectionIndicator>
</ListBoxItem>
```

With a multiple selection, each check pops in and shrinks back out on its own.

To pop every check of your app at once (checkboxes, menus, selects, comboboxes), set `checkAnimation="pop"` on an [`AnimateUIProvider`](/docs/installation#choose-how-checks-animate-optional) instead. The demo's Controls switch between the two.

## Animation

- **Popover**: React Aria's ComboBox has no Animate UI v1 counterpart. Its list opens in Animate UI's [Popover](/docs/primitives/react-aria/popover), which moves like v1's Dropdown Menu content under a combobox: it fades and scales in from 0.9, from the input (`--trigger-anchor-point`), in 250ms, and closes the same way before it unmounts. Reopening while it closes picks up from where it is.
- Filtering while typing is instant: items appear and disappear on the next frame, with no per-item or height animation.
- **ListBoxItem**: one highlight glides behind the focused item (the one React Aria marks `data-focused`) on a spring (stiffness 500, damping 40), following the pointer and the arrow keys alike, like v1's menu highlight and Base UI's Combobox. Moving to another item, it carries on from where it is, at its speed: however fast the pointer or the arrow keys go, there's one highlight on screen. It only fades in (200ms) when it appears from nothing. It glides on the compositor (a Web Animation of `transform`), so a busy main thread, a submenu opening for instance, doesn't stall it. When the pointer leaves the list, it stays on the last item. It wears the item's own focused background (`data-focused:bg-accent`…), read from your styles: the item's background is cleared while it's focused; its text colors stay. The highlight is rendered through the item's `render` prop: your own `render` still works. The ListBox is its own stacking context (`isolation: isolate`), so the highlight goes under the items' content, above the list's background.
- **SelectionIndicator** (the check inside an item): with a single selection, the chosen item's check draws itself like a Checkbox's check (its stroke and opacity in 0.3s on Motion's easeOut, at once) while the previous one erases itself, and the list holds still for 150ms before it closes, so the change is seen. With `animation="pop"` (or `checkAnimation="pop"` on an `AnimateUIProvider`), the check glides there instead, on the highlight's spring (stiffness 500, damping 40), and a first choice pops it in from half its size out of a 2px blur (a spring, stiffness 500, damping 24). The demo's Controls switch between the two. Choosing the item already chosen, and closing any other way (Escape, a click outside), don't wait. With `selectionMode="multiple"`, a selected item's check draws itself, and erases itself when it's deselected; with `pop`, it pops in from half its size and shrinks back out in 0.15s. shadcn/ui renders the check as `isSelected ? <Icon /> : null`, which can't animate its leaving: render a `SelectionIndicator` on every item instead, as the demos do. Outside Animate UI's ListBox and Menu (in a Tab, a ToggleButton…) or with your own `render`, it's React Aria's own.
- **Tag** (shadcn/ui's chips): a tag added to the selection pops in from half its size with a fade, on the popovers' spring (stiffness 300, damping 25). Tags already in the list when it mounts don't animate. Removing a tag is instant: React Aria drops it from the collection at once, and it's often Backspace.
- Under reduced motion, the list and new tags only fade, and the list doesn't hold; the highlight jumps from item to item instead of gliding (it still fades in when it appears); the checks only fade (a single selection's doesn't glide).

## API Reference

`ComboBox`, `Input`, `TagGroup` and the other components take [React Aria props](https://react-spectrum.adobe.com/react-aria/ComboBox.html#props) only. They are not animated.

### Popover

[React Aria props](https://react-spectrum.adobe.com/react-aria/Popover.html#props), plus:

    exitTransition: {
      description: 'Transition of the closing.',

    },

### ListBox

[React Aria props](https://react-spectrum.adobe.com/react-aria/ListBox.html#props) only. It holds its items' highlight and its checks (a single selection's glides between them with `pop`).

### ListBoxItem

[React Aria props](https://react-spectrum.adobe.com/react-aria/ListBox.html#listboxitem) only. It takes part in the highlight; it needs nothing more.

### SelectionIndicator

[React Aria props](https://react-spectrum.adobe.com/react-aria/ListBox.html), plus:

<TypeTable
  type={{
    animation: {
      description:
        "How the check shows and hides: `draw` (it draws itself and erases itself) or `pop` (it pops in from half its size and shrinks back out; a single selection's check glides to the chosen item).",
      type: "'draw' | 'pop'",

    },
  }}
/>

### TagList

[React Aria props](https://react-spectrum.adobe.com/react-aria/TagGroup.html#taglist) only. It tells its tags which were there on mount.
