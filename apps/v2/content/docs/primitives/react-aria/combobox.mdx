## Usage

Import from Animate UI instead of `react-aria-components`: it re-exports all of React Aria, with an animated `Popover`, `TagList` and `Tag`. Everything else stays the same.

```tsx
import {
  ComboBox,
  Input,
  ListBox,
  ListBoxItem,
  Popover,
} from '@animate-ui/react/primitives/react-aria';

const frameworks = [
  { id: 'next', name: 'Next.js' },
  { id: 'astro', name: 'Astro' },
  { id: 'sveltekit', name: 'SvelteKit' },
];

export function FrameworkPicker() {
  return (
    <ComboBox aria-label="Framework" defaultItems={frameworks}>
      <Input placeholder="Search a framework…" />
      <Popover placement="bottom start" offset={6}>
        <ListBox>
          {(item: (typeof frameworks)[number]) => (
            <ListBoxItem id={item.id}>{item.name}</ListBoxItem>
          )}
        </ListBox>
      </Popover>
    </ComboBox>
  );
}
```

## Animation

- **Popover**: React Aria's ComboBox has no Animate UI v1 counterpart. Its list opens in Animate UI's [Popover](/docs/primitives/react-aria/popover), which moves like v1's Dropdown Menu content under a combobox: it fades and scales in from 0.95, from the input (`--trigger-anchor-point`), in 200ms, and closes the same way before it unmounts. Reopening while it closes picks up from where it is.
- Filtering while typing is instant: items appear and disappear on the next frame, with no per-item or height animation. The focused item moved by the arrow keys is instant too.
- **Tag** (shadcn/ui's chips): a tag added to the selection fades and scales in over 600ms. Tags already in the list when it mounts don't animate. Removing a tag is instant: React Aria drops it from the collection at once, and it's often Backspace.
- **ListBox** and **ListBoxItem** are React Aria's, untouched: their highlight is your CSS, and shadcn/ui renders the selected check itself (`isSelected ? <Icon /> : null`), so it stays your markup.
- Under reduced motion, the list and new tags only fade.

## API Reference

`ComboBox`, `Input`, `ListBox`, `ListBoxItem`, `TagGroup` and the other components take [React Aria props](https://react-spectrum.adobe.com/react-aria/ComboBox.html#props) only. They are not animated.

### Popover

[React Aria props](https://react-spectrum.adobe.com/react-aria/Popover.html#props), plus:

### TagList

[React Aria props](https://react-spectrum.adobe.com/react-aria/TagGroup.html#taglist) only. It tells its tags which were there on mount.
