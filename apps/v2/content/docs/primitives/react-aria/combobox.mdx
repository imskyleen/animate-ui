## Usage

Import from Animate UI instead of `react-aria-components`: it re-exports all of React Aria, with an animated `Popover`, `ListBox`, `ListBoxItem`, `SelectionIndicator`, `TagList` and `Tag`. Everything else stays the same.

```tsx
import {
  ComboBox,
  Input,
  ListBox,
  ListBoxItem,
  Popover,
  SelectionIndicator,
} from '@animate-ui/react/primitives/react-aria';

const frameworks = [
  { id: 'next', name: 'Next.js' },
  { id: 'astro', name: 'Astro' },
  { id: 'sveltekit', name: 'SvelteKit' },
];

export function FrameworkPicker() {
  return (
    <ComboBox aria-label="Framework" defaultItems={frameworks}>
      <Input placeholder="Search a framework…" />
      <Popover placement="bottom start" offset={6}>
        <ListBox>
          {(item: (typeof frameworks)[number]) => (
            <ListBoxItem id={item.id} textValue={item.name}>
              {item.name}
              <SelectionIndicator>✓</SelectionIndicator>
            </ListBoxItem>
          )}
        </ListBox>
      </Popover>
    </ComboBox>
  );
}
```

## Animation

- **Popover**: React Aria's ComboBox has no Animate UI v1 counterpart. Its list opens in Animate UI's [Popover](/docs/primitives/react-aria/popover), which moves like v1's Dropdown Menu content under a combobox: it fades and scales in from 0.9, from the input (`--trigger-anchor-point`), in 250ms, and closes the same way before it unmounts. Reopening while it closes picks up from where it is.
- Filtering while typing is instant: items appear and disappear on the next frame, with no per-item or height animation.
- **ListBoxItem**: one highlight glides behind the focused item (the one React Aria marks `data-focused`) on a spring (stiffness 350, damping 35), following the pointer and the arrow keys alike, like v1's menu highlight and Base UI's Combobox. Moving to another item, it carries on from where it is, at its speed: however fast the pointer or the arrow keys go, there's one highlight on screen. It only fades in (200ms) when it appears from nothing. When the pointer leaves the list, it stays on the last item. It wears the item's own focused background (`data-focused:bg-accent`…), read from your styles: the item's background is cleared while it's focused; its text colors stay. The highlight is rendered through the item's `render` prop: your own `render` still works. The ListBox is its own stacking context (`isolation: isolate`), so the highlight goes under the items' content, above the list's background.
- **SelectionIndicator** (the check inside an item): with a single selection, choosing another item holds the list still for 150ms while the check glides there, on a quick spring (stiffness 500, damping 40), then the list closes: the check is seen landing. A first choice (no check to glide from yet) and closing any other way (Escape, a click outside) don't wait. With `selectionMode="multiple"`, a selected item's check pops in from half its size with a fade, like v1's checkbox check, and goes at once when it's deselected. shadcn/ui renders the check as `isSelected ? <Icon /> : null`, which doesn't animate: render it in a `SelectionIndicator` instead, as the demos do. Outside Animate UI's ListBox (in a Tab, a ToggleButton…) or with your own `render`, it's React Aria's own.
- **Tag** (shadcn/ui's chips): a tag added to the selection pops in from half its size with a fade, on the popovers' spring (stiffness 300, damping 25). Tags already in the list when it mounts don't animate. Removing a tag is instant: React Aria drops it from the collection at once, and it's often Backspace.
- Under reduced motion, the list and new tags only fade; the highlight jumps from item to item instead of gliding (it still fades in when it appears); a single selection's check jumps, and a multiple selection's check only fades.

## API Reference

`ComboBox`, `Input`, `TagGroup` and the other components take [React Aria props](https://react-spectrum.adobe.com/react-aria/ComboBox.html#props) only. They are not animated.

### Popover

[React Aria props](https://react-spectrum.adobe.com/react-aria/Popover.html#props), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the opening, and of the closing unless `exitTransition` is set.',
      type: 'Transition',
      default: '{ duration: 0.25, ease: [0.215, 0.61, 0.355, 1] }',
    },
    exitTransition: {
      description: 'Transition of the closing.',
      type: 'Transition',
      default: 'transition',
    },
  }}
/>

### ListBox

[React Aria props](https://react-spectrum.adobe.com/react-aria/ListBox.html#props) only. It holds its items' highlight and lets a single selection's check glide.

### ListBoxItem

[React Aria props](https://react-spectrum.adobe.com/react-aria/ListBox.html#listboxitem) only. It takes part in the highlight; it needs nothing more.

### SelectionIndicator

[React Aria props](https://react-spectrum.adobe.com/react-aria/ListBox.html), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the check moving to the chosen item (single selection), or popping in (multiple).',
      type: 'Transition',
      default:
        "a spring (stiffness 500, damping 40); multiple: Motion's defaults, as v1's checkbox check, a spring (stiffness 550, damping 30) and a 300ms fade",

  }}
/>

### TagList

[React Aria props](https://react-spectrum.adobe.com/react-aria/TagGroup.html#taglist) only. It tells its tags which were there on mount.
