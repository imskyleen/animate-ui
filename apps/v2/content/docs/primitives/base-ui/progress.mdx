## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same.

```tsx
import { Progress } from '@animate-ui/react/primitives/base-ui/progress';

export function Upload({ value }: { value: number }) {
  return (
    <Progress.Root value={value}>
      <Progress.Label>Uploading</Progress.Label>
      <Progress.Value />
      <Progress.Track className="h-2 overflow-hidden rounded-full">
        <Progress.Indicator className="bg-primary" />
      </Progress.Track>
    </Progress.Root>
  );
}
```

## Animation

- **Indicator**: Base UI sizes it with a percentage `width`. Animate UI keeps it full width and reveals the value with an animated `transform` instead (no layout on every frame); the track clips it, as shadcn/ui's `overflow-x-hidden` track does. Right-to-left (`DirectionProvider`) is handled.
- It moves with `spring.snappy` without bounce (600ms): progress often updates in bursts, and a spring keeps its velocity when a new value retargets it. No overshoot, which would uncover the start of the track.
- It starts at its value on mount, with no animation.
- Indeterminate (`value={null}`): the indicator is left to your styles.
- shadcn/ui's `transition-all` on the indicator would run on top of Motion: the CLI removes it.
- Under reduced motion, the indicator jumps to each value.

## API Reference

Every part takes exactly the props of [Base UI's Progress](https://base-ui.com/react/components/progress#api-reference). Animate UI adds the animation props below.

### Root, Track, Value, Label

[Base UI props](https://base-ui.com/react/components/progress#root) only.

### Indicator

[Base UI props](https://base-ui.com/react/components/progress#indicator), plus:

<TypeTable
  type={{
    transition: {
      description: 'Transition of the indicator moving to a new value.',
      type: 'Transition',
      default: 'spring.snappy without bounce (600ms)',
    },
  }}
/>

The Indicator renders through Base UI's `render` prop: a `render` of your own replaces the animated element.
