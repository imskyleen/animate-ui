## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same.

```tsx
import { Progress } from '@animate-ui/react/primitives/base-ui/progress';

export function Upload({ value }: { value: number }) {
  return (
    <Progress.Root value={value}>
      <Progress.Label>Uploading</Progress.Label>
      <Progress.Value />
      <Progress.Track className="h-2 overflow-hidden rounded-full">
        <Progress.Indicator className="bg-primary" />
      </Progress.Track>
    </Progress.Root>
  );
}
```

Using the `@base-ui/react` umbrella import instead? The barrel mirrors it: `import { Progress } from '@animate-ui/react/primitives/base-ui'`.

## Animation

The motion of Animate UI v1's progress:

- **Indicator**: Base UI sizes it with a percentage `width`, and its width springs to each new value (stiffness 100, damping 30: no overshoot), as v1's did. Right-to-left works as Base UI lays it out (`inset-inline-start`).
- **Value** counts to each new value on the bar's own spring (stiffness 100, damping 30), so the number moves with the bar, formatted as Base UI formats it (a percentage, or your `format` and `locale`), from 0 when it appears, as v1's counting value did. A `children` function gets the counted text and number.
- The indicator starts at its value on mount, with no animation.
- Indeterminate (`value={null}`): the indicator is left to your styles, and the Value to Base UI.
- shadcn/ui's `transition-all` on the indicator would run on top of Motion: the CLI removes it.
- Under reduced motion, the indicator jumps to each value (the Value still counts).
- Without a `locale`, Base UI formats the numbers (the Value, `aria-valuetext`) in the runtime's locale: the server's on the server and the browser's in the browser, so a page rendered in English and opened in another language didn't hydrate cleanly ("13%" against "13 %"). Animate UI formats them in en-US on the server and while the page hydrates, then in the browser's locale, as React Aria does. Pass `locale` to pick one yourself.

## API Reference

Every part takes exactly the props of [Base UI's Progress](https://base-ui.com/react/components/progress#api-reference). Animate UI adds the animation props below.

### Root, Track, Label

[Base UI props](https://base-ui.com/react/components/progress#root) only.

### Indicator

[Base UI props](https://base-ui.com/react/components/progress#indicator), plus:

<TypeTable
  type={{
    transition: {
      description: 'Transition of the indicator moving to a new value.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 100, damping: 30 }",
    },
  }}
/>

### Value

[Base UI props](https://base-ui.com/react/components/progress#value), plus:

<TypeTable
  type={{
    transition: {
      description: 'Transition of the number counting to a new value.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 100, damping: 30 }",
    },
  }}
/>

`AnimateUIProvider`'s `tempo` scales these transitions with everything else.
