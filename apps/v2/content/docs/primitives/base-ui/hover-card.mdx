## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same.

```tsx
import { PreviewCard } from '@animate-ui/react/primitives/base-ui/preview-card';

export function ProfileLink() {
  return (
    <PreviewCard.Root>
      <PreviewCard.Trigger href="https://github.com/imskyleen/animate-ui">
        @animate-ui
      </PreviewCard.Trigger>
      <PreviewCard.Portal>
        <PreviewCard.Positioner sideOffset={4}>
          <PreviewCard.Popup>
            Animated drop-in primitives for Radix UI, Base UI and React Aria.
          </PreviewCard.Popup>
        </PreviewCard.Positioner>
      </PreviewCard.Portal>
    </PreviewCard.Root>
  );
}
```

Using the `@base-ui/react` umbrella import instead? The barrel mirrors it: `import { PreviewCard } from '@animate-ui/react/primitives/base-ui'`.

## Animation

The motion of Animate UI v1's Base UI Preview Card, value for value:

- **Popup** grows from 0.8 and fades in, from the trigger (`--transform-origin`), on a spring (stiffness 300, damping 25) that overshoots a little before it settles.
- Once the trigger's `closeDelay` is over, it closes the same way: it shrinks back to 0.8 on the same spring while it fades out, then unmounts.
- Base UI only opens it on hover for mouse-like pointers: nothing sticks on touch screens.
- With `keepMounted` on the Portal, the closed popup stays in the DOM: it plays its exit, then is hidden.
- Your own `render` element (or function) on the Popup is made animatable rather than replaced.
- Reopening while it closes picks up from where it is, on the same spring.
- Open from the start (`defaultOpen`), it plays the same entrance on page load, like v1.
- Under reduced motion, it only fades (no scale).

## API Reference

Every part takes exactly the props of [Base UI's Preview Card](https://base-ui.com/react/components/preview-card#api-reference). Animate UI adds the animation props below.

### Root, Trigger, Portal, Positioner, Arrow, Backdrop, Viewport

[Base UI props](https://base-ui.com/react/components/preview-card#root) only. They are not animated.

### Popup

[Base UI props](https://base-ui.com/react/components/preview-card#popup), plus:
