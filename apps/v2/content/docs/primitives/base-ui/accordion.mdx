## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same.

```tsx
import { Accordion } from '@animate-ui/react/primitives/base-ui/accordion';

export function FAQ() {
  return (
    <Accordion.Root defaultValue={['item-1']}>
      <Accordion.Item value="item-1">
        <Accordion.Header>
          <Accordion.Trigger>Is it accessible?</Accordion.Trigger>
        </Accordion.Header>
        <Accordion.Panel>
          Yes. It adheres to the WAI-ARIA design pattern.
        </Accordion.Panel>
      </Accordion.Item>
    </Accordion.Root>
  );
}
```

## Animation

- **Panel** grows its height and fades in over 600ms with a strong ease-out, and collapses in 400ms before it unmounts.
- Opening another item while one is closing retargets smoothly.
- Motion animates the panel itself: shadcn/ui's `h-(--accordion-panel-height) data-starting-style:h-0 data-ending-style:h-0` classes are no longer needed (the CLI removes them). `--accordion-panel-height` and `--accordion-panel-width` read `auto`.
- `keepMounted` and `hiddenUntilFound`, on the Root or a Panel, keep closed panels in the DOM: they collapse, then get Base UI's `hidden` (or `hidden="until-found"`, which find-in-page can reveal; a panel revealed that way opens at once, as in Base UI).
- An `onValueChange` that calls `eventDetails.cancel()` still cancels the change.
- Under reduced motion, the height changes at once and the panel only fades.

## API Reference

Every part takes exactly the props of [Base UI's Accordion](https://base-ui.com/react/components/accordion#api-reference). Animate UI adds the animation props below.

### Root, Item, Header, Trigger

[Base UI props](https://base-ui.com/react/components/accordion#root) only. They are not animated.

### Panel

[Base UI props](https://base-ui.com/react/components/accordion#panel), plus:

<TypeTable
  type={{
    transition: {
      description: 'Transition of the opening.',
      type: 'Transition',
      default: 'transition.disclosure (600ms, ease-out)',
    },
    exitTransition: {
      description: 'Transition of the closing.',
      type: 'Transition',
      default: 'transition.exit (400ms, ease-out)',
    },
  }}
/>

A `render` element (or function) of your own is made animatable with `motion.create`.
