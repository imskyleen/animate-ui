## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same. shadcn/ui's Toggle Group uses two Base UI modules, `toggle-group` and `toggle` (its items): import both from Animate UI.

```tsx
import { Toggle } from '@animate-ui/react/primitives/base-ui/toggle';
import { ToggleGroup } from '@animate-ui/react/primitives/base-ui/toggle-group';

export function Alignment() {
  return (
    <ToggleGroup defaultValue={['left']} aria-label="Text alignment">
      <Toggle value="left" aria-label="Align left">
        <AlignLeftIcon />
      </Toggle>
      <Toggle value="center" aria-label="Align center">
        <AlignCenterIcon />
      </Toggle>
      <Toggle value="right" aria-label="Align right">
        <AlignRightIcon />
      </Toggle>
    </ToggleGroup>
  );
}
```

Using the `@base-ui/react` umbrella import instead? The barrel mirrors it: `import { Toggle, ToggleGroup } from '@animate-ui/react/primitives/base-ui'`.

## Animation

The motion of Animate UI v1's toggle group:

- **Toggle** (each item) scales to 0.95 while pressed, on Motion's default spring for scale (stiffness 550, damping 30); the selection changes on the press itself.
- **ToggleGroup** with single selection (no `multiple`): the selected item's surface slides to the newly selected item, on a spring (stiffness 200, damping 25), the new surface fading in as the previous one fades out while following it (v1's highlight, a shared layout animation). The first selection fades the surface in on its item; clearing the selection fades it out.
- To make shadcn/ui's surface slide without touching the component, the group draws it with its own `::before` and `::after`, behind its items, copying the selected item's background and corner radii; a small stylesheet clears the selected item's own background while it isn't hovered (hovered, its own background shows on top, as v1's item hover did over the highlight). The items' borders and `first:` / `last:` styles are untouched.
- With multiple selection there is no sliding surface: each item keeps its own colours (shadcn/ui's CSS, faded by its `transition-all`; v1 faded a highlight per item in 0.3s).
- The arrow keys only move the focus between items: nothing animates.
- Under reduced motion, there is no press scale and the surface jumps to its item (its fades still play).

## API Reference

`ToggleGroup` takes exactly the props of [Base UI's Toggle Group](https://base-ui.com/react/components/toggle-group#api-reference), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the surface sliding between items (single selection).',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 200, damping: 25 }",
    },
  }}
/>

Its items are [Toggles](/docs/primitives/base-ui/toggle), which take Base UI's props, plus:

<TypeTable
  type={{
    transition: {
      description: 'Transition of the press scale.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 550, damping: 30 }",
    },
  }}
/>

`AnimateUIProvider`'s `tempo` scales these transitions with everything else.
