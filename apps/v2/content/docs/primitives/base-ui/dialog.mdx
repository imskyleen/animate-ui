## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same, types included (`Dialog.Popup.Props`, `Dialog.Root.ChangeEventDetails`…).

```tsx
import { Dialog } from '@animate-ui/react/primitives/base-ui/dialog';

export function EditProfile() {
  return (
    <Dialog.Root>
      <Dialog.Trigger>Edit profile</Dialog.Trigger>
      <Dialog.Portal>
        <Dialog.Backdrop />
        <Dialog.Popup>
          <Dialog.Title>Edit profile</Dialog.Title>
          <Dialog.Description>
            Make changes to your profile here.
          </Dialog.Description>
          <Dialog.Close>Save</Dialog.Close>
        </Dialog.Popup>
      </Dialog.Portal>
    </Dialog.Root>
  );
}
```

Using the `@base-ui/react` umbrella import instead? The barrel mirrors it: `import { Dialog } from '@animate-ui/react/primitives/base-ui'`.

## Sheet

shadcn/ui's Sheet is the same primitive: its popup carries `data-side`, and the Dialog then slides it in from that edge, fading in, like Animate UI v1's Sheet, instead of tipping it in. Add it with `shadcn add sheet`, then animate it with `animate-ui animate sheet`.

## Animation

Animate UI v1's dialog motion, with a smoother overlay and a quicker exit.

- **Backdrop** fades in from nothing to what its classes set: its background color deepens while its backdrop filter grows, so the page behind blurs progressively from 0 (fading its opacity would cross-fade the sharp page with an already blurred one). Over 400ms on a soft ease-out, along with the popup's fade, and it leaves the same way.
- **Popup** tips forward into place, around its center: it starts from `perspective(500px) rotateX(-20deg) scale(0.8)`, transparent and blurred (4px), and comes upright and sharp on a spring (stiffness 150, damping 25), fading in ahead of it with the backdrop (400ms on a soft ease-out): it's there first, then it settles. Dismissed, it goes back the way it came, at once, quicker and speeding away (0.2s, a steady push from half its average speed to one and a half), out of sight just before the backdrop has cleared, then unmounts.
- `from` picks the edge the popup tips from, as in v1: `top` by default (`rotateX(-20deg)`), `bottom` (`rotateX(20deg)`), `left` (`rotateY(20deg)`) or `right` (`rotateY(-20deg)`) (a sheet, with `data-side`, slides from its side instead).
- With `data-side="top" | "right" | "bottom" | "left"` (shadcn/ui's Sheet), the popup slides in from that edge by its own size and fades in, in 0.4s on a soft ease-out (`cubic-bezier(0.215, 0.61, 0.355, 1)`): it answers at once and slows down all the way in. Unlike a drawer it doesn't go past its rest: held against the screen's edge, it would open a gap there. Dismissed, it leaves like a dialog, at once, quicker than it came and speeding off its edge (0.2s, a steady push), fading out.
- On the backdrop, `exitTransition` defaults to `transition`: change `transition` and both directions follow, as in v1. A dialog's or a sheet's own exit is the quicker one above unless you set `exitTransition`.
- Base UI decides a closed popup is done before Motion's exit has started. The Portal keeps Base UI's portal mounted and the popup visible until the exit is over; clicks go through to the page as soon as it closes.
- Reopening while it closes picks up from where it is.
- `eventDetails.cancel()` in `onOpenChange` keeps it open, detached triggers (`handle`) open it, and opening from the keyboard animates the same way.
- With `keepMounted` on the Portal, the closed popup stays in the DOM: it plays its exit, then Base UI hides it.
- Your own `render` element (or function) on the Backdrop or the Popup is made animatable rather than replaced.
- Under reduced motion, the popup fades and un-blurs without tilting, scaling or sliding.
- `AnimateUIProvider tempo` scales every duration and spring.

## API Reference

Every part takes exactly the props of [Base UI's Dialog](https://base-ui.com/react/components/dialog#api-reference). Animate UI adds the animation props below.

### Root, Trigger, Portal, Viewport, Title, Description, Close

[Base UI props](https://base-ui.com/react/components/dialog#root) only. They are not animated.

### Backdrop

[Base UI props](https://base-ui.com/react/components/dialog#backdrop), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the fade in (background color and backdrop filter).',
      type: 'Transition',
      default: '{ duration: 0.4, ease: [0.215, 0.61, 0.355, 1] }',
    },
    exitTransition: {
      description: 'Transition of the fade out.',
      type: 'Transition',
      default: 'transition',
    },
  }}
/>

### Popup

[Base UI props](https://base-ui.com/react/components/dialog#popup), plus:

<TypeTable
  type={{
    from: {
      description:
        'The edge the popup tips from as it comes in, as in v1. Ignored by a sheet (data-side).',
      type: "'top' | 'bottom' | 'left' | 'right'",
      default: "'top'",
    },
    transition: {
      description:
        'Transition of the opening. One you pass drives its fade too.',
      type: 'Transition',
      default:
        "{ type: 'spring', stiffness: 150, damping: 25, opacity: { duration: 0.4, ease: [0.215, 0.61, 0.355, 1] } }; with data-side: { duration: 0.4, ease: [0.215, 0.61, 0.355, 1] }",
    },
    exitTransition: {
      description: 'Transition of the closing.',
      type: 'Transition',
      default: '{ duration: 0.2, ease: [0.33, 0.17, 0.67, 0.5] }',
    },
  }}
/>
