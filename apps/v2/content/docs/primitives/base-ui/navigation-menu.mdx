## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same.

```tsx
import { NavigationMenu } from '@animate-ui/react/primitives/base-ui/navigation-menu';

export function SiteNav() {
  return (
    <NavigationMenu.Root>
      <NavigationMenu.List>
        <NavigationMenu.Item>
          <NavigationMenu.Trigger>Learn</NavigationMenu.Trigger>
          <NavigationMenu.Content>
            <NavigationMenu.Link href="/docs">
              Documentation
            </NavigationMenu.Link>
          </NavigationMenu.Content>
        </NavigationMenu.Item>
      </NavigationMenu.List>
      <NavigationMenu.Portal>
        <NavigationMenu.Positioner sideOffset={8}>
          <NavigationMenu.Popup className="h-(--popup-height) w-(--popup-width)">
            <NavigationMenu.Viewport />
          </NavigationMenu.Popup>
        </NavigationMenu.Positioner>
      </NavigationMenu.Portal>
    </NavigationMenu.Root>
  );
}
```

Using the `@base-ui/react` umbrella import instead? The barrel mirrors it: `import { NavigationMenu } from '@animate-ui/react/primitives/base-ui'`.

## Animation

Base UI's Navigation Menu has no Animate UI v1 counterpart: it moves like v1's Base UI Menu.

- **Popup** fades and scales in from 0.9, from its trigger (`--transform-origin`), in 250ms (`{ duration: 0.25, ease: [0.215, 0.61, 0.355, 1] }`, a soft ease-out), and closes the same way; Base UI keeps it mounted until then, and Animate UI unmounts it once the exit has played.
- Moving from one item to another, the Popup's size follows the new content in 250ms with the same curve: Base UI resizes it through `--popup-width`/`--popup-height`, and Animate UI sets the CSS transition of `width` and `height` inline (Base UI waits for it before it sets the size back to auto). The Positioner keeps its own transition.
- **Content** fades in from a 4px blur, in 250ms, when moving between items, while the previous one fades out into a blur: the swap reads as one surface changing. On the first opening, the Popup's entrance is enough.
- Keyboard navigation between links and triggers moves focus only: nothing animates.
- An item open from the start (`defaultValue`) shows with the Popup's entrance on page load.
- Under reduced motion, everything only fades and sizes change at once.

## API Reference

Every part takes exactly the props of [Base UI's Navigation Menu](https://base-ui.com/react/components/navigation-menu#api-reference). Animate UI adds the animation props below. The `render` prop of the Popup and the Content is used by the animation.

### Root, List, Item, Trigger, Link, Icon, Portal, Positioner, Viewport, Backdrop, Arrow

[Base UI props](https://base-ui.com/react/components/navigation-menu#api-reference) only. They are not animated.

### Popup

[Base UI props](https://base-ui.com/react/components/navigation-menu#popup), plus:
