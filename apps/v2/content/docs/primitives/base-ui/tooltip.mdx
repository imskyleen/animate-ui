## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same.

```tsx
import { Tooltip } from '@animate-ui/react/primitives/base-ui/tooltip';

export function BoldButton() {
  return (
    <Tooltip.Provider delay={0}>
      <Tooltip.Root>
        <Tooltip.Trigger aria-label="Bold">B</Tooltip.Trigger>
        <Tooltip.Portal>
          <Tooltip.Positioner sideOffset={4}>
            <Tooltip.Popup>
              Bold
              <Tooltip.Arrow />
            </Tooltip.Popup>
          </Tooltip.Positioner>
        </Tooltip.Portal>
      </Tooltip.Root>
    </Tooltip.Provider>
  );
}
```

Using the `@base-ui/react` umbrella import instead? The barrel mirrors it: `import { Tooltip } from '@animate-ui/react/primitives/base-ui'`.

## Animation

The motion of Animate UI v1's Base UI Tooltip, starting from 0.7, with a warm-up:

- **Popup** grows from 0.7 and fades in, from the trigger (`--transform-origin`), on a spring (stiffness 400, damping 29) that overshoots a little before it settles.
- It closes the same way: it shrinks back to 0.7 on the same spring while it fades out, then unmounts.
- Tooltips warm up: once one is open, moving along a toolbar shows the next one at once, without its entrance, and hides the previous one at once. 300ms after the last one closed, the next one plays its entrance again. shadcn/ui gives each tooltip its own Provider, so the library's own grouping never sees it: Animate UI tracks it across all of its tooltips.
- Base UI only opens it on hover for mouse-like pointers, and on keyboard focus.
- With `keepMounted` on the Portal, the closed popup stays in the DOM: it plays its exit, then is hidden.
- Your own `render` element (or function) on the Popup is made animatable rather than replaced.
- Open from the start (`defaultOpen`), it plays the same entrance on page load, like v1.
- With `followCursor` on the Root, the popup leans towards the pointer while it moves over the trigger, by half its offset from the trigger's center, on a spring (stiffness 200, damping 17): on both axes, or only `'x'` or `'y'`, as in v1. Under reduced motion it follows without the spring.
- Under reduced motion, it only fades (no scale).

## API Reference

Every part takes exactly the props of [Base UI's Tooltip](https://base-ui.com/react/components/tooltip#api-reference). Animate UI adds the animation props below.

### Root

[Base UI props](https://base-ui.com/react/components/tooltip#root), plus:

<TypeTable
  type={{
    followCursor: {
      description:
        'Make the popup follow the pointer over the trigger, on both axes or only one, as in Animate UI v1.',
      type: "boolean | 'x' | 'y'",
      default: 'false',
    },
    followCursorSpringOptions: {
      description: 'The spring the popup follows the pointer on.',
      type: 'SpringOptions',
      default: '{ stiffness: 200, damping: 17 }',
    },
  }}
/>

### Provider, Trigger, Portal, Positioner, Arrow, Viewport

[Base UI props](https://base-ui.com/react/components/tooltip#provider) only. They are not animated.

### Popup

[Base UI props](https://base-ui.com/react/components/tooltip#popup), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the opening, and of the closing unless `exitTransition` is set.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 400, damping: 29 }",
    },
    exitTransition: {
      description: 'Transition of the closing.',
      type: 'Transition',
      default: 'transition',
    },
  }}
/>
