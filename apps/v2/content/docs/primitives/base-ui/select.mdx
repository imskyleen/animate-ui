## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same.

```tsx
import { Select } from '@animate-ui/react/primitives/base-ui/select';

const fonts = [
  { label: 'Inter', value: 'inter' },
  { label: 'Geist', value: 'geist' },
];

export function FontPicker() {
  return (
    <Select.Root items={fonts} defaultValue="geist">
      <Select.Trigger aria-label="Font">
        <Select.Value />
        <Select.Icon />
      </Select.Trigger>
      <Select.Portal>
        <Select.Positioner alignItemWithTrigger={false} sideOffset={4}>
          <Select.Popup>
            <Select.List>
              {fonts.map((font) => (
                <Select.Item key={font.value} value={font.value}>
                  <Select.ItemText>{font.label}</Select.ItemText>
                  <Select.ItemIndicator>✓</Select.ItemIndicator>
                </Select.Item>
              ))}
            </Select.List>
          </Select.Popup>
        </Select.Positioner>
      </Select.Portal>
    </Select.Root>
  );
}
```

Using the `@base-ui/react` umbrella import instead? The barrel mirrors it: `import { Select } from '@animate-ui/react/primitives/base-ui'`.

## Animation

Base UI's Select has no Animate UI v1 counterpart: it moves like v1's Base UI Menu.

- **Popup** fades and scales in from 0.9, from the trigger (`--transform-origin`), in 250ms (`{ duration: 0.25, ease: [0.215, 0.61, 0.355, 1] }`, a soft ease-out), and closes the same way; then Base UI unmounts it (or hides it, when it keeps the items mounted for typeahead on the closed trigger).
- With `alignItemWithTrigger` (Base UI's default), the list is laid over the trigger with the selected item on the value, like a native select: it only fades.
- **The highlight**: one surface glides behind the highlighted item on a spring (stiffness 350, damping 35), following the pointer and the arrow keys alike, like v1's menu highlight. Moving to another item, it carries on from where it is, at its speed: however fast the pointer or the arrow keys go, there's one highlight on screen. It only fades in (200ms) when it appears from nothing. When the pointer leaves the list, it stays on the last item. It wears the item's own highlighted background (`focus:bg-accent`, `data-highlighted:bg-accent`…), read from your styles: the item's background is cleared while it's highlighted; its text colors stay.
- **ItemIndicator**: with a single value, choosing another item moves the check there while the list closes, like v1's radio indicator. With `multiple`, the list stays open: a selected item's check pops in from half its size with a fade, like v1's checkbox check, and goes at once when it's deselected.
- Reopening while the list is closing picks up from where it is.
- Base UI's Select has no `keepMounted`: Animate UI passes an `actionsRef` to the Root and unmounts the popup when its exit is over. Your own `actionsRef` still works, and `onOpenChangeComplete` fires after the entrance and after the exit.
- Open from the start (`defaultOpen`), the list plays its entrance on page load.
- Under reduced motion, nothing scales or glides: the popup and the checks only fade; the highlight jumps from item to item and only fades in when it appears.

## API Reference

Every part takes exactly the props of [Base UI's Select](https://base-ui.com/react/components/select#api-reference). Animate UI adds the animation props below.

### Root, Trigger, Value, Icon, Portal, Backdrop, Positioner, List, ItemText, Group, GroupLabel, Separator, ScrollUpArrow, ScrollDownArrow, Arrow, Label

[Base UI props](https://base-ui.com/react/components/select#root) only. They are not animated.

### Item

[Base UI props](https://base-ui.com/react/components/select#item) only. It takes part in the highlight; it needs nothing more.

### Popup

[Base UI props](https://base-ui.com/react/components/select#popup), except `render` (Animate UI renders the popup as a `motion.div`), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the opening, and of the closing unless `exitTransition` is set.',
      type: 'Transition',
      default: '{ duration: 0.25, ease: [0.215, 0.61, 0.355, 1] }',
    },
    exitTransition: {
      description: 'Transition of the closing.',
      type: 'Transition',
      default: 'transition',
    },
  }}
/>

### ItemIndicator

[Base UI props](https://base-ui.com/react/components/select#item-indicator), plus:

<TypeTable
  type={{

      type: 'Transition',

        "Motion's defaults, as in v1: a 450ms move; multiple: a spring (stiffness 550, damping 30) and a 300ms fade",
    },
  }}
/>
