## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same.

```tsx
import { Menu } from '@animate-ui/react/primitives/base-ui/menu';

export function AccountMenu() {
  return (
    <Menu.Root>
      <Menu.Trigger>Account</Menu.Trigger>
      <Menu.Portal>
        <Menu.Positioner sideOffset={4}>
          <Menu.Popup>
            <Menu.Item>Profile</Menu.Item>
            <Menu.Item>Billing</Menu.Item>
            <Menu.Separator />
            <Menu.Item>Log out</Menu.Item>
          </Menu.Popup>
        </Menu.Positioner>
      </Menu.Portal>
    </Menu.Root>
  );
}
```

Using the `@base-ui/react` umbrella import instead? The barrel mirrors it: `import { Menu } from '@animate-ui/react/primitives/base-ui'`.

shadcn/ui's Dropdown Menu is built on it.

## Animation

The motion of Animate UI v1's Base UI Menu:

- **Popup** fades and scales in from 0.9, from the trigger (`--transform-origin`, set inline so it works without styles), in 250ms (`{ duration: 0.25, ease: [0.215, 0.61, 0.355, 1] }`, a soft ease-out), and closes the same way. Submenu popups grow from the side of their trigger the same way.
- Base UI keeps the popup mounted after it closes, and Animate UI unmounts it once the exit has played (`onOpenChangeComplete` fires then).
- **The highlight**: one surface glides behind the highlighted item on a spring (stiffness 350, damping 35), following the pointer and the arrow keys alike, and into submenus. Moving to another item, it carries on from where it is, at its speed: however fast the pointer or the arrow keys go, there's one highlight on screen. It only fades in (200ms) when it appears from nothing. When the pointer leaves the menu, it stays on the last item. It wears the item's own highlighted background (`focus:bg-accent`, `data-highlighted:bg-accent`…), read from your styles: the item's background is cleared while it's highlighted, or while its submenu is open; its text colors stay.
- **CheckboxItemIndicator** pops in from half its size with a fade whenever it appears (checking the item, or opening the menu) and goes at once when unchecked. **RadioItemIndicator** glides to the newly checked item (when choosing it closes the menu, it glides while the menu fades out, as in v1).
- When the menu closes with focus inside, focus goes back to the trigger at once instead of after the exit, and the leaving popup ignores the pointer.
- With `keepMounted` on the Portal, the closed popup stays in the DOM and Base UI hides it after the exit.
- Open from the start (`defaultOpen`), the menu plays its entrance on page load, like v1.
- Under reduced motion, nothing scales or glides: the menu only fades; the highlight jumps from item to item and only fades in when it appears.

## API Reference

Every part takes exactly the props of [Base UI's Menu](https://base-ui.com/react/components/menu#api-reference). Animate UI adds the animation props below. The Popup's `render` prop is used by the animation.

### Root, SubmenuRoot, Trigger, Portal, Positioner, Group, GroupLabel, RadioGroup, Separator, Arrow, Backdrop, Viewport

[Base UI props](https://base-ui.com/react/components/menu#api-reference) only. They are not animated.

### Item, LinkItem, CheckboxItem, RadioItem, SubmenuTrigger

[Base UI props](https://base-ui.com/react/components/menu#api-reference) only. They take part in the highlight; it needs nothing more.

### Popup

[Base UI props](https://base-ui.com/react/components/menu#popup), plus:

<TypeTable
  type={{
