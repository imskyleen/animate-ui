## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same, types included.

```tsx
import { AlertDialog } from '@animate-ui/react/primitives/base-ui/alert-dialog';

export function DeleteProject() {
  return (
    <AlertDialog.Root>
      <AlertDialog.Trigger>Delete project</AlertDialog.Trigger>
      <AlertDialog.Portal>
        <AlertDialog.Backdrop />
        <AlertDialog.Popup>
          <AlertDialog.Title>Delete this project?</AlertDialog.Title>
          <AlertDialog.Description>
            This action cannot be undone.
          </AlertDialog.Description>
          <AlertDialog.Close>Cancel</AlertDialog.Close>
        </AlertDialog.Popup>
      </AlertDialog.Portal>
    </AlertDialog.Root>
  );
}
```

Using the `@base-ui/react` umbrella import instead? The barrel mirrors it: `import { AlertDialog } from '@animate-ui/react/primitives/base-ui'`.

## Animation

Animate UI v1's alert dialog motion, with a smoother overlay and a quicker exit.

- **Backdrop** fades in from nothing to what its classes set: its background color deepens while its backdrop filter grows, so the page behind blurs progressively from 0 (fading its opacity would cross-fade the sharp page with an already blurred one). In 400ms on CSS's `ease` (`cubic-bezier(0.25, 0.1, 0.25, 1)`), which starts and lands gently, so the page never changes all at once, on the first frame or on the last; it clears the same way in 250ms once the popup is dismissed. Its blur grows as it's seen: the eye sees most of a blur in its first pixel, so its radius rises slowly at first, and what's seen of the blur keeps pace with the tint.
- **Popup** tips forward into place, around its center: it starts from `perspective(500px) rotateX(-20deg) scale(0.8)`, transparent and blurred (4px), and comes upright and sharp on a spring (stiffness 150, damping 25), fading in ahead of it (400ms on a soft ease-out), and ahead of the backdrop: it's there first, then it settles. Dismissed, it goes back the way it came, at once, quicker and speeding away (0.2s, a steady push from half its average speed to one and a half), out of sight just before the backdrop has cleared, then unmounts.
- `from` picks the edge the popup tips from, as in v1: `top` by default (`rotateX(-20deg)`), `bottom` (`rotateX(20deg)`), `left` (`rotateY(20deg)`) or `right` (`rotateY(-20deg)`).
- Each part leaves its own way unless you set its `exitTransition`: the backdrop clears in 250ms, the dialog speeds away in 0.2s.
- The Portal keeps Base UI's portal mounted and the popup visible until the exit is over; clicks go through to the page as soon as it closes.
- Reopening while it closes picks up from where it is.
- With `keepMounted` on the Portal, the closed popup stays in the DOM: it plays its exit, then Base UI hides it.
- Your own `render` element (or function) on the Backdrop or the Popup is made animatable rather than replaced.
- Under reduced motion, the popup fades and un-blurs without tilting or scaling.
- `AnimateUIProvider tempo` scales every duration and spring.

## API Reference

Every part takes exactly the props of [Base UI's Alert Dialog](https://base-ui.com/react/components/alert-dialog#api-reference). Animate UI adds the animation props below.

### Root, Trigger, Portal, Viewport, Title, Description, Close

[Base UI props](https://base-ui.com/react/components/alert-dialog#root) only. They are not animated.

### Backdrop

[Base UI props](https://base-ui.com/react/components/alert-dialog#backdrop), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the fade in (background color and backdrop filter).',
      type: 'Transition',
      default: '{ duration: 0.4, ease: [0.25, 0.1, 0.25, 1] }',
    },
    exitTransition: {
      description: 'Transition of the fade out.',
      type: 'Transition',
      default: '{ duration: 0.25, ease: [0.25, 0.1, 0.25, 1] }',
    },
  }}
/>

### Popup

[Base UI props](https://base-ui.com/react/components/alert-dialog#popup), plus:
