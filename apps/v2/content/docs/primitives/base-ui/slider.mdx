## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same.

```tsx
import { Slider } from '@animate-ui/react/primitives/base-ui/slider';

export function Volume() {
  return (
    <Slider.Root defaultValue={50}>
      <Slider.Control>
        <Slider.Track>
          <Slider.Indicator />
          <Slider.Thumb aria-label="Volume" />
        </Slider.Track>
      </Slider.Control>
    </Slider.Root>
  );
}
```

Using the `@base-ui/react` umbrella import instead? The barrel mirrors it: `import { Slider } from '@animate-ui/react/primitives/base-ui'`.

## Animation

- **Dragging follows the pointer instantly**, and keyboard changes are instant.
- **A press on the track glides** the thumb and the indicator to the new value with `spring.snappy` (600ms). Base UI positions them with layout: they jump to the new place, and a transform offset springs back (FLIP), so nothing animates `left` or `width`. It composes with the `translate` Base UI centers the thumb with, and waits for `thumbAlignment="edge"`'s second layout pass. With a range slider, only the thumb that moves glides.
- Dragging right after a press cancels the glide: the thumb sits under the pointer.
- **The pressed thumb grows** to `scale(1.15)` with `spring.snappy`, and shrinks back on release.
- An `onValueChange` that calls `eventDetails.cancel()` still cancels the change.
- Under reduced motion, presses jump and nothing scales.

## API Reference

Every part takes exactly the props of [Base UI's Slider](https://base-ui.com/react/components/slider#api-reference). Animate UI adds the animation props below.

### Root, Label, Value, Control, Track

[Base UI props](https://base-ui.com/react/components/slider#root) only. Presses are tracked on the Control.

### Indicator

[Base UI props](https://base-ui.com/react/components/slider#indicator), plus:

<TypeTable
  type={{
    transition: {
      description: 'Transition of the indicator after a press on the track.',
      type: 'Transition',
      default: 'spring.snappy (600ms, bounce 0.15)',
    },
  }}
/>

### Thumb

[Base UI props](https://base-ui.com/react/components/slider#thumb), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the thumb after a press on the track, and of its press scale.',
      type: 'Transition',
      default: 'spring.snappy (600ms, bounce 0.15)',
    },
    pressedScale: {
      description: 'Scale of the thumb while it is pressed or dragged.',
      type: 'number',
      default: '1.15',
    },
  }}
/>

The pressed thumb also gets `data-pressed`. The Indicator and the Thumb render through Base UI's `render` prop: a `render` of your own replaces the animated element.
