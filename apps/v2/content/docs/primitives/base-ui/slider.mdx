## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same.

```tsx
import { Slider } from '@animate-ui/react/primitives/base-ui/slider';

export function Volume() {
  return (
    <Slider.Root defaultValue={50}>
      <Slider.Control>
        <Slider.Track>
          <Slider.Indicator />
          <Slider.Thumb aria-label="Volume" />
        </Slider.Track>
      </Slider.Control>
    </Slider.Root>
  );
}
```

Using the `@base-ui/react` umbrella import instead? The barrel mirrors it: `import { Slider } from '@animate-ui/react/primitives/base-ui'`.

## Animation

Animate UI v1 had no slider: it moves like v1's switch thumb.

- **The pressed or dragged thumb stretches along the track**: its width grows by 3/16 (a 16px thumb becomes 19px, v1's switch `pressedWidth`), on v1's switch spring (stiffness 300, damping 25), and springs back on release. It's the thumb's real width, so its round ends stay round, and Base UI centers it on its value, so it grows on both sides (along its height in a vertical slider).
- **A press on the track glides** the thumb and the indicator to the new value on the same spring (v1's switch thumb `layout` spring). Base UI positions them with layout: they jump to the new place, and a transform offset springs back (FLIP), so nothing animates `left`. With a range slider, only the thumb that moves glides.
- **Dragging follows the pointer instantly**, and keyboard changes are instant. Dragging right after a press cancels the glide: the thumb sits under the pointer.
- Under reduced motion, presses jump and nothing stretches.

## API Reference

Every part takes exactly the props of [Base UI's Slider](https://base-ui.com/react/components/slider#api-reference). Animate UI adds the animation props below.

### Root, Label, Value, Control, Track

[Base UI props](https://base-ui.com/react/components/slider#api-reference) only. Presses are tracked on the Control.

### Indicator

[Base UI props](https://base-ui.com/react/components/slider#indicator), plus:

<TypeTable
  type={{
    transition: {
      description: 'Transition of the indicator after a press on the track.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 300, damping: 25 }",
    },
  }}
/>

### Thumb

[Base UI props](https://base-ui.com/react/components/slider#thumb), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the thumb after a press on the track, and of its stretch while pressed.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 300, damping: 25 }",
    },
  }}
/>

The pressed thumb also gets `data-pressed`. The Indicator and the Thumb render through Base UI's `render` prop: a `render` of your own replaces the animated element. `AnimateUIProvider`'s `tempo` scales these transitions with everything else.
