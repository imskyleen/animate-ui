## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same.

```tsx
import { Slider } from '@animate-ui/react/primitives/base-ui/slider';

export function Volume() {
  return (
    <Slider.Root defaultValue={50}>
      <Slider.Control>
        <Slider.Track>
          <Slider.Indicator />
          <Slider.Thumb aria-label="Volume" />
        </Slider.Track>
      </Slider.Control>
    </Slider.Root>
  );
}
```

Using the `@base-ui/react` umbrella import instead? The barrel mirrors it: `import { Slider } from '@animate-ui/react/primitives/base-ui'`.

## Animation

Animate UI v1 had no slider: it moves like v1's switch thumb.

- **The pressed or dragged thumb stretches along the track**: its width grows by 3/16 (a 16px thumb becomes 19px, v1's switch `pressedWidth`), on a spring (stiffness 400, damping 32), and springs back on release. It's the thumb's real width, so its round ends stay round, and Base UI centers it on its value, so it grows on both sides (along its height in a vertical slider).
- **A press on the track glides** the thumb and the indicator to the new value on the same spring: as quick as v1's switch thumb, calmer (it goes about 1.5% past the value, where v1's switch thumb went about 4%). Base UI positions them with layout: they jump to the new place, and a transform offset springs back (FLIP), so nothing animates `left`. With a range slider, only the thumb that moves glides.
- **Dragging follows the pointer instantly**, and keyboard changes are instant. Dragging right after a press cancels the glide: the thumb sits under the pointer.
- Under reduced motion, presses jump and nothing stretches.
- Without a `locale`, Base UI formats the numbers (the Value, `aria-valuetext`) in the runtime's locale: the server's on the server and the browser's in the browser, so a page rendered in English and opened in another language didn't hydrate cleanly ("0.5" against "0,5", "1,000" against "1 000"). Animate UI formats them in en-US on the server and while the page hydrates, then in the browser's locale, as React Aria does. Pass `locale` to pick one yourself.

## API Reference

Every part takes exactly the props of [Base UI's Slider](https://base-ui.com/react/components/slider#api-reference). Animate UI adds the animation props below.

### Root, Label, Value, Control, Track

[Base UI props](https://base-ui.com/react/components/slider#api-reference) only. Presses are tracked on the Control.

### Indicator

[Base UI props](https://base-ui.com/react/components/slider#indicator), plus:

<TypeTable
  type={{
    transition: {
      description: 'Transition of the indicator after a press on the track.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 400, damping: 32 }",
    },
  }}
/>

### Thumb

[Base UI props](https://base-ui.com/react/components/slider#thumb), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the thumb after a press on the track, and of its stretch while pressed.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 400, damping: 32 }",
    },
  }}
/>

The pressed thumb also gets `data-pressed`. The Indicator and the Thumb render through Base UI's `render` prop: a `render` of your own becomes the animated element. `AnimateUIProvider`'s `tempo` scales these transitions with everything else.
