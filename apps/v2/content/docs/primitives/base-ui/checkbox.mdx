## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same.

```tsx
import { Checkbox } from '@animate-ui/react/primitives/base-ui/checkbox';

export function Terms() {
  return (
    <label className="flex items-center gap-2">
      <Checkbox.Root defaultChecked>
        <Checkbox.Indicator>
          <CheckIcon />
        </Checkbox.Indicator>
      </Checkbox.Root>
      Accept terms and conditions
    </label>
  );
}
```

Using the `@base-ui/react` umbrella import instead? The barrel mirrors it: `import { Checkbox } from '@animate-ui/react/primitives/base-ui'`.

`Checkbox.Root.Props`, `Checkbox.Indicator.State` and the other type namespaces are kept.

## Animation

The motion of Animate UI v1's checkbox:

- **Indicator**: the check draws itself. Its stroke (`pathLength`) and its opacity go from 0 to 1 together in 0.2s, after a 0.2s delay, on Motion's default ease-out. Unchecking erases it in 0.2s, without the delay, then the indicator unmounts, as in Base UI. The indicator element itself never moves: its content animates, so your layout and classes stay as they are. Content that isn't an SVG shape fades the same way.
- **Root** scales to 0.95 while pressed (no hover scale), on Motion's default spring for scale (stiffness 550, damping 30).
- A box that is checked when it mounts draws its check too, as v1's did. The indicator stays hidden until then, so a server-rendered page doesn't flash the check first.
- Checking with Space animates the same way: the state changes at once, the animation never delays it.
- Toggling again mid-animation turns back from where the check is.
- `indeterminate` shows the indicator like `checked`. An icon swapped for the indeterminate state draws without the delay, as v1's indeterminate line did. A parent checkbox in a `CheckboxGroup` animates the same way: the indicator follows the state Base UI computes.
- Under reduced motion, the check only fades (its stroke stays whole) and nothing scales.
- With `keepMounted`, the unchecked indicator stays in the DOM with its check hidden.
- The box's own colours are the component's CSS: shadcn/ui's `transition-colors` fades them.

## API Reference

Every part takes exactly the props of [Base UI's Checkbox](https://base-ui.com/react/components/checkbox#api-reference). Animate UI adds the animation props below. A `render` element (or function) of your own gets Base UI's behaviour, without the animation.

### Root

[Base UI props](https://base-ui.com/react/components/checkbox#root), plus:

<TypeTable
  type={{
    transition: {
      description: 'Transition of the press scale.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 550, damping: 30 }",
    },
  }}
/>

### Indicator

[Base UI props](https://base-ui.com/react/components/checkbox#indicator), plus:

<TypeTable
  type={{
    transition: {
      description: 'Transition of the check drawing itself.',
      type: 'Transition',
      default: '{ duration: 0.2, delay: 0.2, ease: [0, 0, 0.58, 1] }',
    },
    exitTransition: {
      description: 'Transition of the check erasing itself.',
      type: 'Transition',
      default: '{ duration: 0.2, ease: [0, 0, 0.58, 1] }',
    },
  }}
/>

`AnimateUIProvider`'s `tempo` scales these transitions with everything else.
