shadcn/ui's Combobox uses Base UI's Combobox for every base, Radix UI included: `animate-ui animate combobox` swaps its `@base-ui/react` import in both.

## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same.

```tsx
import { Combobox } from '@animate-ui/react/primitives/base-ui/combobox';

const frameworks = ['Next.js', 'React Router', 'Astro', 'SvelteKit'];

export function FrameworkPicker() {
  return (
    <Combobox.Root items={frameworks}>
      <Combobox.Input
        aria-label="Framework"
        placeholder="Search a framework…"
      />
      <Combobox.Portal>
        <Combobox.Positioner sideOffset={6}>
          <Combobox.Popup>
            <Combobox.Empty>No framework found.</Combobox.Empty>
            <Combobox.List>
              {(item: string) => (
                <Combobox.Item key={item} value={item}>
                  {item}
                </Combobox.Item>
              )}
            </Combobox.List>
          </Combobox.Popup>
        </Combobox.Positioner>
      </Combobox.Portal>
    </Combobox.Root>
  );
}
```

`import { Combobox } from '@base-ui/react'` (shadcn/ui's import) becomes `import { Combobox } from '@animate-ui/react/primitives/base-ui'`: the barrel mirrors the `@base-ui/react` umbrella.

### Check animation

The chosen item's check draws itself while the previous one erases itself. With `animation="pop"` on every item's ItemIndicator, the check glides from the previous item to the chosen one instead (a first choice pops it in from half its size):

```tsx
<Combobox.Item key={item} value={item}>
  {item}
  <Combobox.ItemIndicator animation="pop">✓</Combobox.ItemIndicator>
</Combobox.Item>
```

With a multiple selection, each check pops in and shrinks back out on its own.

The same demo with `checkAnimation="pop"` (its Controls switch it back to `draw`):

To pop every check of your app at once (checkboxes, menus, selects, comboboxes), set `checkAnimation="pop"` on an [`AnimateUIProvider`](/docs/installation#choose-how-checks-animate-optional) instead.

## Animation

Base UI's Combobox has no Animate UI v1 counterpart: it moves like v1's Base UI Menu.

- **Popup** fades and scales in from 0.9, from the input (`--transform-origin`), in 250ms (`{ duration: 0.25, ease: [0.215, 0.61, 0.355, 1] }`, a soft ease-out), and closes the same way before it unmounts. Reopening while it closes picks up from where it is.
- **The highlight**: one surface glides behind the highlighted item on a spring (stiffness 500, damping 40), following the pointer and the arrow keys alike, like v1's menu highlight. Moving to another item, it carries on from where it is, at its speed: however fast the pointer or the arrow keys go, there's one highlight on screen. It only fades in (200ms) when it appears from nothing. It glides on the compositor (a Web Animation of `transform`), so a busy main thread, a submenu opening for instance, doesn't stall it. When the pointer leaves the list, it stays on the last item. It wears the item's own highlighted background (`focus:bg-accent`, `data-highlighted:bg-accent`…), read from your styles: the item's background is cleared while it's highlighted; its text colors stay.
- Filtering while typing is instant: items appear and disappear on the next frame, with no per-item or height animation.
- Base UI resets the query and syncs the input when the popup unmounts, so the list doesn't change while it fades out.
- **Chip**: a chip added to the selection pops in from half its size with a fade, on the popovers' spring (stiffness 300, damping 25). A removed one (with its remove button or Backspace) leaves the selection at once, and a copy of it shrinks out where it was, out of the flow, in 0.15s. Either way, the chips after it and the input glide to make room or close the gap, on a quick spring without overshoot (stiffness 500, damping 40), instead of jumping, and when the row wraps onto a line more (or one less), the Chips grow (or shrink) to it on the same spring. A placeholder showing up as the input glides back (the last chip removed) fades in once the input is there, from a light blur (2px, 0.3s on a strong ease-out), instead of riding along. Chips already selected on mount don't animate. The copy is only seen: hidden from assistive tech, inert, without your ids, and without the chip's `data-slot`, so it doesn't count as a chip (shadcn/ui's Chips narrow their padding while they hold one).
- **ItemIndicator** (kept mounted on every item, so a check can hide itself): with a single value, the chosen item's check draws itself like a Checkbox's check (its stroke and opacity in 0.3s on Motion's easeOut, at once) while the previous one erases itself, and the list holds still for 150ms before it closes, so the change is seen. With `animation="pop"` (or `checkAnimation="pop"` on an `AnimateUIProvider`), the check glides there instead, on the highlight's spring (stiffness 500, damping 40), and a first choice pops it in from half its size out of a 2px blur (a spring, stiffness 500, damping 24). The demo's Controls switch between the two. Choosing the item already chosen, and closing any other way (Escape, a click outside), don't wait. With `multiple`, a selected item's check draws itself, and erases itself when it's deselected; with `pop`, it pops in from half its size and shrinks back out in 0.15s; a check written as text ("✓") fades (or pops).
- Animate UI passes an `actionsRef` to the Root and unmounts the popup when its exit is over. Your own `actionsRef` still works, `onOpenChangeComplete` fires after the entrance and after the exit, and `keepMounted` on the Portal keeps the closed popup mounted and hidden.
- Open from the start (`defaultOpen`), the popup plays its entrance on page load.
- Under reduced motion, nothing scales or glides: the popup, chips, checks and a placeholder showing up only fade (the chips after an added or removed one move at once), and the list doesn't hold; the highlight jumps from item to item and only fades in when it appears.

## API Reference

Every part takes exactly the props of [Base UI's Combobox](https://base-ui.com/react/components/combobox#api-reference). Animate UI adds the animation props below.

### Root, Input, InputGroup, Trigger, Clear, Value, Icon, Portal, Backdrop, Positioner, List, Row, Collection, Group, GroupLabel, Empty, Status, Separator, Arrow, Label, Chips, ChipRemove

[Base UI props](https://base-ui.com/react/components/combobox#root) only. They are not animated.

### Item

[Base UI props](https://base-ui.com/react/components/combobox#item) only. It takes part in the highlight; it needs nothing more.

### Popup

[Base UI props](https://base-ui.com/react/components/combobox#popup), except `render` (Animate UI renders the popup as a `motion.div`), plus:
