## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same.

```tsx
import { Switch } from '@animate-ui/react/primitives/base-ui/switch';

export function AirplaneMode() {
  return (
    <label className="flex items-center gap-2">
      <Switch.Root>
        <Switch.Thumb />
      </Switch.Root>
      Airplane mode
    </label>
  );
}
```

Using the `@base-ui/react` umbrella import instead? The barrel mirrors it: `import { Switch } from '@animate-ui/react/primitives/base-ui'`.

`Switch.Root.Props`, `Switch.Thumb.State` and the other type namespaces are kept.

## Animation

The motion of Animate UI v1's switch:

- **Thumb**, pressed: stretches toward the middle of the track, its other edge in place. Its width grows by 3/16 (a 16px thumb becomes 19px, v1's `pressedWidth`) on a spring (stiffness 300, damping 25). It's the thumb's real width, so its round ends stay round.
- **Thumb**, on a change: springs to its new side while its width springs back, on the same spring (v1's `layout` animation). The thumb's `translate` classes still decide where it rests (`data-checked:translate-x-…`): Animate UI puts it back where it was with a `transform` and springs it to its new place.
- **Root** doesn't move. Its colours are the component's CSS, and v1's track changed colour at once: shadcn/ui's `transition-all` on the track would fade it, so the CLI removes it.
- The press is v1's: the pointer, or Enter on the keyboard. Space toggles without the stretch, and the thumb glides the same way.
- Toggling again mid-glide turns back from where the thumb is, without a jump.
- Under reduced motion, the thumb jumps to its side, without the stretch.
- shadcn/ui's `transition-transform` on the thumb would tween its `translate`; the CLI removes it too (Animate UI also skips it while measuring, so a leftover class doesn't break the glide).

## API Reference

Every part takes exactly the props of [Base UI's Switch](https://base-ui.com/react/components/switch#api-reference). Animate UI adds the animation props below. A `render` element (or function) of your own gets Base UI's behaviour: a Root rendered that way has no press stretch, a Thumb no animation.

### Root

[Base UI props](https://base-ui.com/react/components/switch#root). The Root doesn't animate itself: it tells the Thumb when it's pressed.

### Thumb

[Base UI props](https://base-ui.com/react/components/switch#thumb), plus:

`AnimateUIProvider`'s `tempo` scales the spring with everything else.
