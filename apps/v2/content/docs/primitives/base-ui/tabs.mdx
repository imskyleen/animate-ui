## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same.

```tsx
import { Tabs } from '@animate-ui/react/primitives/base-ui/tabs';

export function Settings() {
  return (
    <Tabs.Root defaultValue="account">
      <Tabs.List>
        <Tabs.Tab value="account">Account</Tabs.Tab>
        <Tabs.Tab value="password">Password</Tabs.Tab>
      </Tabs.List>
      <Tabs.Panel value="account">Make changes to your account.</Tabs.Panel>
      <Tabs.Panel value="password">Change your password.</Tabs.Panel>
    </Tabs.Root>
  );
}
```

Using the `@base-ui/react` umbrella import instead? The barrel mirrors it: `import { Tabs } from '@animate-ui/react/primitives/base-ui'`.

## Animation

- **The active tab's surface slides** to the new tab on a spring (stiffness 300, damping 30), like Animate UI v1's highlight: the new surface fades in as it slides from the previous one, which follows it and fades out 200ms later. The List draws it as an indicator that copies the active tab's own classes and data attributes, so it looks exactly like your active tab (background, border, shadow, and the `line` variant's underline) in every style and theme, while the active tab's own surface is hidden. Its focus ring stays on the tab.
- **The tabs' colors change over 500ms** (`ease`, the curve of a color change), whatever transition your tabs set.
- Clicking quickly through tabs retargets the slide smoothly.
- **The incoming panel fades in from a 4px blur** over 500ms on a strong ease-out, while its height springs from the previous panel's to its own, like v1's tab contents, on the spring of [Auto Height](/docs/primitives/animate-ui/auto-height) and Animate UI's [Tabs](/docs/primitives/animate-ui/tabs) (stiffness 300, damping 30). The panels share an element (the tabs root, usually), which remembers the selected panel's height. The outgoing panel leaves at once, so the two never overlap.
- The selected panel fades in on mount (page load) too, as in v1.
- Keyboard changes animate like clicks, as in v1: Base UI moves focus with the arrow keys and selects with Enter or Space (or on focus with `activateOnFocus`), and the surface slides and the panel fades in.
- With `keepMounted`, inactive panels stay in the DOM, `hidden`, and fade in when they become active.
- Rendering Base UI's own `Tabs.Indicator` turns the sliding indicator off: yours is used instead.
- `<AnimateUIProvider tempo>` paces every transition.
- Under reduced motion, the surface jumps and the height changes at once; the fades still play.

## API Reference

Every part takes exactly the props of [Base UI's Tabs](https://base-ui.com/react/components/tabs#api-reference). Animate UI adds the animation props below.

### Root, Tab, Indicator

[Base UI props](https://base-ui.com/react/components/tabs#root) only.

### List

[Base UI props](https://base-ui.com/react/components/tabs#list), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the surface sliding to the new tab (pointer changes); the previous surface fades out 200ms after it starts.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 300, damping: 30 }",
    },
  }}
/>

### Panel

[Base UI props](https://base-ui.com/react/components/tabs#panel), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Transition of the incoming panel: its fade from a blur, and its height (in `height`, or the whole transition when it has none).',
      type: 'Transition',
      default:
        "{ duration: 0.5, ease: [0.23, 1, 0.32, 1], height: { type: 'spring', stiffness: 300, damping: 30, bounce: 0, restDelta: 0.01 } }",
    },
  }}
/>

The Panel renders through Base UI's `render` prop: a `render` of your own replaces the animated element.
