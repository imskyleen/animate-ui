## Usage

Import the primitive from Animate UI instead of Base UI. Everything else stays the same, types included (`Drawer.Popup.Props`, `Drawer.Root.SnapPoint`…).

```tsx
import { Drawer } from '@animate-ui/react/primitives/base-ui/drawer';

export function DailyGoals() {
  return (
    <Drawer.Root>
      <Drawer.Trigger>Daily goals</Drawer.Trigger>
      <Drawer.Portal>
        <Drawer.Backdrop />
        <Drawer.Viewport>
          <Drawer.Popup>
            <Drawer.Content>
              <Drawer.Title>Daily goals</Drawer.Title>
              <Drawer.Description>Swipe down to dismiss.</Drawer.Description>
              <Drawer.Close>Done</Drawer.Close>
            </Drawer.Content>
          </Drawer.Popup>
        </Drawer.Viewport>
      </Drawer.Portal>
    </Drawer.Root>
  );
}
```

Using the `@base-ui/react` umbrella import instead? The barrel mirrors it: `import { Drawer } from '@animate-ui/react/primitives/base-ui'`.

shadcn/ui's React Aria Drawer is built on Base UI's Drawer too: `animate-ui animate drawer` animates it the same way. shadcn/ui's Radix UI Drawer is built on Vaul instead: Animate UI replaces it with the [Radix UI Drawer](/docs/primitives/radix-ui/drawer), which has Vaul's API.

## Animation

Animate UI v1 had no drawer: the motion is v1's Sheet, with Base UI's swipe on top.

- **Popup** slides in from its edge (`swipeDirection`, a full size of its own) and fades in, on v1's sheet spring (stiffness 150, damping 22, a little livelier than the dialog's), and slides and fades back out the same way.
- While you drag it, it follows the finger on the same frame: no transition runs during a swipe. Let go slowly and it springs back; flick it and it leaves along the swipe, faster the harder the flick (the exit scaled by Base UI's `--drawer-swipe-strength`).
- **Backdrop** fades in and un-blurs (opacity 0 → 1, `blur(4px)` → `blur(0px)`) in 200ms, easeInOut, and leaves the same way; it follows the swipe in between.
- Snap points, nested drawers and `swipeDirection` work as in Base UI.
- CSS-driven, not Motion: Base UI drives the swipe through CSS variables and waits for CSS transitions before unmounting, so a JavaScript animation would fight the finger. The primitive brings its own small stylesheet (zero specificity) and the timing as inline variables: a spring becomes the `linear()` curve Motion itself would use (550ms for the sheet spring), and `AnimateUIProvider tempo` reaches it. It reads shadcn/ui's `--translate-x`, `--translate-y`, `--stack-scale` and `--closed-transform` when they're set.
- Under reduced motion, the drawer fades in place; a swipe dismissal still leaves along the swipe.

## API Reference

Every part takes exactly the props of [Base UI's Drawer](https://base-ui.com/react/components/drawer#api-reference). Animate UI adds the animation props below.

### Root, Provider, Trigger, Portal, Viewport, SwipeArea, Content, Title, Description, Close, Indent, IndentBackground, VirtualKeyboardProvider

[Base UI props](https://base-ui.com/react/components/drawer#root) only. They are not animated.

### Popup

[Base UI props](https://base-ui.com/react/components/drawer#popup), plus:

<TypeTable
  type={{
    transition: {
      description:
        'Opening (slide and fade in), snapping and springing back after a swipe that does not dismiss. CSS-driven: a spring becomes a `linear()` curve, a tween keeps its `duration` and cubic-bezier or named `ease`.',
      type: 'Transition',
      default: "{ type: 'spring', stiffness: 150, damping: 22 }",
    },
    exitTransition: {
      description:
        'Closing (slide and fade out), scaled by the release velocity of a swipe.',
      type: 'Transition',
      default: 'transition',
    },
  }}
/>

### Backdrop

[Base UI props](https://base-ui.com/react/components/drawer#backdrop), plus:

  }}
