## Usage

```tsx
import { REGEXP_ONLY_DIGITS } from 'input-otp';

<InputOTP maxLength={6} pattern={REGEXP_ONLY_DIGITS}>
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
    <InputOTPSlot index={2} />
  </InputOTPGroup>
  <InputOTPSeparator />
  <InputOTPGroup>
    <InputOTPSlot index={3} />
    <InputOTPSlot index={4} />
    <InputOTPSlot index={5} />
  </InputOTPGroup>
</InputOTP>;
```

A drop-in replacement for shadcn/ui's `InputOTP`: same parts, same props. Pass `aria-invalid` to the slots to show the error style.

## Motion

A typed character pops in over 0.15s, fading in from a 0.95 scale; a pasted code staggers in by 25ms per character. Deleting is instant. The active ring jumps to the next slot without a transition, since it follows the keyboard, and the caret blinks in the active empty slot. Under reduced motion, characters only fade and the caret stops blinking.
