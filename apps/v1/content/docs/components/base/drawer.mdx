## Usage

```tsx
<Drawer>
  <DrawerTrigger>Open Drawer</DrawerTrigger>
  <DrawerPopup>
    <DrawerHeader>
      <DrawerTitle>Drawer Title</DrawerTitle>
      <DrawerDescription>Drawer Description</DrawerDescription>
    </DrawerHeader>
    <p>Drawer Content</p>
    <DrawerFooter>
      <button>Submit</button>
      <DrawerClose>Cancel</DrawerClose>
    </DrawerFooter>
  </DrawerPopup>
</Drawer>
```

Set `swipeDirection` on `Drawer` to choose the edge: `"down"` (default, bottom drawer), `"up"`, `"left"` or `"right"`. It is also the direction that dismisses the drawer.

## Motion

The drawer is animated with CSS transitions, not Motion. Base UI drives the swipe gesture itself through CSS variables (`--drawer-swipe-movement-x`/`-y`, `--drawer-swipe-progress`, `--drawer-swipe-strength`) and the `data-starting-style` / `data-ending-style` attributes, so the styles read those directly and a JavaScript animation never fights the finger.

- **Open:** the popup slides in by 100% of its own size with the drawer curve (`ease-drawer`) over 500ms. The backdrop fades in over 300ms.
- **Swipe:** while dragging, transitions are disabled and the popup follows `--drawer-swipe-movement-*`; the backdrop fades with `--drawer-swipe-progress`.
- **Close:** 300ms (backdrop 200ms), scaled by `--drawer-swipe-strength` so a fast flick finishes faster. Velocity-based dismissal is Base UI's.
- **Reduced motion:** the drawer fades in and out in place instead of sliding.
