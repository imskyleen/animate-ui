## Usage

Wrap your app (or the part that shows toasts) in `Toaster`, then add toasts from any component inside it with `useToastManager`.

```tsx
<Toaster>
  <App />
</Toaster>
```

```tsx
function SaveButton() {
  const toastManager = useToastManager();

  return (
    <Button
      onClick={() =>
        toastManager.add({
          title: 'Event created',
          description: 'Sunday, December 03, 2023 at 9:00 AM',
        })
      }
    >
      Save
    </Button>
  );
}
```

To add toasts from outside React (a data layer, a `fetch` wrapper), create a manager once and pass it to the `Toaster`:

```tsx
const toastManager = createToastManager();

<Toaster toastManager={toastManager}>
  <App />
</Toaster>;

toastManager.add({ title: 'Saved' });
```

## Motion

Toasts animate with CSS transitions driven by Base UI's own stacking and swipe variables, not with Motion: a toast can be added while others are still moving, and transitions pick up from wherever they are instead of restarting.

- A toast slides in from the viewport edge by its own height while fading in, over 0.4s with a strong ease-out, and leaves the same way, faster, in 0.2s. Swiped away, it keeps going in the swipe direction.
- Toasts behind the front one scale down by 0.05 per step (never below 0.9) and peek out by 0.75rem. Hovering the stack, focusing it with the keyboard or tapping it spreads them out on the same curve, and pauses their timers.
- Under reduced motion toasts only fade, and the stack changes position without moving.

### useToastManager

<ExternalLink
  href="https://base-ui.com/react/components/toast#usetoastmanager"
  text="Base UI API Reference - useToastManager"
/>

Returns the `toasts` and the `add`, `update`, `close` and `promise` methods. `add` takes a `title`, `description`, `type`, `timeout`, `priority` and `actionProps` (rendered as the toast's action button), and returns the toast's id.
