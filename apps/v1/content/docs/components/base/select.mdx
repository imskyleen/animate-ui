## Usage

```tsx
const fruits = [
  { label: 'Apple', value: 'apple' },
  { label: 'Banana', value: 'banana' },
];

<Select items={fruits}>
  <SelectTrigger aria-label="Fruit" className="w-[180px]">
    <SelectValue placeholder="Select a fruit" />
  </SelectTrigger>
  <SelectPanel>
    <SelectGroup>
      <SelectGroupLabel>Fruits</SelectGroupLabel>
      {fruits.map((fruit) => (
        <SelectItem key={fruit.value} value={fruit.value}>
          {fruit.label}
        </SelectItem>
      ))}
    </SelectGroup>
  </SelectPanel>
</Select>;
```

Pass `items` to `Select` so `SelectValue` shows the label of the selected item rather than its raw value.

## Motion

The panel grows out of the trigger: it fades in from a 0.96 scale over 0.2s and closes faster, in 0.15s. When it overlaps the trigger (`alignItemWithTrigger`, the default with a mouse) it only fades, like a native select. Moving the highlight with the arrow keys is instant, and under reduced motion the panel fades without scaling.
