## Usage

```tsx
const [selected, setSelected] = React.useState<string | null>(null);
const [query, setQuery] = React.useState('');
const filtered = frameworks.filter((framework) =>
  framework.toLowerCase().includes(query.toLowerCase()),
);

<Combobox value={selected} onChange={setSelected} onClose={() => setQuery('')}>
  <ComboboxInput
    placeholder="Select a framework"
    displayValue={(framework: string | null) => framework ?? ''}
    onChange={(event) => setQuery(event.target.value)}
  />
  <ComboboxOptions>
    {filtered.length === 0 ? (
      <ComboboxEmpty>No results.</ComboboxEmpty>
    ) : (
      filtered.map((framework) => (
        <ComboboxOption key={framework} value={framework}>
          {framework}
        </ComboboxOption>
      ))
    )}
  </ComboboxOptions>
</Combobox>;
```

## Motion

The options grow out of the input: they fade in from a 0.95 scale over 0.6s and close faster, in 0.4s. Typing filters the list instantly, with no per-item or height animation, and moving the highlight with the arrow keys is instant too. Under reduced motion the list fades without scaling.
