## Usage

```tsx
<Slider defaultValue={[50]} max={100} step={1} getAriaLabel={() => 'Volume'} />
```

Pass two values for a range slider:

```tsx
<Slider defaultValue={[25, 75]} max={100} step={1} />
```

## Motion

Dragging the thumb follows the pointer with no lag, and the keyboard changes the value instantly. Clicking the track away from the thumb springs the thumb and the range to the new value; moving the pointer right after cancels that animation so the thumb stays under it. A pressed thumb grows slightly, and hovering it with a mouse shows a ring. Under reduced motion every change is instant and nothing scales.
