## Usage

```tsx
<Select items={fruits}>
  <SelectTrigger aria-label="Fruit">
    <SelectValue placeholder="Select a fruit" />
    <SelectIcon />
  </SelectTrigger>
  <SelectPortal>
    <SelectPositioner>
      <SelectPopup>
        <SelectScrollUpArrow />
        <SelectList>
          <SelectGroup>
            <SelectGroupLabel>Fruits</SelectGroupLabel>
            <SelectItem value="apple">
              <SelectItemText>Apple</SelectItemText>
              <SelectItemIndicator />
            </SelectItem>
          </SelectGroup>
          <SelectSeparator />
        </SelectList>
        <SelectScrollDownArrow />
      </SelectPopup>
    </SelectPositioner>
  </SelectPortal>
</Select>
```

## Motion

`SelectPopup` fades in from a 0.96 scale with `transition.dropdown` and exits with `transition.exit`, growing from `--transform-origin`. When the positioner aligns the selected item with the trigger (`alignItemWithTrigger`, `data-side="none"`) it only fades. Base UI's Select has no `keepMounted` portal, so `Select` passes an `actionsRef` to the root and unmounts the popup once its exit animation finishes; reopening mid-exit retargets the same element. Under reduced motion it fades without scaling. Items have no animated highlight: keyboard navigation stays instant.
