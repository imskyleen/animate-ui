## Usage

```tsx
<Slider defaultValue={[25, 75]}>
  <SliderLabel>Price</SliderLabel>
  <SliderValue />
  <SliderControl>
    <SliderTrack>
      <SliderIndicator />
    </SliderTrack>
    <SliderThumb index={0} />
    <SliderThumb index={1} />
  </SliderControl>
</Slider>
```

## Motion

Dragging is direct manipulation: the thumb and indicator follow the pointer with no transition, and arrow keys, Page Up/Down, Home and End change the value instantly. Pressing the control away from the thumb (a jump) springs the thumb and indicator to the new value with `spring.snappy`. Base UI positions them with `inset-inline-start`/`width` percentages, so the layout jumps and a FLIP transform (a translate for the thumb, a translate and scale from the start edge for the indicator) springs back to identity; it works for range sliders, vertical sliders and `thumbAlignment="edge"`. If the pointer moves more than 3px after the press, the animation is cancelled at once and the thumb sits under the pointer. While a thumb is pressed it scales to 1.15. Under reduced motion nothing moves or scales: every change is instant.

  The `render` property is not supported in the `SliderThumb` component, as it
