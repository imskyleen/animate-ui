## Usage

```tsx
<Combobox items={fruits}>
  <ComboboxInput placeholder="Search a fruit" />
  <ComboboxPortal>
    <ComboboxPositioner>
      <ComboboxPopup>
        <ComboboxEmpty>No results.</ComboboxEmpty>
        <ComboboxList>
          {(fruit) => (
            <ComboboxItem key={fruit} value={fruit}>
              {fruit}
              <ComboboxItemIndicator />
            </ComboboxItem>
          )}
        </ComboboxList>
      </ComboboxPopup>
    </ComboboxPositioner>
  </ComboboxPortal>
</Combobox>
```

Multiple selection with chips:

```tsx
<Combobox items={fruits} multiple>
  <ComboboxChips>
    <ComboboxValue>
      {(values) => (
        <>
          <AnimatePresence mode="popLayout" initial={false}>
            {values.map((value) => (
              <ComboboxChip key={value}>
                {value}
                <ComboboxChipRemove />
              </ComboboxChip>
            ))}
          </AnimatePresence>
          <ComboboxInput />
        </>
      )}
    </ComboboxValue>
  </ComboboxChips>
  {/* ComboboxPortal… */}
</Combobox>
```

## Motion

`ComboboxPopup` fades in from a 0.95 scale with `transition.dropdown` and exits faster with `transition.exit`, growing from `--transform-origin` (the input). `ComboboxPortal` stays mounted while it exits, and `Combobox` passes an `actionsRef` to the root so Base UI only resets the query and syncs the input once the exit has finished; reopening mid-exit retargets the same element. Filtering is keyboard-driven: items and the empty state appear and disappear instantly, and the list height is not animated. The highlight follows the arrow keys instantly (style `data-highlighted`). The check of `ComboboxItemIndicator` appears with the list; with `multiple`, toggling an item while the list is open fades and scales it with `transition.change`. Chips enter with `transition.change` and leave with `transition.exit`, except when Backspace removes them: that is instant. Under reduced motion everything fades without scaling.
