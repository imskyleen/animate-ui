## Getting started

Animate every installed shadcn/ui component in one command:

```bash
npx @animate-ui/cli@latest animate all
```

Or swap a primitive's import yourself:

```tsx
// Before
import { Accordion as AccordionPrimitive } from 'radix-ui';
// After
import { Accordion as AccordionPrimitive } from '@animate-ui/react/primitives/radix-ui';
```
