# @animate-ui/vue

Animated drop-in primitives for [reka-ui](https://reka-ui.com), built with [Motion for Vue](https://motion.dev/docs/vue).

Each primitive has exactly the API of reka-ui: swap the import and your components animate.

```ts
// Before
import { AccordionContent } from 'reka-ui'
// After
import { AccordionContent } from '@animate-ui/vue/primitives/reka-ui'
```

Documentation: [animate-ui.com](https://animate-ui.com)
